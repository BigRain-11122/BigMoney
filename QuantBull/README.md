## 可学教训（简版，详见 research/QUANTBULL_TRIAGE.md）

1. 用户投资纪律的代码化范式（不买暴雷/ST/停牌边缘）值得在 B 层掩码族延续——但 BigMoney 已有 b_layer_filter 承接 ST/亏损面，**停牌间隔形态过滤是增量**。
2. 负面公告=比新闻更早更硬的信号（新闻大面积报道通常滞后公告）。
3. GA 大搜索范式在 BigMoney 路线中被有意放弃（先验有效性>进化搜索），QuantBull 双岛 9.7 万代的沉没成本即证据。
