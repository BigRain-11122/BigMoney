## 方法论句集（白话）

### S1. 著名题材持有优先：在成名的著名主题集上，破线出场的机械门跑不赢「点火即买入、拿到底」。

- **数字**：机械波骑系统 pooled +631.6% vs 同窗被动持有 +927.9%（冻结三条件之①失败；16/16 折 LOO 同号过）
- **裁定**：机械门判负于著名主题持有
- **边界**：同窗 B&H 是幸存者基线非公平基线（E25 律：事件集按成名筛选自带幸存偏差）

### S2. 任意时点波骑机具优于随机：破线出场+复活再入场的结构门，从任意时点捕获题材行情的能力大幅超过随机点火。

- **数字**：系统 pooled +631.6% vs 随机点火 null p95 +312.6%（K=200 随机点火 null，系统≈null 中位的 15.8 倍）
- **裁定**：机具真实捕获力成立（vs 随机点火大幅胜）
- **边界**：胜过随机≠胜过著名主题持有（S1）；政体依赖如实披露（bull +231% / bear -44%）

### S3. 常数选择未定案：判读对结构常数高度敏感，冻结常数下的判负不构成稳健结论，深破线族超持有也禁直接采纳。

- **数字**：8 变体 pooled 域 [+237.4%, +951.6%]（4.0 倍摆幅；最优变体 破线0.75/复活1.30 +951.6% 超过持有）——待独立冻结再判
- **裁定**：常数未定案（0.75 深破线族待独立冻结再判）
- **边界**：禁看结果调线（两读法都只作稳定性注记）

### S4. 首波长于复活波：先验锚点点火的第一道波，比后续算法谷再入场的复活波更可能是长波。

- **数字**：AUC 0.7325（波级置换 raw p=0.0020，Bonferroni n=5 过线；主题簇重抽参考 p=0.496=簇弱）
- **裁定**：结构描述级采纳（簇弱·禁升格独立样本预测门）
- **边界**：「看前20天热度判断题材命」在波段级判负（12/15 检验全灭·folk 特征表归档参考件）

### S5. 算法谷点火全集判负：在算法谷点火的题材波全集上，破线+复活系统过不了 null 校准技能线（与著名集 S1/S2 互补的另一半判决面）。

- **数字**：TJ-SOLO-x1 pooled sharpe 0.2735 < null 校准技能线 1.3172；（null μ 0.3734/σ 0.1827·n_eff 625981·core48 池）；四面 g1/g2 全 false（bootstrap CI 下界最低 -0.17 非正）；M1 t=1.19<3.0；family PBO 0.429（观察带）；四面判负计数=4/4
- **裁定**：judged_negative 族级诚实关线（T-2026-10-04-167-P1·E28 集群分层首判）
- **边界**：FULL 面=实用披露口径不读法；0.75 深破线变体读数已在敏感性腿如实披露·判线不因变体重设（E24-ii）

## 方法论副产物（E25 卡·verbatim）

- **E25 幸存者基线律+结构常数敏感性律（事件型判决双律·theme line R4 实证）**（proven）：①**幸存者基线律**——按「成名」筛选的事件集（CEO 点名著名主题 16 例）上，同窗 B&H 不是公平基线而是幸存者基线：实测 pooled B&H +928% vs 随机点火 null p95 +313%（3x 差=幸存者溢价的直接读数）；事件型战法判决的公平对照=随机点火 null（窗长/代理分布匹配）——拿 B&H 当判线的批会把「事件选择偏差」错读成「战法无效」（THEME_PERSIST_P1 r657：机械波骑系统判负于 B&H 但 vs null 中位 15.8 倍）。②**结构常数敏感性律**——机械规则批（破线/复活/网格类结构常数门）的判读稳定性必须过常数网格披露腿：本批 8 变体 pooled 读数域 [+237%, +952%]（4.0x 摆幅·主判读在网格内变号）——单点常数判读不稳健时结论只能写「常数选择未定案」禁写方向性控诉/背书（禁看结果调线恒在）。配套首波结构发现=anchor_is_prior×is_long AUC 0.73（波级置换 p=0.002 过 Bonferroni·主题簇参考读数 0.496 独立性弱）＝「首波（点火锚）长于复活波」按结构描述采纳·禁升格独立预测门。证据=results/theme_persist_p1/ 五件+research/THEME_PERSIST_P1.md §7/§8（r657）。
