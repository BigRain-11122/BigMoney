## 1. 命题与现状基线

- 命题（令 §二原文）：一切**策略性空仓期**的现金不躺平——停泊生息、主信号回归日资金随叫随到。
- 引擎现状（如实）：live/paper.py 账户模型=INITIAL_CASH + 持仓 marks 累计，出场后现金恒 0 收益躺平（引擎无持币生息面·LFC_P1_SCREEN §1 已预留 prereg 路径）；纸盘 6 员中 3 员全仓持币+1 员半仓 ≈350 万躺平中（令 §二现状钩子）。
- 空仓段面（令 §二门禁）：空仓高发段=熊市/阴跌政体——停泊腿即五态矩阵（O-20260926-1355）熊/阴跌段收益增强件；全史空仓日占比基数=bm-b 统计面（≤10-16 供给）。

## 2. 引擎腿架构（本件属主面）

### 2.1 仓位子状态机（每账户现金面扩展）

账户现金从标量扩为子状态：

```
CASH_FLAT        # 躺平现金（现引擎缺省态·基线 C 臂保留态）
PARKED(asset, units, cost_ts)   # 已停泊：资产持仓单位数+入场戳
```

- 停泊触发面：账户「策略性空仓」判定=该账户当日无策略持仓（含 fail-closed 现金腿与政体路由强制空仓日两类来源·来源字段随账本行记录）。
- 回场触发面：策略信号回归日（入场信号面）→ 回场协议执行（§2.3）。
- 状态机迁移全部落账本行（append-only·每行带 source=strategic_exit|regime_cash|fail_closed 与 ts）。

### 2.3 回场协议（三铁律①「随叫随到」的机械面）

- 回场执行=T+1 开盘保守代理（O-1132 律同源）：信号日 D 的停泊仓在 D+1 开盘价卖出回场，现金于 D+1 可用——**回场延迟成本按品种实测入判据**（禁拍脑袋：每品种全史回场延迟=信号日→现金可用日的隔夜+往返成本三档压测面，判据线归 bm-a prereg）。
- **成本口径冻结引用（v0.2 对齐·prereg §3）**：ETF 往返成本=**26.082bp（V1 legacy 面 A）×stress∈{1,2,3} = 26.082 / 52.164 / 78.246 bp**——接线路成本面一律 import 本冻结口径（prereg 单一可比数=单边 bp×2·与主引擎 13.041bp canonical 单边同源），禁自创口径禁手抄漂移。
- 回场可用性声明引用（prereg §4 流动性门）：ETF 卖出资金当日交易可用/T+1 取现——零交易日回场延迟；接线面沿用面板 median daily amount ≥¥50,000,000 门读数（判读归 prereg·接线侧只做读数落账）。
- 停泊上限纪律：停泊面**不得占用主策略资金可用性**——回场延迟窗内主策略入场若被延迟=回场成本入停泊臂损益（诚实记账·禁止只记收益不记延迟损失）。
- **接线出场轴声明（v0.2·prereg §3 出场轴键引用）**：判决批自身=②持有到底（stint 数学·引擎缺省出场栈结构性缺席）；**接线路出场轴=①策略自有出场**（主信号回场日退出=本件 §2.3 回场协议）——prereg 明文「本批不测不判接线路出场」→ 接线窗出场轴属工程面自有承重，跑前冻结于接线窗 prereg（挂点版本冻结纪律照旧）。

### 2.4 风险隔离（三铁律③「不冒新险」）

- 停泊袖面风险预算独立字段（risk_budget_parking·预注册值归 bm-a）；停泊亏损单列 sleeve_pnl 列，**不得并入交易员组合回撤**（纸盘账本双列呈现：composite_pnl | sleeve_pnl）。
- 三铁律②「只吃安稳钱」的工程面（v0.2 引用 prereg §4 Face 3 冻结红线读数）：**p95 within-stint 最大回撤红线 A 臂 ≥−3.0% / B 臂（511380）≥−6.0%**；**硬尾帽单 stint 净值谷底 A >−10.0% / B >−15.0%**——接线侧账本行每 bar 落 within-stint DD 读数（判线值以 prereg 冻结面为唯一权威·工程侧零重定义）；可转债臂硬过滤钩子（强制赎回/退市/债底破位三过滤器接口预留）=ETF 形态下管理人层面承载（prereg §4 注记·直池腿另批显式过滤）。
