# 预注册 · Y4 的尺度无关伴随量（2026-11-13 · bm-c r1616）

> 冻结于**首次运行之前**。本文件写完、提交前不跑任何带新统计量的计算。看结果改线＝违规。

## 0. 为什么需要它（承 r1614/r1615 的两句话）

- r1614：七档 vol-target 书，在四条决策日历下**每一档都至少被拒一次** → `NO_RUNG_SURVIVES`。
- r1615：把**同一个池子等权全持**（194～204 只、每 bar 再平衡、零选择、零择时、零成本）放进同一个闸，
  top-2 占比 **1.466～1.497**，四条日历全拒；七档书只是它的 **52%～59%**。
- 结论：`candidate_year_gate.year_metrics` 的 `top2_share = 两年净收益之和 / 各年净收益之和` 是**尺度相关**的——
  分母随「赚得少」一起变小，所以低收益的书两年就能占满。它同时量「集中」与「赚得少」，两件事同框，
  于是供应面上 4 个候选全卡在 Y4 时，没人能分清是书太集中还是账赚得太少。

## 1. 被检验的统计量（定义现在冻结）

对一条年度净收益序列 `r_1..r_n`（百分数，含部分年份，与 Y4 同一行集）：

1. 取其中位数 `m = median(r_i)`；
2. 找到**最大的两年**（并列取先出现者），把它们的值替换成 `m`，得到 `r'_i`；
3. `CAGR = Π(1+r_i/100)^(1/n) − 1`，`CAGR' = Π(1+r'_i/100)^(1/n) − 1`；
4. **retained = CAGR' / CAGR**（`CAGR ≤ 0` 时无定义 → 记 `null`，禁写 0）。

口径说明（冻结）：
- `retained` 答的是「这本书去掉最好的两年之后还剩多少增长」，不是「两年贡献了多少钱」；
- 分子分母同为单位换算，**按比例缩放全年收益不改变结论**（同乘 c 时两个 CAGR 同乘约 c）——
  这一条本身就是一个承重自检腿（容差见 §4.1）；
- 部分年份照旧参与，因为 Y4 也参与；换分母就是换口径，本量**不换分母**。

## 2. 比较臂（沿用 r1615，不新建）

等权全持、逐 bar 再平衡、零成本、零选择、零择时的那条参考账本，四条日历同一口径。

## 3. 判据（写死在三态里，禁事后加档）

逐档、逐相位与参考臂比 `retained`：

| 条件（四条相位全满足才成立） | 判词 |
|---|---|
| 每一相位 `retained_book > retained_ref` | `MORE_ROBUST_THAN_SHAPE` |
| 每一相位 `retained_book < retained_ref` | `LESS_ROBUST_THAN_SHAPE` |
| 其余（相位间翻转） | `MIXED_BY_PHASE` |

整面唯一答案：

- 任一档 `MORE_ROBUST_THAN_SHAPE` → `BOOKS_STAND_WITHOUT_THEIR_TWO_BEST_YEARS`
- 否则任一档 `LESS_ROBUST_THAN_SHAPE` → `AT_LEAST_ONE_BOOK_RESTS_ON_TWO_YEARS`
- 否则 → `NO_PHASE_CLEAN_COMPARISON`

**禁则（本预注册最重要的一条）**：`retained` **不参与准入**。它只被**并列印在** `answer`
旁边，`answer` 的字面（`NO_RUNG_SURVIVES` / `ONLY_BRITTLE_RUNGS` / `RUNG_SURVIVES_PATH_TEST`）
由原闸原封不动地决定。任何「用新口径把被拒的档判成通过」的写法＝违规。

## 4. 验收（跑之前就定好的自检腿）

1. **尺度不变腿**：把一组的年度净收益同乘 0.5，`retained` 的变化必须 `< 0.02`（绝对差）。
2. **承重腿**：一组「两年极高、其余为零」的书，`retained` 必须显著低于「每年一样」的书。
3. **判词数据驱动腿**：只把参考臂的 `retained` 抬高到超过书的水平，`MORE_ROBUST` 必须翻成 `LESS_ROBUST`。
4. **不越权腿**：`decide()` 收到 `retained` 面板后，`answer` 字面必须逐字不变。
5. **重派生腿**：`check()` 必须能从产出的 `years_net_pct` 重算每格 `retained` 与整面判词，禁手写。

## 5. 预注册的诚实边界

- 本量**不能**证明某档可以采纳；它最多能说「这档的集中不是靠最好的两年」。
- 若结果落在 `NO_PHASE_CLEAN_COMPARISON`，那就是没有读数，**不许**降级成「大致相当」。
- 旧口径（Y4）与旧答案一律保留原样披露；本文件不构成对 `candidate_year_gate` 的任何修改。
