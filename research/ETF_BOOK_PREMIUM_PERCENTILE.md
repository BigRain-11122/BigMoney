# 这张单付的溢价，今天在它自己的历史里排第几

证据截止 2026-11-09　机器 bm-c　判决面 `results/etf_premium/PREMIUM-PERCENTILE.json`

## 一句话

11-10 的实盘单页自己写着「这三只票在这把尺子上没有够用的历史观测，所以今天这个溢价算不算高，本页答不了」。
本轮把这句话答掉：**这三只美元基金绝大多数日子就贴着净值走（中位溢价 1.26%~1.76%），而今天读
21.16% / 18.63% / 8.90%，分别是它们自己历史的第 100 / 99 / 99 百分位；若各自回到自己的中位溢价，
这张 ￥392,727 的单值 ￥28,959（7.4% 的账面）。**

## 为什么必须做

- 单页的「溢价」段是唯一一处**已经算出钱、却明说判不了**的地方：￥41,697（11-06 口径）买的是溢价，
  而判据只有 2 个观测。
- 缺的不是数据源，是**尺子的历史**：同一只票的单位净值每天披露，只是从来没被接进这张面。
- 溢价高低直接决定「今天这张单便不便宜」，而下一个决策 bar 是 2026-11-11 —— 早一天有读数就早一天可用。

## 做法

`scripts/etf_book_premium_percentile.py`：票面的五条腿逐条走

1. **价格**取自家面板 `data/daily/<sym>.csv`（与票面同源），
2. **净值**取东财按基金披露的单位净值历史（as-collected，缓存可重取，2019-01 起），
3. `premium(t) = close(t) / NAV(严格早于 t 的最新一期) - 1`，**同日净值一律不用**（那是这根收盘的未来），
4. 判词由分布派生：`AT_RECORD_HIGH / UPPER_TAIL(≥p90) / LOWER_TAIL(≤p10) / ORDINARY / THIN(<60 观测) / UNPRICED`，
5. **滞后梯子**：同一根收盘用倒数第 1/2/3 期净值各算一次，把「读数里有多少是净值戳的日期」量出来。

发布闸（不过即拒发，exit 2）：面板同一会话收盘必须复现已发布盘口价（≤0.5%）；每个已发布溢价必须
等于其自身 price/iopv（≤0.01pp）；已发布 CNY 数必须满足 `amount·p/(1+p)`（精确式）或其线性式
`amount·p`，两者相差多少逐条披露。

**三个读数**：

1. **「溢价」不是这类基金的常态**。159501/513100 的中位溢价 1.26%~1.28%，p05 为 -0.52%/-0.64%
   ——它们平时就是贴净值走的。今天这 21%/18.6% 是极端读数，不是「跨境基金天生贵」。
2. **今天这笔钱是可数的**：按各自中位溢价回算，三条腿合计 ￥28,959（159501 ￥12,884 / 513100
   ￥11,513 / 159577 ￥5,148），占这张单 7.4%。这是「溢价回到自己的常态」的价，不是卖出理由。
3. **净值戳的日期能挪动读数 5.5~7.8pp**。同一天收盘，用倒数第 1/2/3 期净值算，159501 读
   21.16% → 22.82% → 14.98%（跨度 7.84pp）；513100 18.63 → 20.24 → 12.58；159577 8.90 → 9.62 → 4.16。
   今天最新一期净值是 2026-11-06 的戳（滞后 3 个日历日），所以「21%」里有相当一块是**这几天标的
   自己涨跌**，不是有人愿意多付。QDII 的净值本来按海外收盘记，这一段结构上就存在。

**两个不许做的动作**（写在面上）：

- 不把两把尺子相加：盘口 IOPV 的 23.64% 与本面的 21.16% 是两个量（一个是盘中篮子估值，一个是
  已披露单位净值 T-3），并列印、不相加、不换算。
- 不把高分位当卖单：限购基金可以常年溢价，2020-03-24 的 513100 曾经 23.53% 之后仍有长溢价段。
  面里给的是「今天便不便宜」，不是「该不该卖」。
