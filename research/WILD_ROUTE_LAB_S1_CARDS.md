## §一 共享事件引擎与力学口径（全卡共用，s2 编码一次实现）

- **涨停判定**：close ≥ limit_up(prev_close, board)；limit_up 按板型：主板 ±10% / 创业板·科创板 ±20% / ST ±5%（票 spec 冻结口径；北交所 30% 不在本批宇宙）。round 到分（A 股价格 tick=0.01）。
- **炸板（烂板）判定**：high ≥ limit_up 且 close < limit_up（盘中触涨停未收封）。社区实践互证（slice-6：「基于日线数据自建炸板判断兜底」与 Akshare 炸板池同构）。
- **一字板判定**：low ≥ limit_up（或 low ≥ prev_close×1.097 主板类）→ 次日 gap-up 高开属未捕获溢价（un-captured premium），入场放弃腿如实记账。
- **连板计数**：consecutive limit-up days（含当日）；**市场高度** max_height(T)=全市场当日最大连板数；**梯队**=同题材/板块涨停家数。
- **执行口径（票 spec 冻结）**：signal 于 T 收盘可得 → T+1 开盘成交（only if tradeable）；一字 gap-up 不可成交=放弃+披露。滑点+成本双面 {x1, x2}。
- **宇宙剔除口径**（对齐 #6 复现面）：ST/*ST/上市<365 天/北交所剔除；子宇宙臂={P-1c 全 A ok-universe ~5129 / 涨停池子集 / 断板池子集 / 龙头池子集}。
- **regime 门候选（全数值，slice-5 S-C hiquant B+）**：主升=涨停数>80 家+炸板率<10%+高度>5 板；震荡=涨停数 30-80+炸板率 10-25%+高度 3-5 板；退潮/冰点=涨停数<30+炸板率>25%+高度<3 板。健康分歧=换手 15-35%（最佳 25%）+量能前日 1.5-2 倍+炸板率<25%+回封率>50%+封单/成交额≥8%；危险分歧=巨量 3 倍+换手>40% 放量下跌。三指标全日频可算=**s2 regime 门主候选**（#3 断板密度指纹/#8 冰点门/#9 高度面同源共享）。

## §二 12 pattern 卡片

### 卡 #1 首板打板（9% 触发 · 「临门一脚」变体）

- **定义**：当日盘中价 ≥ 前收盘×1.09（**9% 非 10%**——封死涨停买一队列堆积，普通买单排队难成交；按涨停价成交假设=回测严重乐观偏差）→ 次日开盘卖出 T+2。
- **主源**：Mr.看海 khQuant 横评（CSDN fengzhuqiaoqiaoqiu/148267009，全文深读）· 证据级 **B-**（真实量化横评帖+漏单实弹案例）。仓位面：最大 5 只均分、当日不重复买（社区复刻参数）。
- **日频编码候选**：`signal: high_T ≥ prev_close×1.09 ∧ 非一字；entry=open_{T+1}（若可成交）；exit=open_{T+2}`。
- **诚实边界**：①日线近似=盘中触发→次日开盘成交的代理距（真实打板=排板时点优势不捕获）②商业平台漏单案例（9.15% 未触发）=涨停附近撮合机制回测伪影警示，我方撮合假设显式披露③滑点 0.01 精度经成本链放大可见→{x1,x2} 双面必要性佐证。
- **拥挤注记**：「北京炒家」叙事=社区共识成分，仅作战法族命名出处，不编码。

### 卡 #2 一进二（二板确认接力）

- **定义**：个股首个交易日涨停（首板）后第二个交易日继续涨停=「一进二」现象；被视为主力深度介入/主升浪开端确认信号。
- **主源**：墨衍 AI-syndication《构建"一进二"涨停策略模型》（weixin_33755557/93698889）· 证据级 **C**（现象定义与街名一致；模型触发/买卖规则全在付费墙，开放面零阈值零胜率宣称）。
- **日频编码候选（本批最小定义，缺源腿自设须披露）**：`event: D1 涨停(首板) ∧ D2 涨停(二连) → 一进二确认日=D2 收盘；entry=open_{D3}（若可成交）`；变体臂=打二板（D2 盘中触发即买，日频近似=T+1 口径下不可表达，弃并披露）。
- **诚实边界**：源帖四点民俗有效性叙事（资金聚焦/惯性安全垫/过滤噪音/情绪周期 regime 条件化）=市场共识叙事零证据，仅 regime 条件化主张与 T-58 REGIME 账户面同构观察注记。
- **先验负**：zoo #75 接力族出谱（§〇.1）。

### 卡 #3 断板低吸 / 断板反包

- **定义**：T 日炸板（涨停被打开/断板）事件后两条入场路：①低吸=断板后低位/次日低开折价买入②反包=T+1 重新涨停（长阳反包）确认后再入场。一字炸板子格：一字涨停被砸开→次日缩量反包。
- **主源**：S-A《A股打反包板的一些原则》gky9989（104397106）· **C**（三行原则街味实操+唯一硬阈值）；S-B 金铁《短线追涨与低吸技术》书级笔记 zhiyuan411（147540606）· **B**（体系阈值丰富，无回测验证面）。
- **阈值面**：①反包日量 ∈ 炸板日量的 **[80%, 90%]**（爆量=勉强封死/无量=过于一致，S-A）②收复巨量长阴=3 日内长阳反包且量能递减（S-B）③低吸阈值族：超跌=较高点回撤 30%+长下影；洗盘结束=振幅>15% 且收盘跌幅<3%；跌停反复打开+换手>20%；13/21 日线金叉角度>45°=强势回档；量能凹口=连续 5 日量<20 日均量后突破；量比>2 催化量+次日维持 80% 跟随量；低开反包昨日阴线=反转信号。
- **日频编码候选**：`event: high_T ≥ limit_up ∧ close_T < limit_up；低吸腿 entry=open_{T+1}；反包腿: close_{T+1} ≥ limit_up(prev_close_{T+1}) → entry=open_{T+2}；量能过滤: vol_{T+1}/vol_T ∈ [0.8,0.9]（反包腿）`。
- **诚实边界**：S-A「涨停有气势」「分时丝滑」=盘中面日频不可编码（un-captured premium 族）；「低开太多」无数字阈值。
- **先验负**：zoo #75 断板族出谱；S-B 情绪三段论（萌发/成熟/宣泄，断板密度=宣泄段指纹）作 regime conditioning 候选。

### 卡 #8 情绪冰点卡位

- **定义**：情绪冰点=市场短线情绪极端退潮日；卡位=冰点后反转日抢先涨停卡身位的非最高板成员（梯队结构 face）。

### 卡 #9 连板高度空间（空间板）

- **定义**：市场最高连板高度=空间天花板度量；空间板操作法=龙头 X 板日买入、博弈冲 X+1 板预期。
- **主源**：S-G buranchenai《趋势股龙头战法》（106455229，三窗 40 交易日统计全文到手）· **B-**；S-A CSDN 官方 python 号方法学框架文（166152802 摘要面）· **C+**（高度/强度/共振三维+多因子打分+A 股特化撮合回测+成交率滑点修正+未来函数规避=与我方批设计要素逐项互证）。

- **日频编码候选**：`度量: max_height(T)=全市场最大连板数；臂1 高度锁死状态跟风腿: 高度 4/5/6 板日买入冲 X+1（预期负，参照 0% 晋级窗）；臂2 空间打开日卡位腿: max_height 创窗高日`；**双重身份注记**：max_height 自身=情绪周期高度面 regime 指纹（§一），s3 註记 pattern 与 regime 双面。

### 卡 #10 老妖回魂（二次拉升 · 本批命名权卡）

- **命名考古**：「老妖回魂」精确词社区零命中（3 查询实证）=**术语正典不存在，命名权收归本批**；操作语义=前期妖股沉寂后再涨停（回魂/二次拉升结构）。
- **阈值面主源**：公爵86《"横有多长竖有多高"游资战法再现》（weixin_43787229/157327503，全文深读）· **B+**——范式重构论：牛股非「横」出来而是「洗」出来的（涨停-缩量回调-再涨停强势洗盘完成筹码转移）；**主力三重留痕**=①涨停质量（早盘封板/一气呵成/封单坚决 vs 尾盘偷袭/反复开板/封单薄弱）②量能结构（**涨停放量+回调缩量+再涨停放量** vs 涨停缩量对倒诱多/天量出货）③回调韧性（浅幅/时间短/均线支撑强）；选股算法=**涨停强度 × 量能配合度 × 回调韧性系数**；**全参数**：涨停阈值主板 9/创业科创 19/进阶 15（板型自适应）、**回调幅度=（首涨停后至次涨停期间最低价）/首涨停收盘价×100% ≤10% 硬性条件**；完整代码=私信付费（诚实标注）。
