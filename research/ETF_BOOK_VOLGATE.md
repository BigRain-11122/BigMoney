# 书的门：把 `zoo #96` 的成交量状态机套在生产书上（REFUSE，r1402 bm-c）

## 一句话

供给线把 zoo #96（成交量双峰状态机）当**规则**判负了（对 510300 年化 −0.67pp，相位 null p=0.09）。
那条判决回答的是「它能不能替我交易指数」，不回答钱真正问的问题：**它能不能当这本书的风险开关**。
这一面就是那个连接件——同一条冻结规则、同一本书、同一条成本口径。答案：**不能，而且比随机相位更差**。

## 冻结了什么（读数之前写死）

| 项 | 值 |
|---|---|
| 书 | 生产档 `etf_book_production.prep_panel()` + `backtest(n=5, R=20, vol_target=8%)`，10bp/边 |
| 门 | `HMA(成交额合计,5)/HMA(成交额合计,100)`，>1.15 或 <0.8069 = 进场，中间=空仓 |
| 时点 | 第 t 根收盘的状态，作用于第 t+1 根的书收益（一根都不能少） |
| 成本 | 每单位 |Δw| 收一边，进出自付；复核腿 13.041bp/边 |
| 空集 | 状态序列圆周平移 200 次，p = 平移版收益 ≥ 观测值的比例 |
| 配角 | 镜像臂（带内=持仓、带外=空仓）、半仓臂、无波动目标的基座书 |

- 相对书的超额：**−9.86pp/年**；13.041bp 口径 **−11.15pp**；基座口径 −6.64pp。
- 相位 null：200 次平移均值 **−11.62pp**、p95 −8.64pp，观测 −9.86 → **p=0.15**。
  也就是说，「同一个门换个相位」通常更差，而真门也没好到显著——它不是信号，是**一条固定的场外时段**。
- 镜像臂 −10.53pp 且 null p=0.85：两个方向都在亏，说明亏的不是方向，是**离场**本身。

## 这条读数为什么值钱

书的年化 11.5% 里有很大一块是**在场时间**换来的（现金腿只有 ~1.35%）。把这 61% 的时间换成现金，
数学上就等于把 11.5% 稀释成 1.6%——而这套门的择时精度不足以补回差额，还顺带把回撤从 −10.6% 放大到 −18.9%
（错过反弹后在更差的位置重新进场）。**降险设备如果同时降收益、升回撤，那就不是降险设备。**

## 诚实的偏差披露

1. 被门控的臂在场外仍承担书的内部换手成本（引擎曲线已含），真实空仓不会调仓——所以这里的每个门读数都是**下限**，
   门只会显得更好，不会更差。结论方向因此不受影响。
2. 成交量轴=全市场成交额合计（zoo #96 自己的选择）；该面的股份数代理在 #96 里符号相反，这条警告随行至此。
3. 一根对齐：状态在收盘 t 读出，作用于 t+1 的收益。

## 结论与指针

`REFUSE_AS_OVERLAY`。zoo #96 从此在两处都关了：作为指数规则（r1396）与作为本书的风险开关（本面）。
供给线的「单独判负 ≠ 钱线的答案」这一问已经有人问过了，答案是「不，这里也不行」。
