3. **生命周期指纹（全 bars 制）**:
   - 发酵段=点火→+20td 斜率；主升段=窗内最优 20td 滚动斜率；
   - 见顶=点火后 750td 内最高收盘；持续长度=点火→见顶 bars 数；
   - 退潮段=见顶后 250td 内最大回撤 + 跌破 -20% 判线所用天数；
   - 超额=同窗 vs 沪深300；国外映射=纳指ETF 同点火 20td（"国外先发酵"腿）；扩散广度=14 题材面 ETF 在点火+20td 处 20 日涨幅为正的占比。

## 三、首过发现（描述性·不构成判线）

1. **"一两日游"与"贯穿一两年"在早段 20td 有初步分离面**: 券商脉冲 5td 见顶+22%即衰；而所有最终长命主题在点火 20td 内未死（新能源车 +7.9%、白酒 +14.4%、算力 +29.8% 均继续走）——**先验锚下的首过读法：20td 内冲顶即大概率是脉冲**。
2. **长主题的死亡是断崖不是阴跌**: 见顶后破 -20% 判线天数中位≈9-13td（算力3/AI5/DeepSeek5/白酒7/一带一路9/创业板15），而顶后最大回撤普遍 -40%..-86%——**持有到顶后的退出窗口极窄**。
3. **国外映射强度分层**: 新能源车点火时纳指同窗 +20%（海外特斯拉先行强）；AI2023/DeepSeek2025 点火时纳指同窗 ≈0/-4.9%（国内自主点火型）——**"国外先发酵"不是长命的必要条件**（两类都有长命例）。
4. **扩散广度两形态**: 点火+20td 广度 1.0（新能源/军工/白酒/算力=全面共振型）vs 0.21（AI2023/低空/黄金=冷启动聚焦型）——两形态都出现长命例；广度在点火期不是持续性的有效分离面（首过 n 太小，仅记录）。
5. **退潮深度与主升强度无首过相关**: 医药CXO +97% 涨幅却 -85.7% 退潮（归零式）；中特估 +18% 涨幅仅 -13.7%（红利面韧性）。

## 四、诚实警示（已知局限·下一刀的靶）

1. **共享面波叠合**: AI2023/算力2024/DeepSeek2025 共用科技/半导体/芯片面——单面的"点火→顶"跨波连续测量，`dur_to_peak` 对这类主题系统性偏长（表中 \* 项）。**下一刀=波段切分**（同面多波分解，逐波重测）。
2. **先验点火日是公认锚，非算法识别**——算法窗检测（量能/斜率变点）是 R3 第二刀。
3. **涨停池/连板梯队/炸板率数据不在库**——游资判据数值化（R2 面）需先补数据道（O-2103 R2 已注明 lane）。
4. ETF 代理=主题的可测面非主题本体；低空=弱代已标。
5. n=16 全部描述性结论**禁直接升格为判线**；R4 持续性预测门须冻结预注册（含随机基线+三窗+成本恒开三铁律）。

### 6.3 波段级首过发现（描述性·n=43 小样本·禁升格判线）

1. **波死≠主题死：复活是常态**。36 个已破线波中 27 个在 250td 内等来 +25% 复活波（**75%**）——v0.1 读取的「断崖」绝大多数是**一波的死**，不是主题的死。R4 持续性门必须两层分开判：波级死亡 + 主题级复活。
2. **早段 20td 斜率在波段级不分离脉冲/长命**（脉冲中位 +13.3% / 中段 +11.1% / 长波 +9.8%）——v0.1 §三.1 的点火锚早段分离面**未在波段级复现**（那是共享面叠窗的产物，如实修正记录）。波段级干净分离的是**持续长度本身**：脉冲中位 8td / 中段 56.5td / 长波 242td。
3. **首波脉冲有两种命运**（n=2 仅记录）：券商=主题终亡；光伏 2021=首波 17td 脉冲死后主题复活、W2 才是主升（+91%）——「点火即冲顶」不能直接判主题死刑。
4. **军工 2020 勘正**：波段级实测 W1=129td 长波（+72%）——v0.1 轮报告里「军工 5td 见顶即衰」系与券商例混淆的笔误面，正典以本表为准（md §三.1 原文为券商例，无误）。
5. **破 -20% 天数波段级中位 29td**（min 3 / max 131；v0.1 全局峰锚读法中位 9-13td 偏快——全局峰多为最大波 Blow-off 顶故破线更急，两读法并存如实披露）。
6. **低波代理面（红利/黄金）全程不破线**：中特估(红利面)与黄金 W1 的 -20% 线或至窗末/或极晚才破——题材判据向低波面移植时判线必先探边界（G-SEG 同族教训呼应 r633）。

### 6.4 诚实警示（v0.2 增量）

- 后续波是**代理面的波**——波1之外的主题叙事身份不认定（低空 W2 已标）；
- open_ended=窗末未破线（窗=点火+750td），非「至今存活」；窗外重生不入库；
