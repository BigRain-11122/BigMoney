# 把整块穷举完：准入判决在一个换仓块里的 25 个起点

**一句话**：五个周起点只是抽样，穷举整块之后是 **25 个起点 / 22 过 / 3 拒**；
最接近线的拒绝只差 **0.007**（夏普）而相邻起点一跳的中位是 **0.2006**——那一条是抽签；
但成本后年化那一侧有一个拒绝差 **1.78pp**，超过它自己一跳的中位 **1.03pp**——**那一条不是抽签**。
两个尺子给出两种结论，所以这一段不能只印「换起点就换答案」，它必须把两个距离都印出来。

## 为什么做这一张面

`etf_book_phase_admission` 把这本书在五个周起点上各定价一次，读出 4 过 1 拒，并在自己的
局限里写了这句话：**「五个周起点是一个换仓块，不是所有日历的样本；第六个起点是第六次掷币，
不是新证据。」**

那是一个诚实的自陈，也是一句没有说完的话：读者被告知「换起点就换答案」，却拿不到
「换多少个起点、有几个真的被拒、被拒的那几个离闸线有多远」。这张面就是那句话的收尾——
把**一个换仓块里的每一个起点**都定价一次，而不是再加一个星期。

## 怎么做的

| 项 | 做法 | 出处 |
|---|---|---|
| 起点集 | 面板从 2020-01-01 起的**前 25 个 bar**（连续切片，`grid_starts()`） | 本面 `GRID_FROM` / `GRID_STARTS` |
| 为什么 25 | 一个换仓周期 20 根 bar 全部覆盖，并够到相位面用过的最晚 first_bar（2020-02-04） | 本面 `REBAL_PERIOD`；自检 L9 钉死「宽于换仓周期」 |
| 定价 | 同一本 `nobond_vt08_adopted`，每个起点跑一次 | `etf_book_phase_admission.P.arm` → `etf_robust_pf.open_to_open_equity` |
| 逐起点判决 | S1 样本外夏普 ≥0.70；A1 成本后年化 ≥6.0%；K1 一日下单 ≤1% ADV | `candidate_year_gate.decision_block`（阈值导入） |
| 聚合 | 直接调用相位面的 `aggregate()`，**不重写第二份判词表** | `etf_book_phase_admission.aggregate` 导入 |
| spread 规则 | 直接调用相位面的 `spread_state()`（它自己钉定 `candidate_year_gate_phases.adjudicate`） | 导入，自检 L10 |
| 跨面对账 | 相位面那 5 个起点按 `first_bar` 在本面里逐个找回来，��词与读数必须逐位相同 | 本面 `cross_face_vs_phase_admission` |

**新增的只有一个读数**：同一条尺在**相邻起点之间一跳多少**（25 个读数的相邻差的中位）。
它把「拒绝」分成两种：距离小于一跳的 = 网格自己的分辨率不够，大于一跳的 = 真实的位置。

## 读数（2026-11-19 面板，1,666 根 bar，算到 2026-11-19）

| 项 | 夏普 S1（闸线 0.70） | 成本后年化 A1（闸线 6.0%） |
|---|---|---|
| 25 起点判决 | 22 ADMIT / **3 DENY** / 0 读不出 | 同左（拒绝的起点不完全相同） |
| 过线 / 不过线 | 23 / 2 | 23 / 2 |
| 最小 ~ 中位 ~ 最大 | 0.6002 ~ 1.6120 ~ 1.9903 | 4.22% ~ 11.09% ~ 13.37% |
| 跨度 | 1.3901 | 9.15pp |
| **相邻起点一跳的中位** | **0.2006** | **1.035pp** |
| 最接近线的拒绝 | 2020-01-22，差 **0.0070**（= 0.035 跳） | 2020-01-17，差 0.07pp（= 0.07 跳） |
| 最差的拒绝 | 2020-01-17，差 0.0998（= 0.50 跳） | 2020-01-20，差 **1.78pp（= 1.72 跳）** |
| 最差的拒绝是否超出分辨率 | 否（在噪声之内） | **是（在噪声之外）** |

被拒的三个起点：`2020-01-17`（两条尺都不过）、`2020-01-20`（只 A1 不过）、`2020-01-22`（只 S1 不过）。

- **跨面控制腿**：相位面的 5 个起点在本面里按 `first_bar` 逐个找到，判决与读数**逐位相同**
  （Δ夏普 0.000000、Δ年化 0.000000pp，0 处分歧）——所以这一面是用同一个引擎、同一份面板
  跑出来的，不是第二套算法。
- **同一个「五个起点」的结论没有翻面**：5 个里仍然 4 过 1 拒，只是现在知道在 25 个里
  有 3 个被拒，且其中**有一个是真实的位置**（A1 侧）。

## 这改变了什么，不改变什么

- **改变**：读者第一次能区分「这块网格上所有的拒绝都是抽签」和「其中有一条不是」。
  票面上的那一行现在写的是：夏普侧最差的拒绝也在噪声内（0.0998 < 0.2006），
  成本后年化侧最差的拒绝**超出**了它自己的一跳步长（1.78pp > 1.03pp）。
- **不改变**：准入判决依旧是 `YEAR-GATE.json` 的三读数，仍然由相位面判
  `UNADJUDICABLE_PHASE`；本面**不动任何闸线**，也不新增阈值。K1 是今天的盘口读数，
  在每个起点上逐位相同（构造使然），所以这块网格只测得到 S1 和 A1。
- **不改变**：本面不替换单相位 ADMIT，也不把「25 个起点里 22 个过」读成一个新的准入比例。

## 局限（如实）

1. 25 个起点**彼此只差一根 bar**，它们是同一条价格序列的 25 个视图，不是 25 次独立试验。
   一跳的中位被当作「分辨率」引用，**不是标准误**。
2. 「一跳的步长」是一个**描述**，不是判据：它把拒绝分成距离大/小两类，但不决定准入。
   准入线仍然在 `candidate_year_gate` 与相位面那里。
3. 起点集固定为 2020-01 的 25 根 bar。换一个年代（例如 2015 年）会是另一个块；
   本面没有测「年代 × 起点」二维网格。
4. 容量 K1 不随起点变化，所以本面**没有**测「不同起点下容量是否变化」。
5. 全部是已发布序列上的算术，不是券商成交记录。
