## §1 资金分配（100万实盘）

| 仓位 | 金额 | 比例 | 说明 |
|---|---|---|---|
| 股票多头 | 70万 | 70% | 主战场，5-10只个股 |
| ETF（行业/宽基） | 20万 | 20% | 分散+防御，2-3只 |
| 现金/逆回购 | 10万 | 10% | 缓冲，Regime=OFF时升至100% |

**为什么股票70%而不是35%**：散户做短线，alpha来自选股不是择时。100万足够在个股上分散5-10只，不需要ETF占大头。

**Regime=OFF时**：股票+ETF全部清仓，100万停泊逆回购（GC001，年化~2%）。

## §2 持仓数量与单票仓位（散户现实约束）

| 项 | 值 | 理由 |
|---|---|---|
| 同时持有股票 | 5-8只 | 100万每只10-14万，佣金最低5元才不浪费 |
| 单票上限 | 15%（15万） | 避免单票黑天鹅 |
| 单票下限 | 5%（5万） | 低于5万佣金占比过高 |
| 同时持有ETF | 1-3只 | 20万分3只=每只6-7万 |
| 每周换仓次数 | 2-4只 | 不超过总持仓的50%，控成本 |

**为什么不是20-30只**：100万买20只股票每只5万，单边佣金5元+印花税25元=30元，双边60元。一只票涨3%才赚1500元，成本占4%。分散到5-8只，每只10万，佣金占比降到0.1%以下。

## §4 融合评分（散户可执行版）

不是每天跑43个风格。**每晚给候选股打一个分**：

```
每只候选股得分 = Σ(触发的风格数)
  - 触发S1 = +1分
  - 触发S2 = +1分
  - 触发S7 = +1分
  - ...以此类推

买入规则：
  1. 得分≥2分的股票才有资格买（多个风格共振）
  2. 得分相同按流动性排序（成交额大的优先）
  3. 按得分从高到低买满仓位（最多买8只）
  4. Regime=OFF时不买
```

**为什么是得分≥2**：单风格信号噪音大，两个风格共振（比如"超跌+放量"或"动量+突破"）才有统计意义。这就是"多风格融合"的散户版——不需要计算机，一张表打勾。

## §5 执行细节（散户每天怎么做）

### 5.1 每日时间表

| 时间 | 动作 | 耗时 |
|---|---|---|
| 15:00收盘后 | 扫信号、打分、列买卖清单 | 15分钟 |
| 次日9:25 | 看集合竞价，决定挂单价 | 2分钟 |
| 9:30-9:35 | 挂单成交 | 3分钟 |
| 9:35后 | 不看盘（日线级别不需要盯盘） | 0 |

### 5.2 下单方式

- **买入**：次日开盘价±1%挂限价单，不追高
- **卖出**：触发退出规则的，次日开盘直接卖（不等反弹）
- **止损**：盘中触及-7%立即卖（不等收盘）
- **不做**：不在盘中临时改主意、不追涨停板、不抄底跌停板

### 5.3 成本控制

| 项 | 数值 |
|---|---|
| 佣金 | 万2.5，最低5元（找券商谈） |
| 印花税 | 卖出0.05% |
| 滑点估计 | 买入+0.2%，卖出-0.2% |
| 单笔总成本 | 约0.3-0.4% |
| 每月换手 | 2-3轮（70万仓位×2.5轮=月交易成本~7000×0.35%≈2500元） |
| 要求月收益 | >0.5%才覆盖成本 |

## §6 风控铁律（100万散户版）

| 规则 | 值 | 触发动作 |
|---|---|---|
| 单票止损 | -7% | 次日开盘无条件卖 |
| 日止损 | 组合日亏>2%（>2万） | 当日不开新仓 |
| 月止损 | 组合月亏>6%（>6万） | 清仓休息到月底 |
| Regime门 | HS300<MA200 | 全部清仓停手 |
| 单票仓位 | 5%-15% | 超限自动卖出 |
| 持仓数量 | 5-8只 | 超过8只不买新的 |
| 最大回撤 | 组合从高点回撤>15% | 减半仓到50%运行 |

**铁律**：以上规则没有例外。触发就执行，不抱幻想。

## §7 新手过渡（前3个月）

| 阶段 | 时间 | 仓位 | 目的 |
|---|---|---|---|
| 纸盘 | 第1-2个月 | 0 | 每天按规则记录买卖，看模拟收益 |
| 试水 | 第3个月 | 30%（30万） | 实盘跑，验证执行不手抖 |
| 正常 | 第4个月起 | 100% | 全仓位运行 |

**纸盘期间要记录**：
- 每天的信号清单（买什么卖什么）
- 如果按规则执行，模拟收益是多少
- 对比实际操作（试水期）和纸盘记录的偏差
