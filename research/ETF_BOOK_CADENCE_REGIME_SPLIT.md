# 节奏差是「起跑日」造成的，还是「你活在哪段行情」造成的

**面**：`results/etf_book_cadence_regime_split.json`（evidence_cutoff **2026-11-25**，面板 5,288 bar / 1,531 只，sha1 `46a5c9a6…`）
**工具**：`scripts/etf_book_cadence_regime_split.py`（selftest 18/18 · run rc0 · check rc0 · 二次 run 字节恒等）
**上一手**：r2129 `research/ETF_BOOK_CADENCE_START_DATES.md` 的续作点 2——它当时自己承认分不开这两个旋钮。

## 一句话

**把起跑日挪出 2020 冬天之后，R20→R10 的方向主要跟着「这段行情」走，不跟着「你哪天进场」走**：同一季度里换起跑日，节奏差的中位极差只有 **1.73 pp**；同一本书换季度，极差 **4.45 pp**（约 2.6 倍）。双因素中位抛光后，起跑日效应极差 1.22 pp、行情段效应极差 4.54 pp（3.7 倍），残差 2.37 pp。

判词：`REGIME_DOMINATES | BOTH_CHANNELS_READ`（8bp 与 1bp 两档一致）。

## 怎么做的（为什么这两个旋钮能分开）

6 个起跑日（2021-09-01 / 2022-03-01 / 2022-09-01 / 2023-03-01 / 2023-09-01 / 2024-03-01，全部在 2020-01-02..2020-03-05 那个冬天之外）× **同一批日历季度**（2022Q1..2025Q4，16 段）。

- 一个季度里有 2–6 本书同时活着，它们**面对同一段行情**，差别只有进场日 → 段内跨书差 = **起跑日（路径）通道**；
- 一本书横跨 7–16 个季度，**排序不动、只有行情在换** → 书内跨季差 = **行情通道**；
- 两者都不是零假设意义上的独立样本，所以再叠一层两因素中位抛光（9 轮）：行效应=起跑日，列效应=行情段，残差=两者都解释不了的交互。

引擎零重实现：面板与评分来自 `scripts/etf_book_cadence_start_dates.build_inputs`，成交链来自 `scripts/etf_variants_null_rolling.fast_next_open`（收盘决策 → 次日开盘，成本恒开，n_hold=5）。

## 读数（8bp 主档）

| 通道 | 中位极差 | 可用样本 |
|---|---|---|
| 起跑日（同一季度里换进场日） | **1.73 pp** | 11 个季度（≥4 本书） |
| 行情段（同一本书换季度） | **4.45 pp** | 6 本书（≥3 季度） |
| 抛光行效应 | 1.22 pp | 6 个起跑日 |
| 抛光列效应 | **4.54 pp** | 16 个季度 |
| 抛光残差 | 2.37 pp | 142 格 |

1bp 档（假设费率，仅对照）：起跑 1.75 / 行情 4.42 / 行效应 1.31 / 列效应 4.33 / 残差 2.36 —— **同型**，不是成本造的。

两个方向都要读：

1. **中位跟着季度跳**（2023Q4 −8.1 到 2024Q3 +5.3），这是行情通道；
2. **2025 下半年段内跨书极差涨到 5–10 pp**——晚期季度里进场日又开始咬人（书更短、排序更分散），所以"起跑日不重要"这句话不能推到所有年份。

## 钱（100 万参考账户，季度总收益差，未年化）

- 起跑日通道 1.73 pp ≈ **17,278 元/季**；
- 行情通道 4.45 pp ≈ **44,539 元/季**。

这只是"答案会动多大"，不是年化收益，两者不能相加，也不能乘 4 变成年。

## 这一面允许说 / 不允许说

> **允许说**：在 2021-09..2024-03 这些起跑日之间（2020 冬天之外），**换进场日对 R20→R10 的方向影响约为换行情段的四成**；节奏差的主要来源是"账本活在哪一段"。
> **允许说**：冬天那把尺子（+0.76/+0.68 pp）之所以为正，是因为所有书都活在同一个冬天里——**没有行情段可换**，于是只剩下那条本来很小的起跑日通道。
> **不允许说**：「起跑日不重要」——2025 下半年段内极差 5–10 pp，比全年中位大一个量级。
> **不允许说**：这面能替 `etf_book_rebal_adoption` 投票——票面判词仍是 `PHASE_DEPENDENT`，本面不改票。

## 诚实边界

- 幸存者偏差：盘上票池是现存 ETF（家族共同缺口，未解）。
- 无波动目标：`fast_next_open` 不带 vol target，这是未上目标的书。
- 通道不独立：路径通道是"同一行情里不同排序"，行情通道是"同一排序不同行情"，残差量的是两者解释不了的部分。
- 起跑日刻意避开 2020 冬天，所以本面对那个冬天的读数（r2129）不给任何结论。
- 少于 4 本书的季度（2022Q1–2023Q1）**具名排除**不进路径通道；少于 3 季度的书不进行情通道；50 个薄格全部写在 `holes` 里，没有一个被当成 0。
