## 1. 病根（r1256 已量化，本轮证实并修掉）

- `data/daily` 两层结构：裸码 `510300.csv` = core48 近窗副本（2020+，有维护）；前缀码 `sh510300.csv` = 全史 ETF 面（无维护腿）。

## 2. 这条腿做了什么

```
python scripts/update_etf_wide.py run [--limit N] [--workers 6]
python scripts/update_etf_wide.py --selftest     # 21/21
```

- 宇宙 = `data/daily/*.csv` 全部可映射文件（裸码按首位补 sh/sz），实测 1,724 只；唯一跳过 `510880_t73`（T-73 冻结槽副本，非普通标的）。
- 源 = 与五员腿同一条 sina klc_kl.js 直连（ETF 上 qfq 因子恒 1.0 = as-traded 基），**基座由重叠行逐字节校验保证**：本地每一行都必须被源复现（价格 1e-6、量额 ±1），否则该标的原样不动。
- **只做尾追加**：仅写 `date > 本地末行` 的行。这是本轮的第二次修正——首版按并集填洞，会把裸码近窗副本从 2020+ 回填到 2012+，
  等于偷偷改写 core48 产线的底座（实弹 35 个文件，提交前发现并 `git checkout` 回滚）。
- 逐标的隔离：一只标的取数失败或重叠失配不阻塞其余 ~1,720 只（五员腿是五文件一族所以全或无，这里不是一族）。
- 新鲜度门 = 全宇宙**最旧**末行日期 ≥ 15:30 约定的最新完整 bar 日；源已终结的标的（`sh512390`，末行 2026-09-04，退市）记入
  `source_ended_stems` 并从门里剔除，否则门永远开着、每轮白跑一遍。
- 车道归属 = bm-c（新腿由本机立），他机 stdout-only no-op，沿用五员腿的 `--takeover`（属主心跳静默 ≥120min）闸。

## 4. 顺带修掉的分类器缺陷（金额相关）

`scripts/etf_asset_class.py::class_from_name` 在无关键词时**提前返回 "equity"**，使 `class_from_prefix` 的 511/551/518/513 兜底
永远不可达。结果：511880 银华日利、511990 华宝添益、159003 招商快线等货币基金被标成权益，**在刷新后的活票里占 5 只中的 2 只**
（cash 基金价格恒 100 附近、低波低振幅=打分天然靠前）。

修法两条：①无关键词返回 None，让前缀兜底生效；②关键词补货币族（日利/添益/添利/快线/保证金/日日/天天金/财富宝）。
实测翻转 15 只（6 只货币/债券→bond、4 只上海金→commodity、5 只跨境→crossborder），全宇宙类别分布
equity 1,341 / crossborder 247 / bond 113 / commodity 22 / convertible 2。

### 4.1 缺陷一：货币基金被当成股票（上一窗已修，本窗复核）

`etf_asset_class.class_from_name` 旧版 keyword 全不中时返回 `equity`，于是名字里没有
「货币」二字的 511880 银华日利 / 511990 华宝添益 / 159003 招商快线 全被贴成权益，
上一窗的 live 票面 5 选里 **2 只是现金基金**。现改为返回 `None` 让前缀兜底。
复核：`classify` 对 511880/511810/159003/511990 全 = `bond`；今日票面 5/5 = equity。

### 4.2 缺陷二：同一只 ETF 在横截面里出现两次（本窗新发现并修）

`data/daily` 同一标的存两个文件名：`<code>.csv`（core48 六位面）与 `sh|sz<code>.csv`
（全史宽基面）。面板按**文件名**建列 → 1,656 列里 **48 只标的重复**。后果不是报错而是
隐性集中度：R20 的 83 个决策日里 **22 个（26.5%）** 把同一只 ETF 装进 5 格中的 2 格
（例 2021-04-29：513500 两格 + 159980 两格）。这个缺陷长期隐身，正因为旧宽基面停在
2026-09-22——停更列因子/成交额为 NaN 很少入选；**全池刷满有价之后它才全面暴露**。

修法：`scripts/etf_composite_pf.py` 加 `_stem_key`/`_dedupe`，面板载入层按归一代码去重
并优先保留前缀宽基面（刷新腿维护、带最新尾）。三项验证：
列数 1,656 → 1,608（恰减 48）；重复格决策 22/83 → **0/83**；历史起点不变（2005-02-23，
510300 3,500 根）。

对收益的影响（诚实披露，方向=几乎不动）：
书 CAGR 11.18% → **11.05%**，同 beta 对照 2.99% 不变，超额 +8.19 → **+8.06pp**；
基座 next-open R20 仍 OOS **13.48% / SR 1.381 / MDD -10.2%**。即去重不是挪收益，
是拆掉一个隐性的单票双倍仓。
