# research/STRATEGY_SYSTEM_V4_EVOLUTION.md — 全量回测 × 因子策略交叉迭代系统

> 定位：V3的全量进化版。不精简、不手工筛选，43+风格全量walk-forward回测，因子层与策略层双向喂养自动迭代。
> 算力假设：3机80核常驻，夜间/周末可满载跑批。时间充裕，不赶进度。
> 覆盖域：沪深ETF(48只) + A股主板流动性池(~800只)，3-15天日线波段。

---

## §0 系统全景：两个闭环互相驱动

```
┌─────────────────────────────────────────────────┐
│                 组合层（最终产出）                │
│   全量存活风格等权融合 → 组合净值曲线            │
│   月度审计 → 淘汰失效风格 → 反馈指导            │
└──────────────────┬──────────────────────────────┘
                    │ 反馈：哪类风格赚钱/亏钱
                    ▼
┌──────────────────┴──────────────────────────────┐
│              策略层（风格工厂）                  │
│  输入：因子 + 经济机制 → 生成新风格              │
│  全量回测：walk-forward × 全标的 × 全历史        │
│  筛选：过G1'门禁的进存活池                       │
└──────────────────┬──────────────────────────────┘
                    │ 反馈：哪些因子组合有效/无效
                    ▼
┌──────────────────┴──────────────────────────────┐
│              因子层（因子工厂）                  │
│  输入：反馈 + 经济假设 + LLM磨坊                │
│  输出：新因子表达式 → IC测试 → 入库              │
└─────────────────────────────────────────────────┘
```

**两个闭环**：
- **内环（周频）**：因子IC测试 → 合格因子入策略池 → 生成新风格 → 回测
- **外环（月频）**：组合表现审计 → 淘汰失效风格 → 反馈因子挖掘方向 → 新假设

## §1 全量回测协议

### 1.1 回测矩阵

| 维度 | 范围 |
|---|---|
| 标的 | ETF 48只全量 + 股票池800只全量 |
| 历史窗 | 2010-01 ~ 2026-09（16年，深史面板主轴） |
| Walk-forward | 训练窗504交易日(2年)，测试窗21交易日(1月)，步长63交易日(3月) |
| 风格数 | 初始43个，每月增长5-10个 |
| 参数 | 每风格≤2个固定参数，不做网格搜索 |
| 成本 | v2分层滑点 + 印花税(股票) + fill_guard |
| 总回测量 | 43风格 × 848标的 × 64个测试窗 ≈ 230万次单策略回测 |

### 1.2 Walk-forward切分（全量）

```
Window 1:  训练 2010-01~2011-12 → 测试 2012-01
Window 2:  训练 2010-04~2012-03 → 测试 2012-04
...
Window 64: 训练 2024-10~2026-09 → 测试 2026-10
```

- 每个风格在每个标的上跑64个测试窗
- 每个测试窗的信号拼接成完整OOS曲线
- **不做参数优化**，walk-forward检验的是regime适应性

### 1.3 全量门禁链（每个风格必过）

```
G0: 数据完整性门（无缺失、无未来函数、成本正确）
  ↓
G1': skill_line_v2判线（组合层N_eff校正）
  ↓
G1.5: stationary bootstrap 95% CI下界 > 0
  ↓
G2: CSCV PBO ≤ 0.25（8块70组合）
  ↓
G2.5: DSR ≥ 0.95（在组合层计算，不是单策略层）
  ↓
存活池：进入融合组合
```

**关键**：门禁在**组合层**算DSR，不在单策略层。单风格Sharpe 0.3只要CI下界>0就进池，融合后组合层统一过DSR。

## §2 因子层：因子工厂

### 2.1 因子来源（四条生产线）

| 线 | 来源 | 节奏 | 说明 |
|---|---|---|---|
| F1 | 经济假设派生 | 月频 | 每月提出2-3个新经济假设（如"小市值+低波在A股短周期有效"），派生因子表达式 |
| F2 | LLM磨坊(J13 v2) | 周频 | qwen2.5:7b生成因子公式草稿，盲测合格率9/10后入库IC测试 |
| F3 | 现有因子变异 | 周频 | 对存活因子做变异（如mom_20 → mom_20×vol_60/2），测新IC |
| F4 | 外部参照库 | 月频 | Alpha158/GTJA/WQ库中gap族（Aroon/WVMA/量RSI等7族）逐族实现测试 |

### 2.2 因子筛选规则

```
新因子 → IC测试（全标的×全历史）
  ↓
|IC| > 0.03 且 IC_IR > 0.3 → 入候选因子库
  ↓
与现有存活因子 max|corr| ≥ 0.7 → 淘汰（重复信息）
  ↓
入因子库（当前5394个目标→年底扩到8000+）
```

### 2.3 因子淘汰

- 每季度重算全因子IC排名
 | 连续2个季度|IC|<0.02的因子 → 归档
- 归档因子不删除，保留在库中备查

## §3 策略层：风格工厂

### 3.1 风格生成（从因子到风格）

**规则**：一个风格 = 1个经济机制 + 1-2个因子组合 + 固定参数。

```
新因子入库 → 匹配经济机制 → 生成风格
  ↓
例：因子"小市值rank" + 机制"规模异象" → 风格"低市值top20月度轮动"
例：因子"z-score_5d" + 因子"volume_ratio"组合 + 机制"恐慌出清" → 风格"超跌+放量反转"
```

### 3.2 全量回测每个新风格

每个新风格生成后：
1. 预注册（sha冻结规则、参数、预期）
2. 全量walk-forward回测（§1.1矩阵）
3. 过门禁链§1.3
4. 过了就入存活池，没过就归档（记录死因）

### 3.3 风格池目标

| 时间 | 存活风格数 |
|---|---|
| 当前 | ~43个（初始池） |
| 3个月后 | 60-80个 |
| 6个月后 | 100-120个 |
| 12个月后 | 150-200个 |

不是越多越好。风格间平均相关>0.4时停止扩张，优先淘汰冗余。

## §4 交叉迭代机制（核心）

### 4.1 因子→策略喂养（周频）

```
每周日：
1. 因子库新增/更新IC数据
2. 自动生成"因子×机制"组合候选
3. 每个候选生成一个新风格脚本
4. 提交全量回测队列（Celery分布式，3机80核）
5. 跑完过门禁，存活入池
```

### 4.2 策略→因子反馈（月频）

```
每月1日：
1. 审计存活池中所有风格的近6个月OOS表现
2. 分类：
   - 赚钱风格（Sharpe>0.5）→ 提取其核心因子 → 标记"该类因子方向有效"
   - 亏钱风格（Sharpe<0）→ 提取其核心因子 → 标记"该类因子方向无效"
   - 中性风格（Sharpe 0-0.5）→ 保留观察
3. 反馈给因子层：
   - 有效方向 → 深挖变体（如"动量类有效"→ 测不同lookback的动量变体）
   - 无效方向 → 停止该方向的新因子挖掘
   - 空白方向 → 新假设派生（如"波动率类没人测过，去挖"）
```

### 4.3 组合→全局反馈（季频）

```
每季度：
1. 审计组合整体表现（Sharpe/MaxDD/换手率）
2. 检查风格间相关性矩阵
3. 如果组合Sharpe停滞 → 说明当前风格池已饱和，需要新方向
4. 如果某类风格连续2季亏钱 → 该类因子全线归档
5. 生成下季度研究方向备忘录 → 指导F1经济假设线
```

## §5 组合层：全量融合

### 5.1 融合规则

```
每日收盘后：
1. Regime门判定（HS300>MA200 且 20日vol<25%）
2. 若ON：
   a. 计算所有存活风格当日信号
   b. 每只标的权重 = Σ(选中它的风格数) / 总存活风格数 × 域分配
   c. ETF域45% + 股票域55%（Regime=ON时）
   d. 单标的上限：ETF≤5%，股票≤2%
   e. 超限缩回现金
3. 若OFF：全部清仓停泊逆回购
```

### 5.2 域分配（股票为主）

| Regime | ETF | 股票 | 现金 |
|---|---|---|---|
| ON | 35% | 55% | 10% |
| OFF | 0% | 0% | 100% |

### 5.3 融合权重动态调整

- **不优化权重**（等权=防过拟合）
- 但每月审计自动淘汰连续3个月Sharpe<0的风格
- 淘汰后剩余风格自动等权重新分配
- 这就是"动态权重"——不需要显式优化

| 6 | 生成下季度研究方向 | 备忘录入research/ |
| 7 | 检查锁盒越权 | 审计报告 |
| 8 | 重算skill_line_v2判线 | 新判线数值 |

**全部自动化，CEO零动作。异常才告警。**

| 因子库规模 | 7000+个 |
| 组合OOS Sharpe | ≥ 1.0 |

### 8.2 12个月目标

| 指标 | 目标 |
|---|---|
| 存活风格数 | 100-150个 |
| 因子库规模 | 10000+个 |
| 组合OOS Sharpe | ≥ 1.2 |
| 组合MaxDD | ≤ 12% |
| 纸盘6个月Sharpe | ≥ 0.8 |

### 8.3 失败信号

- 6个月后组合Sharpe < 0.5：说明因子方向全错，需要换研究方向
- 风格数停在30个不增长：说明门禁太严或因子挖掘方向枯竭
- 风格间相关>0.5：说明都是同一个信号在重复，分散无效
