## 2. 踩到的两处空转（卡 E507）

1. **票面 JSON 顶层没有 `order` 键**（名单在 `ticket.order`）：第一版腿取到空列表，
   一个 symbol 都没检查，却打印 PASS。
2. **`startswith("| SYM |")` 在全页匹配**：ORDER 页第一张同形状表是权重表，即便取到 symbol，
   也会拿权重列去比溢价。

修法：腿先断言 `N>0`；只在本节内匹配行；读数三方对照（生产者面 → 票面 JSON → 页面），
不信任何单独一方。四条反证（抹分母 / 抹票面 premium 块 / 改一个溢价 / 删分位面）全部转红。
