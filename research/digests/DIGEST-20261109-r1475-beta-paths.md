# DIGEST r1475 bm-c — 那把量额度的尺子，自己在抖 10pp

**问题**：r1473 把额度拆到 `window × universe` 的 2×2 上，量到「短窗签到 0.393073、全窗
签到 0.460253」，差 6.72pp（￥67,180）。收尾句留了一个未答的问题：这 306 根 bar 的 β，
是**这一段日历的偶然**（相位），还是**这本书真的移动了**（水平位移）？如果是后者，额度就该
跟着短窗走；如果是前者，短窗只是运气。

**做法**（`scripts/etf_book_beta_paths.py`，selftest 22/22，`check` 由自身路径重算）：
1. **先量噪声**：对成对的（书、市场）日收益做块自助 500 次（块长 20 = 一个调仓周期），
   每次重估一个 306-bar β → 得到「同一本书跑在同一个世界的另一段路上，读数会摆多少」。
2. **再扫路径**：把同一条规则的 306-bar 窗口沿历史平移（步长 20 bar，68 个窗口），
   得到 β 的分布与趋势 t。
3. **判据机械**：差 < 2×噪声 sd → `UNDECIDABLE`（不是「差不多」）；在尾部（>P90 或 <P10）
   或有显著漂移 → `LEVEL_SHIFT`；其余 `PHASE_ONLY`。三个判决都可能，`UNDECIDABLE` 是真答案。

**读数**（证据截止 2026-11-06，1657 对 bar，分级池 1279 只）：

| 读数 | 值 |
|---|---|
| 今天的 306-bar β | **0.5171**（k = 0.3868） |
| 全窗 β（1657 bar） | **0.4594**（k = 0.4353） |
| 两窗差 | **0.0577** = 4.86pp of k = ￥48,553 / 百万 |
| 自助噪声 sd（β） | **0.1394** → 差只有 **0.41 sd** |
| 判决 | **UNDECIDABLE**（线是 2 sd） |
| 尺子自身的 k 噪声（delta 法） | **10.4pp** |
| 今天读数在历史 68 个窗口里的位置 | P70.6（不在尾部） |
| 路径分布 | p10..p90 = **0.170 .. 0.698**，sd 0.207 |
| **同一个规则滑窗，k 走多远** | **0.287 .. 1.000（p10..p90 跨 71.2pp）**，中位 0.686 |
| 路径趋势 | 斜率 -0.00416，**t = -3.53**（显著） |

**读法**：
- desk 前三个轮次争的「短窗还是全窗」= **4.9pp**；而把同一个规则的窗口挪一挪，k 自己就走
  **71pp**（0.287 到 1.000）。`window_choice_is_the_small_term = true`。
- 尺子的噪声（10.4pp）比被争的差（4.9pp）大两倍：继续在窗口上做算术，是在打印机的最后
  一位上做决定。
- 趋势 t=-3.53 与「判不了」**不矛盾**：漂移说的是「读数在动」，不是「这一对窗口能分开」。
  两个问题两把尺子。面上把这两句分开印，避免一个词盖住另一个。

**下轮指针**：真正的议题不是「选哪个窗口」，是**签发窗口必须固定并预注册**——把「额度用
哪一个窗口、什么时候允许换、换了要重跑什么」写成一条可判的规则，再看它能不能让票面以后
不需要每 bar 人工裁（r1472 的 90.4% 事件）。另：路径在 2020-2022 段读到 0.17~0.29 的 β
（k 打到 1.0 封顶），说明「去杠杆只降不升」的封顶在某些年代是有效约束，值得单列一节。
