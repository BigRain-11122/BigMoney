# DIGEST 2026-11-09 — r1465 bm-c: 「今天的价差」与「价差的水平」

**问题**：r1464 把同一指数在 12 个代码之间的溢价差定价了（换票今天多买 CNY 9,762），但没有一面回答：这个价差明天还在吗？长期收的价差＝换票是一次性修正；今天才有的价差＝换票是每日决策，且今天省下的钱大部分是一次性的，不是收益率。

**量法陷阱（本批核心）**：同一指数的两只 ETF，收盘价之比 `g_t = ln(P_A/P_B)` 的**水平不是溢价差**——两只基金每份净值基准不同（159501 vs 159513 差 10.68pp；513100 vs 159513 差 17.27pp），那是一个任意常数。只有 `g` 的变化才是溢价差的变化。

**正法**：用唯一一天两个溢价都能观测的盘口（当日前向溢价面）把常数钉住：

```
offset = g_last - gap_today
rec_t  = g_t - offset          # rec_last == gap_today 恒等（identity 腿）
```

「基准不动」这个假设要**被测**：分红/拆分/溢价错位在比价上表现为一天的阶跃，按日差 3σ 打折标并逐日公布。

**钱的分法**：今天 CNY 9,762 的换票收益里，按历史平均价差只有 **CNY 1,540** 是「以后还能再拿到」的，**CNY 8,222 是今天这一次**。

**三条可复用律**：
1. 两序列各带任意常数时，水平不可比——先找一天两个水平都能观测的时刻钉偏移，再回溯比较；直接读比价水平会把「净值基准差」印成「溢价」。
2. 假设要变成检测项：把「常数不变」可能失效的形状（阶跃）做成检测器并逐日列出，别写在脚注里。
3. 一次性与可重复必须分成两个数（9,762 vs 1,540）；只报一个，读者一定做错决定。
