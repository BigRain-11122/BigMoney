# 被拒绝的规则留下的不是结论，是一把尺子（r1387 bm-c，2026-11-07）

> 一句话：r1386 判负了一条择时规则，真正有价值的是它输给的那个零假设——同在场份额、只换相位，
> 随机敞口在分散篮子上亏 4.11%/年。这个门槛此前没有任何面发布，于是每个「书要不要有时不在场」
> 的问题都要重推一次尺子。本轮把零假设做成**生产书上的刻度盘**：0.95/0.85/0.70/0.50/0.30 敞口份额，
> 各 200 个随机掩码，输出「一条规则必须先赚到多少 pp/年，才被允许与持有比较」。
> **生产书的答案是 +0.6 / +2.0 / +3.7 / +5.9 / +8.4 pp/年，而且几乎正好等于按时间线性摊薄
> ——这本书没有「错过最好的几天就没了」的聚簇。**

## 一、为什么这一轮是它

- 供给池连续多轮 `ready 0 < floor 3`；上一轮（r1386）按常设律去量了一个从没烧过的候选家族，
  判决 `REFUSE_AS_CANDIDATE`。
- 拒绝本身不产生任何可复用资产，除非把**判据**留下。那条零假设（同份额随机相位）是下一次
  任何「择时/离场/闸门」提案的第一道尺子，而全树唯一提过它的地方是 zoo90 自己的产物文件。
- 因此本轮不新造闸、也不新测候选，而是把那个零假设置于**在役的那本书**上（E380 明确说过：
  离场税不是普适常数），使它成为公开刻度盘。

## 二、量什么（构造冻结在脚本常量里）

| 项 | 值 |
|---|---|
| 书 | 去债复合分数（equity+commodity+convertible）、top5、20 bar 调仓、10bp/边、8% 波动目标——**与发布件同一次调用**（`R.open_to_open_equity`，非重实现） |
| 序列 | 1656 个日收益（2020-01-02..2026-11-06），CAGR 11.96% |
| 掩码 | 两态马尔可夫链，均值 run 20 bar（一个调仓周期），请求份额 0.95/0.85/0.70/0.50/0.30 |
| 抽取 | 每档 200 次，seed=20261107（可逐字节复现） |
| 读数 | 每个掩码的 CAGR − 从不离场的 CAGR；hurdle = −均值（正数=必须赚到的量） |

## 三、读数

| 敞口份额 | 实测实现份额 | hurdle（pp/年） | 线性预测（pp/年） | 最差一次抽取 |
|---|---|---|---|---|
| 0.95 | 0.951 | **+0.64** | +0.59 | −2.8% |
| 0.85 | 0.852 | **+1.96** | +1.78 | −5.8% |
| 0.70 | 0.703 | **+3.70** | +3.55 | −9.1% |
| 0.50 | 0.507 | **+5.93** | +5.90 | −12.1% |
| 0.30 | 0.302 | **+8.39** | +8.35 | −13.0% |

三条判读：

1. **这本书的离场税是线性的**（实测略高于线性，差距 0.05–0.18pp）。收益在时间上铺得均匀，
   没有任何「最好的 10 天」可被抓——所以任何择时规则在这本书上的对手不是波动，是整段漂移。
2. **与 zoo90 的分散篮子形状相反**：同一把尺子在那本书上读出 48.7% 敞口亏 4.11%/年，而线性预测
   只有 1.65%——那本书的收益是有聚簇的。**所以离场税不能跨帐簿借用**（E380 的定量落地）。
3. **对供给面的含义**：任何 MA/趋势类择时规则要通过 0.7 敞口档，先要赚到 3.7pp/年；而被判负的
   zoo90 构造是 −4.79pp。差距不是一个参数能补的，这也解释了为什么这一类规则在本仓反复判负。

## 四、对照臂（尺子的刻度，不是候选的证据）

- 面内 `control_arm`：把书的净值截到发布件的 `as_of`（2026-10-23），用发布件的**同一口径**
  （`A.stats2` 的日历年 CAGR）重算，必须复现 `results/etf_nobond_vt.json` 的 `nobond_vt08=0.1149`
  ——实测 **0.1149**，容差 0.1pp。不复现即 `run` 返回 2、`--check` 判红：尺子量到另一本书上时，
  它比没有更糟。
- 自检里的刻度腿：常数漂移序列上实测税必须落在 (1−share)×CAGR 附近（L3）、份额 1.0 必须逐次
  恰好 0（L1）、掩码必须实现它被请求的份额（L2）、平坦序列税为 0 但**不许读成未测**（L4）。

## 五、两枚坑（本轮实锚）

1. **净值 LEVELS 当收益掩码 ⇒ base CAGR 炸成 inf**（首跑：hurdle 全 +nan、prop +inf、
   `RuntimeWarning: overflow in reduce`）。`open_to_open_equity` 交回的是净值曲线；掩码复合在
   level 上不是测量。正法=入口 `MAX_BAR_RET=0.35` 直接返回「未测」+ 一条专钉腿（L10），
   而不是在下游让它变成 nan 后再靠人发现。
2. **对照臂必须用发布件的口径**：先用「日频复合×(252/n)」自算 CAGR，截到发布 cutoff 读出 12.00%，
   与发布的 11.49% 差 0.5pp，看起来像「书变了」；换成发布件自己的 `stats2`（日历年口径）后
   是 0.1149 的逐位一致。**复现一个数字=复现它的口径**，不是复现一个接近的数字。

## 六、诚实清单

- 这是一把尺子，不是候选：没有预注册、没有判定、不记账、不进试验台账。
- 掩码不收自己的换手成本（真实规则要付自己的切换成本），文中已注明；所以 hurdle 是**下限**。
- 面板是今天上市的 ETF 集合，幸存者偏差照旧，本面不改变它。
- 连续持有期的「聚簇」结论只对这本书的样本窗成立；换窗口要重跑，不许外推。
