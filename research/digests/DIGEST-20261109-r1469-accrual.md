# r1469 — 账本只在「执行」那一行记账，等于假定两次决策之间这本书不赚不亏

**问题。** r1468 把执行后的账写成一行（按决策 bar，append-only）。但那一行**只在换票执行时被写**：
11-06 之后的每一个交易日，持仓的市值在变、60 万现金在挣利息，账本里没有任何一行记这件事。
于是「下一张单从账本起算」里的「账本」，实际是「上一次执行时的账」——两个决策 bar 之间的盈亏
从未落笔，下一张单只能站在一个过期快照上。

**只动两件事，其余都是噪声。** 两次决策之间能让这本书变化的只有两条：

1. **持仓的收盘价**（手数不变——没有新决策就没有交易）；
2. **现金腿**（票面写明现金放 1 日回购，所以周五→周一挣的是三天，不是一天）。

两件事都要落成一行，其余字段（k、权重、目标）在这一层是派生量，不让它们参与记账。

**今天能出的数（面板最新 bar 与执行 bar 同日，所以新账只能记 0 行）。**

为证明引擎在真面板上走得通，把它**反向**跑在账本自己那批手数上（从 2026-10-09 到执行 bar，20 个 bar）：

| 项 | 读数 |
|---|---|
| 腿市值 | ￥417,445 → ￥392,401（**-6.00%**） |
| 现金利息（20 bar，1.185% 档） | **￥563.81** |
| 停牌/缺价 bar 数 | 0 |
| 缺回购报价 bar 数 | 0 |
| **恒等腿** | 最后一行算出的腿市值与账本行自己记的差 **￥0.00** ✅ |

恒等腿是这段回放唯一有价值的部分：同一批手数、同一批收盘价，引擎必须把账本已经写下的钱
算回来（￥392,400.9 逐分对齐）。

**持仓现金的日息（真数，不依赖新 bar）：**

- 最近报价 1.185%（2026-11-06）→ 现金 ￥607,599 每个交易日挣 **￥19.73**，跨周末一格 **￥59.18**。
- 不记这一行，现金就只是躺在账上不会变的一个数字；记了才知道「60% 现金」不是零收益。

**第二个发现：票面背后还有一本账。** 造这张单的脚本自己维护一本归一化账
（`results/etf_book_order/ledger.jsonl`，最新 bar 2026-11-06）：k=**0.4603**；执行账 k=**0.3924**。
差 **6.79pp = ￥67,852 名义暴露**。两本账各自都对——引擎账是**裁剪前**的策略暴露，执行账是
额度允许的暴露——但「下一张单从账本起算」若不指名哪一本，同一句话可以差 6.8 万。

**自踩一枚。** 首版回放把 `cum_ret` 也印出来（+64.67%），因为 `prev_nav` 在合成行里退化成
「只有现金」；起点 nav 在回放里本来就不可知（现金是执行日那天的现金），所以任何累计收益都是
伪数。正法：`accrue_rows` 在起点 nav 未知时令首行 `ret=None`（不是拿现金当分母），并把 `cum_ret`
从回放输出里删掉——r1230/r1316 族「空测量写成好读数」的又一现。

**状态语义。**

- `NO_NEW_BAR`：执行 bar == 面板最新 bar（今天就是这种），**不是**「算不出来」，是那天之后还没有收盘价。
- `ACCRUED`：每 bar 一行，重跑 kept（幂等）。
- 缺回购报价：按零计息并计入 `rf_missing_bars`；缺价：carry 上一收盘并点名，不推价不编价。
