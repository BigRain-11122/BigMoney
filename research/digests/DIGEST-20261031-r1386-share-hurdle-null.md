# 池饿六轮之后第一次见血：zoo90 鳄鱼定时器被拒，而拒它的那把尺子本身就是本轮产物（r1386 bm-c）

> 一句话：供给池空了六轮，每轮都补了一把闸；这一轮不再造闸，去量一个从没烧过的候选家族（zoo90_alligator_timing），用「同仓位份额、同持续性、只换相位」的循环移位零假设量它——**候选被拒（净超额 −4.79%/年、回撤反而更深 5.03pp、p=0.448），但拒绝的理由比候选本身值钱：在这块面板上，任何只在场 48.7% 时间的择时规则，先要填平 −4.11%/年 的「离场税」才有资格说话。**

## 一、为什么这一轮是它

- `Tools/fill_ladder.py --dry-run` 连续六轮 `compatible_ready=0 floor=3`，唯一被拦的行是已判负关闭的 INNOVATION-QUOTA-SLOT-3。前六轮（r1380-r1385）交出去的都是工程闸：标记闸、控制字符闸、消费者见证腿——没有一行新增候选。
- 常设律（TRIAL_LABOR_LAW §1/S3 试用劳动力常设线）对「板空/池饿」的规定是**起草或续跑下一波候选批**，不是再补机制。
- `results/_r258bmc_zoo_eligibility_scan.json` 的 A 层合格排序里，PRIMARY（zoo84 拥挤投票）已在 SLOT-9 消费，**BACKUP = zoo90_alligator_timing** 全树只有两处提及（该扫描件本身 + 一条判决摘要），从未烧过。

## 三、读数

| 口径 | 择时净 | 买入持有 | 差 |
|---|---|---|---|
| 篮子年化 | −1.40% | +3.39% | **−4.79pp** |
| 最大回撤 | −41.98% | −36.95% | **更深 5.03pp** |
| 夏普 | −0.048 | 0.274 | — |

- 在场份额 48.7%，118 次交易 ≈ 18 次/年，成本拖累 2.35%/年。
- 零假设分布：均值 **−4.11%/年**、sd 3.65%、**p=0.448**。也就是说——**同一份额的随机择时平均亏 4.11%，这条规则亏 4.79%，它连「同样在场时间的随机相位」都没赢**。
- 单券交叉验证（同为 1,652 bar）读数方向不同，值得记住：
  - `510300`：敞口 37.8%，年化 −1.94% vs −0.31%（−1.63pp），但**回撤 −45.1% → −29.9%（+15.2pp）**；
  - `510050`：敞口 35.6%，−1.20% vs −1.12%（−0.08pp），回撤 −44.3% → −24.2%（**+20.1pp**）；
  - 即：**在单一宽基上它是「几乎零收益代价的减回撤器」，在分散篮子上是纯粹的拖累**——分散化已经把它想做的事做完了。这条差别是本轮最可复用的判断：MA 类择时不要在一个已经分散化的帐簿上再测一遍。

## 四、判决与下一步

- `verdict_block.verdict = REFUSE_AS_CANDIDATE`，四个条件逐项打印（净超额正 / 赢零假设 / 回撤改善 / bar 数达标），失败三项。**拒绝不是结论**：它只说明这个构造不值得花一份冻结预注册和一次全量判决。
- 供给面因此仍然 `0<3`。下一轮该换的不是「再测一个 MA 变体」（本节单券读数说明在这条轴上再挖是重复），而是去 zoo 表里挑一个**机制上不依赖在场时间**的家族（横截面/事件型），或者反过来：把「离场税」当作**帐簿层规则**来评估（要不要给生产书上 8% 波动目标之外的择时闸），那才是这些数字真正指向的地方。

## 五、复现

```
python scripts/zoo90_alligator_probe.py selftest   # 13/13 PASS
python scripts/zoo90_alligator_probe.py run        # ~60s，落 results/supply_berth/zoo90_alligator_probe.json
```

自检里有一条腿专门钉住本轮的方法论：**「买入持有」在零假设下必须读出恰好 0 超额且 p>0.05**（全 1 敞口的夹具），另一条钉住「完全错位的规则必须被自己的相位零假设抓到」。这两条腿是尺子的刻度，不是候选的证据。

## 六、诚实清单

- 探针只测一个构造、一组参数，**没有网格**——正读数只能买一张冻结预注册票，不能当收益宣称；
- 等权篮子按日零成本再平衡，收费的只有择时自己的换手（篮子是尺子，不是候选）；
- 组合成分用的是今天的面板回溯历史，幸存者偏差照旧；
- 零假设的 200 次给了 1/201 的 p 地板，本轮 p=0.448 离地板很远，不存在「样本不够所以测不出」的借口。
