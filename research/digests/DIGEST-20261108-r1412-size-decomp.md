# DIGEST-20261108-r1412 · 等权池的溢价是规模阶梯（bm-c）

**问题。** r1411 的对照腿（等权全池 +10.11%/yr vs 510300 +3.35%）被当成主问题，判负在日历相位上。
但它没回答：等权一个 5,199 只的池本身就是规模押注。溢价来自参与度、规模因子、还是「离开市值权重」
这一机械动作？

**做法**（零新数据，复用 data/astock_daily 的 outstanding_share 列算 cap=close×股本）：
同一批队列（60bar 非重叠 / 次日开盘进出 / 13.041bp 每边），只换加权与分桶：
EW_ALL、CW_ALL、按当日市值排序等名数三分位（各桶等权）、小三分位市值加权。12 个相位偏移做误差条。

**读数**（5,199 只 / 1,658 bar / 2020-01-02..2026-11-06 / 26 队列）：

- EW_ALL **+10.11%**（精确复现 r1411 的 10.11）
- CW_ALL **+2.01%**，回撤 −42.63% ≈ 就是指数（510300 同期 +3.35% / −45.10%）
- 小 / 中 / 大三分位 **+14.98% / +9.97% / +0.55%**，回撤 −26.5% / −31.5% / −45.0%
- 小三分位市值加权 +14.79% ≈ 小三分位等权 → 规模溢价不是权重错配，是小票本身
- 等权溢价 EW−CW = **8.10pp**；规模差 小−大 = **14.43pp**
- 相位：EW_ALL 6.08..10.82（spread 4.74pp，r1411 判负来源）；**规模差 12 相位全正，最低 12.31pp**

**判决**：SIZE_IS_THE_PREMIUM（不是 candidate，是归因）。等权溢价的三分之二以上是规模阶梯；
大三分位基本等于指数，中小两端承担全部 8pp。
