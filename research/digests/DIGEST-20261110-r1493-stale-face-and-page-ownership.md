# 同一个数，两张纸：一个人没再算过它（r1493 bm-c）

**为什么写这一条**：11-10 凌晨的 smoke 里有一条红——「a gate that flips on the decision phase
is not a gate」报 `floor=0 top-2 drifted from the published verdict`。两个文件都写着同一本书的
同一天：`results/etf_book_scale_floor.json` 说最大两年占年度之和 **71.08%**，
`results/etf_book_year_gate/YEAR-GATE.json` 说 **70.67%**。两个数都不错，错的是**没有人再算过
前一个**——它写于 11-08，判它的门 11-10 重建，面板多了两根 bar。

## 三句话

1. **「两个已发布数字对不上」是线索，不是取舍。** 先问它们算在哪张面板上。这里差的一格是
   某一年的收益（最差年 1.898 → 2.369），不是公式差异：重跑 `etf_book_scale_floor.py` 之后
   71.08% 直接变成 70.67%，与门逐位一致。**面的值没错，面的时机错了。**
2. **闸必须长在「谁判它」的那一侧。** 这个面是**由**年门（`admission_block` 被 import）判的，
   却没有任何链腿在门重建后叫它重算——一张一次性写出的面，读的人只会越来越多。修法不是在
   门里加一句注释，而是把**判它的那条恒等式**做成廉价 check 进 S6 链：floor=0 的臂必须复现
   被采纳书的判决与 top-2 占比，面自己还必须与自己的 `baseline_floor0` 块一致。rc3 = 漂了，
   去重跑（跑的是一次面板构建，按设计留在链外）。
3. **「一致」不等于「同一天」。** 只比数字，会漏掉"一根 bar 前、四舍五入后仍相等"的陈旧件，
   所以 check 同时比面板事实：面带 `evidence_cutoff`（本轮新加——此前这张面只能靠文件 mtime
   判断新旧，而 mtime 恰恰是上一条坑里骗过闸的东西）、去债宇宙数、翻转修复笔数，三样都要等于
   门自报的那三样。**同意与同日是两件事。**

## 同族的第二条：腿要求一个「今天的页」

八条烟测腿把 CEO 一页纸（`docs/live_book/LIVE-BOOK-*.md`，写者=bm-a）与本地重新推导的面逐行
对比，在 bm-c 上必然九红。里面藏着两个不同的问题：

- **页名是按写者那次运行的墙钟起的**，所以 `LIVE-BOOK-<今天>.md` 在写者当天第一次运行之前
  根本不存在——「今天的页不在」不是缺节，是没人跑过。腿改成读**盘上最新的一页**，由该页自己
  的 JSON 说它定价在哪根 bar。
- **别人的页比我的面旧**，只有在本机能写这张页时才算缺陷。腿改为先问写者自己的守卫
  （`writer_allowed(machine_id())`，不另写第二份规则）：本机可写 → 照旧判红；本机不可写 →
  红项收进一行注记，**并把页码、面价、属主、属主心跳时长印出来**（例：
  `page LIVE-BOOK-20261109.md priced 2026-11-06, face priced 2026-11-09 -- page owned by bm-a
  (this host cannot write it; owner heartbeat 5.3 h)`）。声明的沉默才算接管，心跳旧不算。

**反证**：把 `may_write` 强制为真（假装本机是写者），八条腿立刻恢复判红
（`the page prints no account block for bar 2026-11-09` / `9 of the section's lines never reach
the page`）——放宽的只是「别人家的事」，不是断言本身。

## 可复用清单

- 一个面**被读**、**消费者自检全绿**，仍可能是**无人生产**的旧面（r1471 族的下层）：问它有没有
  写者，问写者会不会被上游的变动叫醒。
- 「与判它的门一致」应当是一个**链腿**，不是一条约定；判据 import 而非复写。
- 任何「新旧」判断禁看 mtime（checkout 会重写它）；用**内容级证据**（cutoff / 宇宙数 / 拷贝字段）。
- 一条腿要求「今天的文件」时，先问这个文件是**按谁的时间**命名的；墙钟命名的产物在别人手里。
- 「我核实不了」与「它是错的」必须分成两句，且第一句要把责任人名字印出来。
