# DIGEST 2026-11-08 r1428 (bm-c) — 拒到什么时候才翻身？

## 问题

r1427 的收尾句是「拒的是书不是尺子，动作是重切书」，但供给地板（`ready 0 < floor 3`）已经红了 35 轮，
「前置的书」是一句观察，不是一个可排产的计划。三个动作（换尺子 / 重做书 / 等时间）从来没被分开算过：
**这张闸什么时候能对现有的书说 ADMIT？**

## 做法（不重定价，只在年度表上续写）

`etf_book_admission_eta.py` 复用已发布引擎（`etf_book_scale_floor.nobond_universe` +
`etf_robust_pf.open_to_open_equity`）把三本书的 5 个相位重新跑一遍，只取年度表，然后**按声明费率续写 n 年**
（`median` = 本书自己的中位年 / `worst_full` / `zero`），每加一年重算 Y1–Y4 与两把认证尺子，报最小 n。
ETA 一律取**最差相位**（5 个网格起点里最慢的那个）。身份腿：三本书相位 0 的 top2 与 r1427 面
`max|d| = 0.0`，漂移即 rc3 不出文件。

## 三条可用结论

1. **两把被认证的尺子给出的日期相反：0 年 vs 10 年。** r1426 认证的是「各自判得了自己」，
   不是「对同一本书说同一句话」。所以「换尺子」不是「把假尺换成真尺」，而是**决定这张闸问哪一个问题**
   （分散度 → 今天就过；前置度 → 还要 10 年），必须点名其一，不能并列。
2. **有的红没有日期。** Y3（最差年）路径无关：历史里那个 -7.6% / -18.7% 的年永远不会因为再攒年份而消失。
   smallcap_book 的中位年 +35.7% 也救不了它 → ETA = None。凡「等一等就好」的判断，先问这条线是不是只取决于
   新增数据。
3. **零收益年救不了 Y4。** 分子分母同时不动，份额分毫不变（面里带 trace 腿）。「再混几年摊薄」只在
   新增年**有收益**时成立，摊薄速度由本书 median 决定。

## 没有做的事（诚实边界）

- 没有改任何生产判据：换尺子是采用规则变更，要它自己的一轮采用案（r1426 已定这条边界）。
- 续写是**算术续写**，不是预测：费率在面里逐条印出，读者可换成自己的假设重算。
- 没有触发新回测、没有新预注册、没有触碰 engine/exit_rules。
