## §1 链条身份与机制主张

- 链名：**ETF-OPS-BP1（宽基回调低吸链）**——O-1524「该买就买、该止盈就止盈」的宽基机械化表达。
- α 机制段（PREREG_TEMPLATE §1 四选一·s2 逐字入 prereg）：**行为偏差**——A 股散户追涨杀跌+处置效应（上涨捂不住、回调恐慌割）：上行趋势内的宽基回调触发集中恐慌抛售，低吸方在局部低点承接恐慌盘获得补偿；分层止盈=把「该止盈就止盈」纪律化，对抗盈利仓处置效应。**谁付钱**：趋势内恐慌止损盘在局部低点付出价差，追涨盘在反弹后为流动性付费。
- 国内性主张（O-1522 方向盘）：「趋势不破回调低吸」= A 股原生大众打法（非国外动量/均值回归学术框架的原样移植）；T-89 分段先验=宽基 chop 占比高（510300 实勘 71%），低吸型入场天然适配震荡主导形态——趋势上窗吃鱼身、chop 窗吃回归。

## §2 链条规则（全数值·零酌情断点·每员独立实例）

数据面：每员 qfq 全史日线（sh|sz 前缀面，深度见 s0 §1 表；G-ANCHOR-FACE 四元组在 s2 prereg 逐锚落格）。全部信号用**收盘价可算量**，披露时点=当日收盘后，执行=**T+1 次日开盘**（O-1132 保守代理），成本=V1 legacy 13bp×2 双轨（×2 压测面照跑）。

| 闸 | 规则（冻结数值） |
|---|---|
| 趋势门（该买才买的前提） | `close > MA200`（MA200=前 200 收盘均值，含当日） |
| 触发门（低吸扳机） | `close ≤ max(close, 20d) × (1 − D)`，D∈{4%, 5%}（网格参数） |
| 入场执行 | 双门同日满足 ⇒ T+1 开盘买入一单位（每员单仓位，禁加码金字塔） |
| 持有规则 | 持有期间 `close > MA200` 且未触止盈/止损 ⇒ 继续持有 |
| 止盈 TP1 | `close ≥ entry_cost × (1 + P1)` ⇒ T+1 开盘卖出 50%（P1 网格见 §4） |
| 止盈 TP2 | `close ≥ entry_cost × (1 + P2)` ⇒ T+1 开盘卖出剩余 100% |
| 硬止损 | `close ≤ entry_cost × 0.92`（−8%·公司正典 exit_rules 同门）⇒ T+1 开盘清仓 |
| 趋势止损 | `close < MA200` ⇒ T+1 开盘清仓 |
| 回合定义 | 一单位从入场到清仓=一个回合；半仓 TP1 后余仓继续按同一规则表运行 |
| 胜负判定 | 回合净盈亏（含双边成本）> 0 = 胜；TP1 后余仓以同 entry_cost 计价（成本基准=入场成交价加权） |
| 再入场 | 回合关闭后重新进入「等双门」状态（同日不重入） |

- 涨跌停诚实记账：入场日开盘一字涨停（开盘价=昨收×1.10/1.20 且 low=high=昨收×涨停价）=不可成交，回合标记 `blocked_entry` 如实计数不入胜率分母；出场日一字跌停同理 `blocked_exit` 次日续执行。
- 基金事件守卫（r239 冻结律照抄）：单日 `|r1| > 10.5%`（588000 用 20.5%）且当日宇宙中位 `|r1| < 3%` ⇒ 该员该日隔离不触发。
- 20cm 员（588000）：涨跌停阈按 20% 口径入上述记账规则，其余规则五员同构（两档=分层披露标签非参数分裂，防 N 膨胀；档差异参数化须待 T-106 控盘度量化面+新预注册）。

## §3 KPI 与判读面（胜率主判·三披露并行）

1. **主判=交易级胜率**：`wins / n_rounds`（盈利回合占比），逐员披露。
2. 盈亏比：`avg_win / avg_loss`；回合期望：`E[round_pnl]`（元/单位）。
3. **beat-passive**：同窗同员 buy-hold 总收益 vs 链条总收益（费用后）——胜率高≠跑赢被动（小赢大输陷阱），CN-CORE-SATELLITE 教训面（增量真实≠量级够）直引。
4. **null 对照（胜率主张的科学闸）**：K 同掩码随机入场 null（同出场纪律、同持有规则、随机等量触发日），seed 基先登记 `science_gates.SEED_REGISTRY`——胜率与回合期望须过 null 分布（p95 单侧），否则「低吸有技巧」不成立。
5. 政体条件化有效窗披露（O-1518 T1）：按 T-74 L2 路由态（GREEN/CHOP/ORANGE/RED）与 T-89 分段器（trend/chop 窗）分层披露胜率——禁全天候宣称，状态条件化如实入面。
6. 描述条款（批级披露不替代门）：年化>0、回撤≥−35%、OOS 双正、成本 ×2 稳定——BACKTEST_SCIENCE 宪法全适用。
