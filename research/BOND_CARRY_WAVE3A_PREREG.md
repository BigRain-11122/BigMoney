## §3 方法学【全冻结】

- **信号（零 α 参数·全机械规则）**：月度再平衡（面板最后交易日 t 收盘评估、t+1 开盘执行）：
  - **候选集**＝宇宙成员当日满足：≥60 bars 史＋trailing ADV20 名义额 ≥ **¥500,000**（容量地板=r206 探针测得层的下沿，非拟合 α）＋ **close < 100**（折价门＝pull-to-par 面）；
  - **C1 袖**＝候选集内 ADV20 排名 top-20（不足 20=自适应更少，逐月披露实数）；逐成员仓位=**min(¥10,000, 1%×ADV20)**（帽内可成交语义 R179）；1%×ADV20 < **¥2,500** → 该员**当月递延**（不入场、计入 deferrals 诚实面）；
  - **出场**（t+1 开盘执行）：(i) close ≥ 100 → 收敛止盈；(ii) 月度再平衡出候选集/top-20 → 轮出；(iii) 面终止（到期/退市）→ 末日收盘终值（结算不确定性如实披露）；(iv) 硬界三件套触发 → 全袖切、锁至**下一月度再平衡**（月内零再入场参数）。
  - **C2**＝同袖无折价门（top-20 by ADV20 不论价格，其余全同）；**C3**＝折价门无排名（全部 ADV20≥50 万折价成员、帽内等权）。
- **硬界三件套（D-20260925-01①·保护性判线非 α 面）**：(a) **分布界主责**：袖 20 日滚动累计收益 ≤ **-8%** → 切；(b) **max 硬界**：袖净值自高水位回撤 ≤ **-10%** → 立即切；单日袖 |r| ≥ **3%** → 危机日志（债券尺度危机阈；豁免语义=危机日单列披露，不豁免切仓）；(c) 极端日先验=§5-4。
- **null 对照（三铁律·随机基线）**：K=32 随机成员掩码袖——每 null k 用 `numpy.default_rng(66_000+k)` 于每月度再平衡从**当月候选集外全宇宙**（ADV20≥50 万、≥60 bars、**不问价格**）随机抽与 C1 当月实数同基数成员，同仓位帽规则＋同硬界＋同成本——隔离「折价门」选择 α 于「随便持有流动券」之外。被动基线＝510300 buy-and-hold（跨资产锚）＋**域内被动**（全部 ADV20≥50 万成员帽内等权月度再平衡，债券域 skill line 锚）。**seed 基 `bond_carry_w3a: 66_000` 已登记 `science_gates.SEED_REGISTRY`（r207·冻结前）**。
- **成本口径**：**V2**（ADV20 三层滑点＋1%ADV 帽，`knowledge/rules.py`）；**判 face=费率×2 恒开**（CostPatch 单源）；×3=披露列。逐月/逐年成本披露。停牌/零量 bar 不可成交不可估值。
- **账本**：跑后 `science_gates.append_ledger("BOND_CARRY_WAVE3A", 35, "results/bond_carry_w3a.json", evidence_cutoff="2026-09-24")`（dict schema 唯一禁手抄）。

1. **入场/笔数（帽内可成交口径）**：窗 ~23 年≈275 月度再平衡；折价门候选月占比预测 **55-85%**（2003-2016 折价纪元常满、2016-2020 近面值纪元稀疏）；C1 实际入场预测 **60-300 段**（宽带如实：深折价纪元成员月度轮换慢=长持仓段少入场、近面值纪元候选稀疏；月均持仓段时长不可预知＝预测带宽来源），≥30 F6 预测过线——帽内递延（1%×ADV20<2,500）在早年薄簿窗预测削峰 10-30%（R179 口径教训：预测按可成交非按候选）。
2. **方向/量级**：袖全窗年化 **+0.5%~+3.5%**（折价收敛捕获≈折价深度×收敛速率；2016-2020 近面值纪元贡献≈0 稀释）vs 域内被动 ≈0~+1%（债券价格面零 carry＋久期波动）；Sharpe 预测 0.2-0.6（低波动面分母小、但场外月稀释）——**过线与否=本批主裁决面，不预设立场**。
