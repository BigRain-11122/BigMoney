## 这一面回答什么

r2003 把 2026 的亏损拆成了 beta 与 alpha，留下一个没答的问题：全池 B-A 全窗 +0.2428%/期（t 3.46），前六年 +0.2657%（t 3.94），2026 只有 +0.0893%（t 0.29）。

单一个全池均值回答不了这个问题：**「只在小盘股里有效」和「均匀变弱一半」会印出同一个数**。
所以本轮把同一个池、同一个分数、同一批调仓日，按两个台面上真的会用来排序的变量各切三等分：

| 切法 | 变量 | 口径 |
| --- | --- | --- |
| liquidity | 20 日均成交额（百分位秩） | 层内配对差，**毛** |
| size | log(收盘价 × 流通股本)（百分位秩） | 层内配对差，**毛** |

层内差是毛口径：成本属于整个 B 臂（一只股票换层不是一笔交易），在层里收一层换手费等于凭空造一笔没人付的钱。全池净口径单独印在下面做跨面锚，两个口径不相减。

## 判词

```
liquidity = EDGE_CONCENTRATED_IN_LIQUIDITY_hi
size = EDGE_UNIFORM_SIZE
```

判据（本轮开始前冻结）：

- 最高层与最低层 t 都 ≥ 2.0 → EDGE_UNIFORM（不是小盘/高换手的假象）
- 只有最高层过 2.0 且 hi-lo 斜率 t ≥ 2.0 → EDGE_CONCENTRATED_IN_*_hi
- 只有最低层过且斜率为负 → EDGE_CONCENTRATED_IN_*_lo
- 两层都不过 → EDGE_NOT_SEPARABLE（全池 3.46 由中间层扛）
- 其余 → EDGE_WEAK

## 诚实边界

1. 三层是同一个池的子集，**不能相加**成全池数；全池数只认上面的净口径锚。
2. 层内是毛口径，没有计换层成本；一只股票从 lo 跳到 hi 在真实账本里不是交易。
3. 2026 只有到 2026-11-11 的残缺年，2026 的层均值只作诊断，不单独成为判词。
4. 流通股本用的是面板的 outstanding_share；停牌/送转造成的股本跳变未单独清洗。
5. 票池是现存标的（幸存者偏差），与父面同。
6. 本面是归因件，不是可交易策略：它回答「边在哪一层」，不回答「该买哪只」。
