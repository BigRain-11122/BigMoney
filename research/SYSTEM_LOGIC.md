> 本文件讲清楚整个系统每天/每周/每月到底在跑什么、数据怎么流、每一步怎么判断、错了怎么办。
> 不写代码，只写逻辑规则。与STRATEGY_SYSTEM_V4_EVOLUTION.md配套。

## 一、系统总览：四层流水线

```
数据层 → 因子层 → 策略层 → 组合层
  ↓         ↓         ↓         ↓
更新日线  计算因子IC  生成信号    融合持仓
  ↓         ↓         ↓         ↓
每日收盘  每周/每月   每日收盘    每日收盘
```

每层只做一件事，输入输出明确。层与层之间通过文件/数据库交接，不直接调用。

## 二、数据层：每天喂什么

### 2.1 每日收盘后（15:30触发）

**输入**：新浪/东财公开行情接口

**动作**：
1. 拉取48只ETF最新日线（OHLCV）
2. 拉取800只主板股票最新日线
3. 拉取沪深300指数日线
4. 拉取龙虎榜数据（17:00后披露）
5. 增量写入本地数据仓（不重下历史）

**输出**：
- `data/daily/etf_<code>.csv` 追加当日行
- `data/daily/stock_<code>.csv` 追加当日行
- `data/index/hs300.csv` 追加当日行
- `data/lhb/YYYYMMDD.csv` 当日龙虎榜

**完整性检查**：
- 每只标的必须有完整OHLCV五列，缺列=标记坏数据不使用
- 当日收盘价与前一日收盘价涨跌幅>20%（ETF>10%）=异常标记，人工复核
- 拉取失败的标的记入 `data/failed_daily.json`，次日重试，连续3天失败告警

### 2.2 Regime状态计算

**输入**：HS300日线

**逻辑**：
```
MA200 = HS300收盘价的200日简单移动平均
vol20 = HS300的20日已实现波动率（日收益率标准差×√252）

IF  HS300收盘价 > MA200  AND  vol20 < 0.25:
    regime = "ON"
ELSE:
    regime = "OFF"
```

**输出**：`data/regime_state.json`，字段 `{date, regime, hs300_close, ma200, vol20}`

**这个regime状态是全局开关**：regime=OFF时，后面所有层都不产生买入信号。

## 三、因子层：怎么从原始数据算出因子

### 3.1 因子是什么

因子 = 一个数学表达式，输入是OHLCV时序，输出是一个每日数值。

例：
- `mom_20 = close / close.shift(20) - 1` （20日动量）
- `zscore_5 = (close - close.rolling(5).mean()) / close.rolling(5).std()` （5日z-score）
- `vol_ratio = volume / volume.rolling(20).mean()` （量比）

### 3.2 因子IC怎么算（每周跑一次）

**输入**：所有因子的每日值 + 所有标的的未来N日收益率

**逻辑**：
```
对每个因子f：
  对每个交易日t：
    横截面取当日所有标的的因子值 rank
    横截面取当日所有标的的未来5日收益率 rank
    计算这两个rank序列的Spearman相关系数 = IC(t)
  
  汇总IC序列：
    IC_mean = 所有IC(t)的均值
    IC_std = 所有IC(t)的标准差
    IC_IR = IC_mean / IC_std
    |IC| = 绝对值
```

**筛选规则**：
```
IF  |IC_mean| > 0.03  AND  |IC_IR| > 0.3:
    因子 = "合格"，入候选因子库
ELSE:
    因子 = "不合格"，归档不删除
```

**为什么是0.03和0.3**：这是金融文献中短期因子的常见门槛。低于这个值说明因子没有预测力，不值得用。

### 3.3 因子相关性检查

新因子入库前，必须与现有所有因子算两两相关：
```
IF  max(新因子与现有所有因子的相关系数) > 0.7:
    新因子 = "冗余"，淘汰
ELSE:
    入库
```

**为什么0.7**：相关>0.7说明两个因子说的是同一件事，留一个就够。

### 3.4 因子来源（四条线持续产出）

| 线 | 怎么产出新因子 | 频率 |
|---|---|---|
| 经济假设 | 人/LLM提出一个假设（如"A股散户多所以短期反转强"），写成因子表达式 | 每周2-3个 |
| LLM磨坊 | qwen2.5:7b随机生成因子公式，盲测合格率>0.6后入库 | 每周5-10个 |
| 现有因子变异 | 对合格因子做数学变形（mom_20×vol_ratio, mom_5+mom_20等） | 每周10-20个 |
| 外部库实现 | Alpha158/GTJA/WQ里已有的因子表达式，逐个实现测试 | 每周1-2个 |

**所有新因子必须先过3.2的IC筛选和3.3的相关性检查才能入库。**

## 四、策略层：怎么从因子变成买卖信号

### 4.1 风格（策略）是什么

风格 = 一条买卖规则，输入是因子值，输出是每日持仓信号（0=不持仓，1=持仓）。

每个风格的结构固定为：
```
入场条件：某个因子值满足某个阈值
退出条件：满足以下任一——
  1. 因子值回到中性区
  2. 持仓天数达到上限
  3. 止损触发（亏X%）
```

**参数写死，不做网格搜索。** 阈值取文献/经验默认值。

### 4.2 初始风格清单（43个）

分四大类：

**趋势类**（赚趋势的钱）：
- 唐奇安突破、MA金叉、Supertrend、PSAR、横截面动量top
- 逻辑：价格沿趋势走，突破后继续走

**均值回归类**（赚超跌反弹的钱）：
- z-score反转、RSI超卖、布林下轨、缺口回补、放量反转
- 逻辑：短期跌太多会弹回来

**波动率类**（赚波动结构的钱）：
- 低波加权、波动率突破、波动收缩
- 逻辑：低波股长期跑赢高波股

**量价事件类**（赚事件驱动的钱）：
- 放量上涨、放量下跌反转、OBV、MFI、成交额突变
- 龙虎榜机构买入、北向流入、业绩超预期、利空消化
- 逻辑：成交量/事件包含信息，价格会反应

### 4.3 每个风格的回测逻辑

**输入**：一个风格的买卖规则 + 全历史日线数据

**逻辑**：
```
对每个交易日t：
  1. 用截止到t的数据计算当日所有标的的因子值
  2. 找出满足入场条件的标的
  3. 生成t+1的交易指令（次日开盘价成交）
  4. 检查持仓中的标的是否满足退出条件
  5. 记录当日持仓和收益

回测结束后输出：
  - 每日净值曲线
  - 总收益率、年化收益、Sharpe、MaxDD、胜率、交易次数
  - 逐笔交易记录
```

**关键防未来函数规则**：
- t日收盘后算因子值，t+1开盘才能买
- 不能用t+1的数据在t日做决策
- 所有rolling/shift操作必须shift(1)

### 4.4 成本怎么算

| 成本项 | ETF | 股票 |
|---|---|---|
| 佣金 | 双边万2.5，最低5元 | 双边万2.5，最低5元 |
| 印花税 | 无 | 卖出0.05% |
| 滑点 | 按成交额分层：≥5亿=2bp，1-5亿=5bp，<1亿=10bp | ≥10亿=3bp，3-10亿=6bp，<3亿=15bp |
| 涨跌停 | 涨停买不进，跌停卖不出（延迟到次日） | 同左，主板±10% |

### 4.5 风格怎么筛选进存活池

每个风格跑完回测后，过五道门禁：

```
G0 数据完整性：无缺失、无未来函数、成本计算正确
  ↓ 不过 = 代码bug，修复后重跑

G1' 判线：组合层Sharpe > skill_line_v2
  ↓ 不过 = 单策略不够强，但不淘汰，降级为候选

G1.5 bootstrap CI下界 > 0
  ↓ 不过 = 收益与噪音不可区分，淘汰

G2 PBO ≤ 0.25
  ↓ 不过 = 过拟合概率高，淘汰

G2.5 DSR ≥ 0.95（在组合层算，不在单策略层算）
  ↓ 不过 = 不注册为正式交易员，但保留在融合池
```

**重要**：单风格不需要全过G2.5。单风格只要CI下界>0就进融合池。DSR在组合层统一算。

## 五、组合层：怎么把所有风格融合成最终持仓

### 5.1 每日收盘后的融合逻辑

```
IF regime == "OFF":
    输出：全部空仓，资金停泊逆回购
    结束

IF regime == "ON":
    Step 1: 取出所有存活风格
    Step 2: 对每个风格，计算今日信号（哪些标的该买/该卖）
    Step 3: 对每只标的，统计有多少个风格选中它
    Step 4: 按选中次数分配权重：
            权重 = (选中次数 / 总风格数) × 域分配比例
    Step 5: 应用上限约束：
            ETF单只 ≤ 5%
            股票单只 ≤ 2%
            超限部分等比缩回到现金
    Step 6: 对比昨日持仓，生成今日调仓指令
```

### 5.2 域分配

```
regime=ON时：
  ETF域总仓 = 35%
  股票域总仓 = 55%
  现金 = 10%

regime=OFF时：
  全部 = 100%现金（逆回购）
```

### 5.3 融合的数学原理

假设N个风格，每个风格Sharpe均值μ，两两平均相关ρ：

```
组合Sharpe ≈ μ / √(1/N + ρ × (1 - 1/N))
```

- N=10, ρ=0.3 → 组合Sharpe ≈ μ/0.38 ≈ 2.6μ
- N=30, ρ=0.3 → 组合Sharpe ≈ μ/0.34 ≈ 2.9μ
- N=50, ρ=0.3 → 组合Sharpe ≈ μ/0.33 ≈ 3.0μ

**意思是**：即使每个单风格Sharpe只有0.4，融合30个后组合Sharpe≈1.16。这就是为什么不要求单风格强——分散本身创造alpha。

### 5.4 退出规则（每个持仓的退出条件）

每只持仓的退出条件（满足任一即卖）：
1. 持有天数达到该风格的上限（3-15天不等）
2. 触发止损：单票亏-5%（ETF）/ -7%（股票）
3. 该风格的因子信号反转（如z-score回到正数）
4. 组合层面：日亏>2%停开新仓，月亏>6%清仓休息

## 六、交叉迭代闭环：系统怎么自己进化

### 6.1 周频闭环（每周日跑）

```
1. 因子层：
   - 跑四条新因子生产线（经济假设/LLM磨坊/变异/外部库）
   - 新因子过IC筛选 + 相关性检查
   - 合格的入因子库

2. 策略层：
   - 用新因子生成新风格（因子+经济机制→买卖规则）
   - 新风格提交全量walk-forward回测
   - 跑完过门禁链，合格的入存活池

3. 组合层：
   - 把新存活风格加入融合池
   - 重新计算融合权重
```

### 6.2 月频闭环（每月1号跑）

```
1. 审计层：
   - 重算所有因子IC排名
   - 重算所有风格OOS表现
   - 淘汰连续3个月Sharpe<0的风格
   - 淘汰连续2季度|IC|<0.02的因子
   - 重算风格间相关矩阵

2. 反馈层：
   - 看哪类风格赚钱多 → 反馈给因子层："这个方向有效，深挖"
   - 看哪类风格亏钱多 → 反馈给因子层："这个方向无效，停挖"
   - 看哪类风格没人做 → 反馈给因子层："这个方向空白，去试"

3. 调整层：
   - 淘汰后的风格从融合池移除
   - 剩余风格自动等权重新融合
   - 生成月报：组合收益、风格表现、因子排名、下月计划
```

### 6.3 季频闭环（每季度首月跑）

```
1. 检查组合整体指标：
   - Sharpe是否在提升？
   - MaxDD是否可控？
   - 换手率是否合理？

2. 如果组合Sharpe连续2季不增长：
   - 说明当前风格池已饱和
   - 需要新方向：提出3-5个新研究假设
   - 派发给因子层F1线

3. 如果某类风格连续2季亏钱：
   - 该类因子全线归档
   - 从融合池移除
```

## 七、风控规则（硬约束，不可绕过）

| 规则 | 触发条件 | 动作 |
|---|---|---|
| 单票止损 | 个股亏-7% / ETF亏-5% | 次日开盘无条件卖 |
| 日止损 | 组合当日亏>2%（>2万/百万） | 当日不开新仓 |
| 月止损 | 组合当月亏>6%（>6万/百万） | 清仓，停到月底 |
| Regime门 | HS300<MA200或vol20>25% | 全部清仓停手 |
| 最大回撤 | 组合从高点回撤>15% | 仓位减半到50% |
| 单票上限 | 股票>2% / ETF>5% | 超限部分卖出 |
| 涨跌停 | 涨停买不进/跌停卖不出 | 买入放弃/卖出延迟 |
| 停牌 | 标的停牌 | 跳过，不操作 |

**以上规则没有例外。触发就执行，不抱幻想。**

## 九、失败处理

| 问题 | 处理 |
|---|---|
| 数据拉取失败 | 重试3次，失败记入failed_daily.json，次日补拉 |
| 因子计算报错 | 跳过该因子，记录错误日志，不影响其他因子 |
| 回测报错 | 记录错误，跳过该风格，不影响其他风格 |
| 风格回测全灭 | 不奇怪，记录死因，继续挖新的 |
| 组合连续亏钱 | 月止损触发→清仓休息→下月重新开始 |
| 系统宕机 | watchdog自动重启，恢复后从断点续跑 |
