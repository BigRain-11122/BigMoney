## What was run

- 12 cells (n_hold 12/3/5/8 x rebal 10/20/40), each on **every** decision origin inside one rebalance cycle -> 280 engine runs, 7 workers, cost 0.0010/side, buffer k=0.00, vol target 0.08.

## Why this is a decision and not a description

The production card and the executable ticket quote different widths off the same panel. A width change is only a decision if the cells it separates are separated by more than their own phase band; if they are not, the width choice is being read off one calendar and the honest statement is the band, not the point estimate.
