- 证据截止：2026-10-23；同一 burn（同 start / pick_n / 排除前缀 / eras，零新数据读取）
- 性质：探索面。无预注册、无判词、不入账本。**已发布的 iid 列（CHURNSE-20261021.json）不重写**，本件是新增臂。

## 一句话结论

**E89 的结论扛得住聚类：8 个「区间不过零」的格子全部活下来（2021_2023 的 1866-2327bp），两条时代差仍然过零——只是区间整体要放大约 31%。**

## 为什么必须做这一臂

E89 把每格换手 alpha 当成 27-29 个独立抽样（iid 刀切 + 百分位自助）。实际上这些是**同一个时代里、持仓互相重叠的月度决策**：相邻两次转仓共用 4/5 的票，同一段行情同进同出。iid 口径必然低估噪声——低估多少，E89 自己说不出来。

本件在**同一批数值**上加两臂：

- **块自助**：按决策日期排序，每 3 个连续转仓为一个块（一个季度），整块整块重采样 2000 次（seed=20261025）；
- **逐块刀切**：一次丢一整个块（不是丢单个转仓），闭式计算块级标准误；
- **对照**：iid 列在同一批数值上重算，保证两臂不漂移。

## 读数

规模：16 个水平格 + 8 个时代差格 = 24 格。

| 读法 | 结果 |
|---|---|
| 区间宽度比（块/iid） | 中位 **1.31×**，范围 0.82× - 1.38× |
| iid 下过零的格子 | 8 个 |
| 块聚类下仍过零的格子 | **8 个（零流失）** |
| 两条时代差 | 全部仍过零（2021_2023 差 +318.8bp，SE 901 → 1213；2024_now 差 -211.0bp，SE 167 → 187） |

- **聚簇膨胀只出现在 2021_2023**（x1.24 - x1.38）：那一段的转仓 alpha 高（1866-2327bp）且成串（同批票、同一段小盘行情），相邻转仓高度相关。
- **2024_now 几乎不膨胀**（x0.82 - x1.32，多数≈1.00）：那一段的 alpha 本身就接近零（28-92bp，mid15 甚至 -124bp），噪声已经盖住信号，没有可聚的簇。
- 单格最宽：mid15/unscreened 2021_2023 = 2185.4bp，iid SE 606 → 块 SE 839（x1.38）。
- 持币不动的结论没有变化：2024 年之后换手本身不值钱（水平格 28-92bp，mid15 为负），时代差 -211/-457bp 在两条口径下都过不了零。

## 机制读法

「块聚类把区间放大 31%，但仍然没有一个结论翻面」这件事本身就是信息：**E89 的 8 个存活格不是靠窄区间撑起来的**，它们是 2021_2023 那一段真实存在的换手红利；而 2024 年之后的换手红利在两种口径下都不存在。也就是说，换手 alpha 的故事是**一段历史**，不是当下可用的机制。

## 工程固化

1. 块长（3 转仓）与种子（20261025）必须写死进 spec，否则面孔不可复现；宽度比要逐格发布，不能只报中位数。
2. iid 列必须**在同一次运行里重算**（而不是从旧件读），否则两臂可能坐在不同数值上——本件两臂同源，`_jackknife_mean` 直接 import E89 的实现。
3. 块自助的每次抽样要按长度归一化（块长不均时直接求和会偏向长块）。
4. 参照点确认：unscreened/me/2021_2023 的 1866.5bp 与 E89 已发布值逐字一致（E92 已把该段的非整数比例打印屏掉，本件未改屏）。
