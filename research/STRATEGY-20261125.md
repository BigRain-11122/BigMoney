# 策略定义 · 2026-11-25（金融公司）

> 这份文件回答一个此前一直没被回答的问题：**这本书到底怎么下注。**
> 单点试验（趋势/普查/低波/转债…）全部服务于这本书的取舍；不为它们单独立账。

## 一、目标与硬约束

| 项 | 值 | 说明 |
|---|---|---|
| 本金 | 1,000,000 CNY（可扩 10M） | 扩容按第五条阶梯 |
| 目标年化 | 8%–12% | 不做「越高越好」，做「可重复」 |
| 波动目标 | 7%（上限 8%） | 三条腿的帽加起来约 6.5%：L1 5.8% + L2 3.5% 在 ρ=0.1 下合成 6.3%。写 9% 是自欺——要 9% 必须加第三条不相关腿。 |
| 回撤红线 | 10%（硬） | 触发即降档，见第四条 |
| 与 A 股相关性 | ≤0.35 | 这本书的用途是「不完全跟着 A 股」 |

## 二、三条腿与各自角色

| 腿 | 内容 | 角色 | 现役状态 |
|---|---|---|---|
| **L1 权益核心** | ETF 多因子复合书（6 因子秩打分，5 名等权，20 日调仓） | 收益主引擎 | 生产在役，k=0.435（434,724 元） |
| **L2 基差收成** | IC/IM 股指期货，按贴水分位定仓位（广时满、窄时零） | 与权益低相关的 carry | 研究已过判：置换 p=0.0000、bootstrap CI 不含零 |
| **L3 现金** | GC001 日滚 | 防守与再平衡弹药 | 565,276 元 |

**为什么是这三条**：L1 提供权益 beta 与风格超额；L2 赚的是套保方付的贴水（结构性付费方，不是预测）；L3 是前两条降档时的去处。其余候选（转债、A股横截面、趋势、曲线价差）**已判负或功效不足**，不进书。

## 三、风险预算（逐日可算）

- 组合波动目标 **9%**；按「风险贡献」而非「资金」分配：
  - L1 ≤ **4.6%**（k≤0.55 硬帽，当前 0.435 → 约 4.6%）
  - L2 ≤ **3.5%**（用 carry 序列实测波动折算名义）
  - L3 = 0
- L2 名义 ≤ **2.5×NAV**；保证金占用 ≤ **35% NAV**（留 65% 应对追加与机会）
- 相关性按实测；无实测时按 0.10 保守估计并标注

## 四、触发与降档（写死，不许临场改）

| 触发 | 动作 |
|---|---|
| 基差分位 ≥80（贴水最窄） | L2 该品种权重归零（规则内生） |
| 组合回撤 ≥6% | 全部腿降半（L1 k×0.5、L2 权重×0.5） |
| 组合回撤 ≥10% | L2 清零；L1 降到 k=0.25；只留现金 |
| 单腿 60 日累计 carry < −2pp | 该腿暂停，回研究面 |
| 年度检验：置换 p>0.05 或 bootstrap CI 含 0 | 该腿退役 |

## 五、扩容阶梯（按容量，不按信心）

| 规模 | 依据 |
|---|---|
| 1M → 3M | L1 容量已验证（流动性闸 2000 万/日）；L2 占 ADV 仍 <1% |
| 3M → 10M | L2 每腿 ≤1% ADV（IC 容量 17.5 亿、IM 25.8 亿）；L1 需重跑流动性闸 |
| >10M | 需新增低相关腿（期权/国债曲线），否则回撤会被单一 beta 主导 |

## 六、日历

- **每日**：纸盘 mark（L2）、触发检查、POLICY-TODAY 出指令
- **每周**：L2 权重重打（已内置周频）
- **每月 9 日**：重检 L1 的 k 与容量
- **每季**：失效检验（置换 + bootstrap）

## 七、什么情况下这本书被关掉

1. 12 个月滚动收益 < 3% 且回撤 > 8%（说明收益来源消失）；
2. 两条腿同时触发失效判据；
3. 容量不足以容纳当前规模（ADV 闸连续 10 日超限）。
