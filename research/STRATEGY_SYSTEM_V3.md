# research/STRATEGY_SYSTEM_V3.md — 3-15天短多域策略融合系统

> 核心思路：**不找单一圣杯策略，而是构建大量低相关简单风格，等权融合成组合。** 单策略Sharpe 0.3-0.5没关系，35+风格融合后分散掉特异性噪音，组合Sharpe自然上来。
> 与 BACKTEST_SCIENCE.md 关系：D1-D7判据层不变；本件改生产层——风格库怎么建、怎么融合、怎么验证。
> 覆盖域：沪深ETF（48只）+ 沪深A股主板股票（流动性池~800只）。

---

## §0 为什么是"多风格融合"而不是"精选4个"

| 单策略路线 | 多风格融合路线 |
|---|---|
| 每个策略要过DSR≥0.95才能用 | 单策略门槛降到Sharpe>0即纳入 |
| 48只ETF小横截面，单策略信号少 | 股票域800只×30风格=信号池大 |
| 风格间相关性不可控 | 主动选低相关风格=免费分散 |
| 一个风格失效=组合崩 | 一个风格失效=融合权重自动摊薄 |
| 过拟合风险集中 | 过拟合被等权平均稀释 |

**关键数学**：N个风格等权融合，各风格Sharpe均值μ、两两平均相关ρ，组合Sharpe≈μ/√(1/N + ρ(1-1/N))。ρ=0.3时，N=30融合后Sharpe≈μ/0.58≈1.7×单策略。单策略μ=0.5，融合后≈0.85。

## §1 系统架构

```
L1 数据层：ETF日线(48只) + A股主板日线(~800只流动性池) + HS300 regime
    ↓
L2 Regime门：MA200 + 波动率双闸，熊市空仓
    ↓
L3 风格层：35-50个独立信号风格（ETF域+股票域分开建池）
    │   每个风格=经济机制 + ≤2个固定参数
    │   风格间max|corr|<0.5（D6门槛）
    ↓
L4 融合层：等权融合所有存活风格，每日再平衡
    │   风格权重=1/N（等权，不优化）
    │   ETF域和股票域分开融合，再按45:35合并
    ↓
L5 执行层：T+1开盘 + 成本v2 + fill_guard
```

## §2 Regime门（L2）— 全系统统一

| 条件 | 动作 |
|---|---|
| HS300收盘 > MA200 且 20日已实现波动率 < 25% | Regime=ON：所有风格正常开仓 |
| 任一条件不满足 | Regime=OFF：禁止开新仓，已有持仓走完退出规则，新资金停泊逆回购 |

参数写死不优化。信号日T收盘计算，T+1生效。

### 3.3 风格相关性约束

- 建池时计算所有风格两两日收益相关矩阵
- max|corr| > 0.5的风格对，保留Sharpe较高者，淘汰另一个
- 目标：最终池内两两平均相关 < 0.35
- 每月科学审计重算相关矩阵，漂移>0.1触发风格调整

## §4 融合层（L4）

### 4.1 融合规则

```
每日收盘后：
1. Regime门判定 ON/OFF
2. 若ON：计算所有风格当日信号 → 每只标的持仓=所有选中它的风格权重之和
3. 每只标的权重 = (选中它的风格数) / (总风格数) × 域分配比例
4. ETF域总仓45%，股票域总仓35%（Regime=ON时），剩余20%现金
5. 单标的上限：ETF≤5%，股票≤2%
6. 超出上限的部分等比缩回到现金
```

### 4.2 为什么等权不优化

- 优化权重=过拟合（D1教训）
- 等权融合在金融文献中反复验证不输优化权重
- 风格数N=35+时，权重优化的估计噪声远大于其增益
- 每月审计自然淘汰失效风格=动态权重调整，不需要显式优化

### 4.3 域间分配

| Regime状态 | ETF域 | 股票域 | 现金/逆回购 |
|---|---|---|---|
| ON | 45% | 35% | 20% |
| OFF | 0% | 0% | 100% |

股票域分配低于ETF域原因：个股特异性风险大、成本高（印花税0.05%卖出）、流动性差。

## §6 验证协议

### 6.1 Walk-Forward切分

```
训练窗：252交易日（1年）——仅用于计算滚动统计量（MA/RSI/z-score等）
测试窗：21交易日（1月）
步长：3个月滚动
```

不做参数选择（参数写死），walk-forward检验的是regime适应性——牛熊震荡各阶段融合组合是否稳定。

### 6.2 通过条件（全部满足）

| # | 指标 | 阈值 |
|---|---|---|
| 1 | Walk-forward拼接OOS 组合Sharpe | ≥ 0.8 |
| 2 | 组合MaxDD | ≤ 15% |
| 3 | 年化收益 | > HS300同期 |
| 4 | DSR(组合月度收益) | ≥ 0.95 |
| 5 | Stationary bootstrap CI下界 | > 0 |
| 6 | 成本v2后 | 以上全部仍满足 |
| 7 | 年化换手率 | < 月度（成本占毛收益<30%） |
| 8 | 存活风格数 | ≥ 20个（<20说明融合池太薄） |

### 6.3 风格淘汰机制

- 每月科学审计：计算每个风格近6个月OOS Sharpe
- Sharpe < 0 且跑输被动基线的风格 → 下月淘汰
- 淘汰后从候选风格库补充新风格（保持池大小稳定）
- 风格替换率每月≤20%（防频繁切换）

## §7 诚实预期

### 7.1 目标区间

| 指标 | 预期 |
|---|---|
| 组合Sharpe | 0.8~1.3 |
| 年化收益 | 10%~18% |
| MaxDD | 10%~15% |
| 月交易次数 | ETF域10-20笔 + 股票域30-60笔 |
| 单风格Sharpe | 0.2~0.6（融合后提升至0.8+） |

### 7.2 失败信号

- 融合后Sharpe < 0.6：风格间相关性太高，分散无效
- 某风格持续Sharpe<0超3个月还不淘汰：融合层有bug
- Regime=OFF期间组合仍亏钱：现金腿设计错误

### 7.3 上线节奏

1. 回测验证（本系统walk-forward）
2. 纸盘6个月（G3前向锁盒）
3. 纸盘Sharpe≥0.7 → 实盘20%仓位
4. 实盘3个月稳定 → 加仓至50%
5. 不加杠杆、不做期权期货
