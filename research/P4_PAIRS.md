## §3 方法学【冻结】

- 价格=close 对数价。IS 公共交易日（双方均非 NaN）上 OLS：logA ~ const + β·logB → α̂,β̂（IS 冻结，全史不再估）；**残差价差 s_t = logA − (α̂+β̂·logB)** 全史展开（β 冻结=无未来）。
- ADF(1) 检验（扫描排序用）：Δe_t = γ·e_{t−1} + φ·Δe_{t−1} + const，t(γ̂)；EG 5% 临界 −3.37 仅作描述性标记，**入选只按 t 升序排名**（无 CV 硬门=零调参面）。
- z_t = (s_t − roll60 mean)/(roll60 std)，min_periods=60，仅用过去 60 日（因果）；**入场=cheap 腿 z_t ≤ −2.0；离场=z_t ≥ 0.0**（信号收盘算、次日开盘执行=引擎既有语义）；引擎默认退出机叠加生效（-8% 硬停/止盈梯队/时间衰减照常）。
- 选对：可评对（IS overlap≥500）按 t 升序贪心取**符号非重叠** K=8（不足 8 取尽；0 对→诚实判负收线）。
- 池化组合：8 对入场/离场信号 OR 合并（符号非重叠=零排队阻塞），params=**{"max_positions": 8}**，引擎原生 sizing（每仓=initial×10%，最大部署 80%——被动 100% 部署口径，vi 对比如实折价披露）。
- null 对照：**n=50 随机对同构**（seed 基 48_000=k∈[0,50)，已登记 SEED_REGISTRY "p4_pairs"）：每次=可评对列表 rng.permutation 洗牌→贪心非重叠取 8 对→**同 β 估计流程+同 z 规则+同池化结构+同 max_positions**（捕获「协整选择效应 vs 任意对」）；被动 EW48 buy-hold 信息列（p2_null_calibration passive_buyhold，截断面板）；锚定门=6 员 live.paper.anchor_gate 逐位（**任一 fail=批 VOID**）。
- 成本口径：**V1 legacy**（13bp×2 压测池化候选）+×2 成本生存力描述列；历史锚点复现恒 V1（双轨防漂移）。
- 账本：`science_gates.append_ledger("p4-pairs", 67, "shortline_p4_pairs.json", evidence_cutoff="2026-09-22")`（dict schema，prev=活链头 2791 禁手抄）。
