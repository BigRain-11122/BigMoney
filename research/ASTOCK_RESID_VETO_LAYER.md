# 残差信号的「可实现形态」= 黑名单，不是做空

**一句话**：把 20 日残差最高的那一档从多头池里剔掉，这是 A 股唯一能真正执行的那一半信号——
而它的价值必须用「随机剔掉同样多的名字」来对照，否则你把「剔掉高波动股」误读成「剔掉高残差股」。

## 为什么做这张面

`results/astock_resid_reversal_probe.json`（r1862）已经量过：残差对未来的排序是有效的
（IC 的 t 值很硬），但多空价差**不可实现**——A 股不能大规模做空，而唯一能买的那一档
（残差最低档）几乎没有超额。同一张表里还有一条没人消费的读数：残差**最高**的那一档是
唯一的负数档。

于是问题从「做空谁」改成「不要买谁」。这不是换参数，是换表达方式。

## 三条臂 + 一条对照

| 臂 | 做什么 |
|---|---|
| A | 整个合格池等权持有（什么都不做的书） |
| B | 剔除残差最高 20% 之后等权 |
| C | 剔除残差最高 40% 之后等权 |
| R | **随机**剔除同样多的名字（20 次抽样） |

打分口径（池、beta 窗、残差、排名）全部 `import` 自 `astock_resid_reversal_probe`，
两张面不可能各自漂移。成本按换手计（每边 8bp），逐期配对差给 mean / se / t。

## 判词

**VETO_ADDS_VALUE** —— 但判绿的条件是双门：同时显著优于 A（什么都不做）**和**优于 R（随机剔除）。
只过第一门会得到 `HELPS_ONLY_AGAINST_NOTHING_NOT_AGAINST_RANDOM`，那说明赚的是「少买了几只票」
而不是「躲开了高残差」。

逐年看，B 在样本内**每一年**都不劣于 A；R 逐年几乎与 A 重合——这正是「效果来自排序，
不来自剔除动作本身」的形状。

## 读数在哪

`results/astock_resid_veto_layer.json`：`arms` / `by_year` / `paired_per_rebalance` / `verdict`，
以及 `current`（当前交易日应剔除的名字与残差值，供任何多头名单消费）。

**这张面不在任何台账里印数字**：所有读数只有 JSON 一处来源，文档不复制一份，
省掉「页与面各说各话」的整族缺陷（r1860 判例）。

## 诚实边界

- 探索性普查：**无预注册、无登记、无采纳**，`prereg`/`adoption` 字段为 null 是刻意的。
- 样本内单一面（2020-2026，77 次调仓），没有样本外窗；票池是现存标的（幸存者偏差在
  面板侧，不在本脚本侧）。
- 成本按换手线性近似（每边 8bp），未建模冲击成本；B 臂换手高于 A，成本已按换手计入，
  但没有容量上限（B 臂平均池规模见 `arms.B.mean_size`）。
- 残差是按市值与 beta 中性化后的 20 日收益，属「已经发生的事」；它不是预测器，
  是一个**回避名单**。
