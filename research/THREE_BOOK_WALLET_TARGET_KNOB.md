# 三书钱包：风险目标是一只旋钮，它只买得起门槛

问题：the parent says the third book needs 1.14M at an 8% target; does turning the risk target buy it, and what does turning it cost?

窗口 2020-01-06 → 2026-11-26（1670 根 bar），钱包固定 1,000,000 元。

## 先钉住那条定理

- vol_scale is a constant multiple, so Sharpe does not move with the target
- 5% 与 12% 两档，忽略门槛时最优权重逐位相同，Sharpe 差 = `0.0`
- 所以拧目标**不会**让一本同样的书变得更值钱，它只会改变谁能进场

## 与父面的对账

- 本面 8% 档 = [0.65, 0.35, 0.0]，父面 `results/three_book_wallet.json` = [0.65, 0.35, 0.0]；四项读数最大绝对差 **0.0**（容差 1e-6）→ 一致

## 两个精确的刻度

- 100 万钱包**刚好**容得下一手 carry 的目标 = **9.1029%**（判据：91,029 / 1,000,000）
- 而 9.1% 这一档还差 **318.7 元**才够得着（门槛 1,000,318.7，钱包 1,000,000）
- 拧到与不拧已无区别（忽略门槛的最优权重也进门）的目标 = **18.206%**

注意 9.10% 这个常被引用的数：它比上面那个精确刻度**小**，差的那一点足以让一手 carry 仍然装不下。差多少，算一遍就知道，别按眼感取整。

## 读者会问的三句

1. **拧到底能多赚多少？** 8% 档 6.51%（回撤 -6.72%）→ 12% 档 16.98%（回撤 -8.92%）；多出 10.47 个百分点的年化，全部来自第三本书进得了场，不是来自更聪明的配比。
2. **那为什么不直接拧到 12%？** 要多交付 3.67% 的波动、多扛 2.20% 的回撤，而这条路只在第三本书的门开之后才存在——门关着的时候拧目标，只是把同一份风险放大。
3. **为什么 12.0% 档的实际波动只有 9.79%？** 三本书不相关的部分被混合平均掉了；标称目标是**风险预算上限**，不是交付承诺——本面把实际交付值照印，读者不该拿标称数当收益预期。

## 旋钮在哪一档真的动了

| 从 → 到 | 权重变没变 | 夏普 | 夏普跳变 | 第三本书进场 |
|---|---|---|---|---|
| 5.0% → 6.0% | 没变 | 1.0604 → 1.0604 | 0（纯缩放） | 否 |
| 6.0% → 8.0% | 没变 | 1.0604 → 1.0604 | 0（纯缩放） | 否 |
| 8.0% → 9.1% | 没变 | 1.0604 → 1.0604 | 0（纯缩放） | 否 |
| 9.1% → 10.0% | **变了** | 1.0604 → 1.4965 | +0.4361 | **是** |
| 10.0% → 12.0% | **变了** | 1.4965 → 1.6516 | +0.1551 | 否 |

5 段里 3 段的权重一动没动、夏普逐位不变，只有 1 段发生了跳变。

## 判词

`THE_KNOB_CROSSED_A_FLOOR_AND_JUMPED`

- 65% / 35% / 0%

## 本面不做什么

- this file only prices what different risk targets would deliver; it wires nothing into the live book
- 不重算任何一本书的回测；每本书的序列来自它自己的已发布面
- 不假设门槛之外的冲击成本——放大资金对同一批标的的挤压本面没有定价
