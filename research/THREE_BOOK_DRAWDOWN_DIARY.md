## 1. 为什么最大回撤不够用

父面把最深的一格印成一个数（-6.72%），把水下天数印成一个占比。两个都是**一个观察**的函数。读者真正坐在里面的，是**许多次里的一次**：他不知道这一次算大还是算小，也不知道上一次同样深的时候，要等多久。本面把那同一根已发布的序列切成一个个「峰 → 谷 → 回到原高」的事件，再量事件的分布。不重算任何一本书。

## 4. 事件的分布：多深、多久

把所有事件放进一个池子里取中位，等于把 0.1% 的抖动和 6.7% 的坑当成同一种动物——中位数两边都不描述。所以按深度分档印：

| 深度档 | 事件数 | 仍开着 | 回到原高中位（bar） | 最长（bar） | 中位（日历天） |
|---|---|---|---|---|---|
| <0.5% | 28 | 0 | 2.0 | 7 | 4.0 |
| 0.5-1% | 12 | 0 | 7.5 | 15 | 10.0 |
| 1-2% | 9 | 0 | 18.0 | 64 | 26.0 |
| >=2% | 14 | 1 | 54.0 | 208 | 78.0 |

| 全池读数 | 值 |
|---|---|
| 事件数（已恢复 / 仍开着） | 63（62 / 1） |
| 深度中位 / p90 / 最深 | -0.57% / -0.06% / -6.72% |
| 回到原高（bar）中位 / p90 / 最长 | 6.0 / 63.0 / 208 |
| 从谷底算起要多少 bar（中位 / 最长） | 3.0 / 175 |

共 63 次事件，已恢复 62 次、仍开着 1 次。**跌下去一半的时间花在下坡，另一半花在等**这句话只在深档成立：浅坑几乎当天就填平，深坑的回程才是读者真正要熬的那一段。

## 5. 判词

`THE_DEEPEST_HOLE_IS_THE_ONE_YOU_ARE_SITTING_IN`

判词只由上面印出的数决定：今天在不在事件里、这次是不是最深的、已关闭事件的中位恢复是否 ≥60 根 bar。**它不评价这本书好不好**——一个深度可控但恢复很慢的坑，与一个深度更深但恢复很快的坑，对持有人的意义完全不同，本面把两件事分开量。

## 6. 本面不证明什么

- episodes of a past window are not a forecast: this is how long the last few holes took, not how long the next one will
- no strategy is recomputed here -- the wallet series is three_book_wallet.load_books() + blend(), the same primitives the parent and ride faces use
- the sample has 2020-2026 only; a window that contains one long 2022-style hole cannot say how a longer one would end
- the clock is trading bars of this panel, not calendar decisions; a rebalance that happens on a different cadence would re-open the same path on a different day
- this face does not price anything and does not touch the recommendation; it only measures how the existing book's holes closed

## 7. 复跑与守卫

```
python scripts\three_book_drawdown_diary.py run       # 重算并写面
python scripts\three_book_drawdown_diary.py check     # 上游动了=STALE(rc3)；自相矛盾=CHECK FAILED(rc2)
python scripts\three_book_drawdown_diary.py selftest  # 离线自检
```

`check` 判两件不同的事：①任何上游面（ride 面 / 父面 / 三本书 / 面板）字节或 mtime 变了 → `STALE`（写者该重跑，不是本面算错）；②上游没动却与自己的数矛盾（最深事件 ≠ 父面 maxdd、今天与 ride 面不一致、bar accounting 不平、事件深度印成正数）→ `CHECK FAILED`（真缺陷，不带 STALE 字样）。
