# Y4 那把尺子量不了自己，换三把更准的尺子以后：书是「宽」的，但「前置」（r1426）

**一句话**：同一个 20 格（4 臂 × 5 个决策相位）上并排四把「年度集中度」尺子——控制尺（现行 Y4 的
top-2 年占比）在 4 个臂里有 3 个判不了自己；gross 分母版同样判不了自己；**能判自己的两把是
`effective_years`（PASS：中位 4.97–5.25 年 / 7）和 `years_for_half`（FAIL：中位 2 年 / 1 年）**，
而它们读的是同一本书的两个不同事实——书是宽的，但一半的收益来自 1–2 年。复合判决取**最差词 = FAIL**。

## 为什么跑这一轮

- r1418：日历闸把桌面上真正持有的书（nobond_vt08）判成 CONDITIONAL，唯一失败项是 Y4 top-2 年占比
  **71.08%**，超 70% 线 1.08pp。
- r1419：只把决策网格起点挪一周，同一个数在 71.08 / 79.46 / 79.58 / 79.82% 之间晃 —— 8.7pp 全是相位噪声。
- r1421：为什么晃 —— top-2 占**净和**的份额是「年化夏普换了件衣服」（份额对尺度不变，零分布只取决于
  m/s），且净和可以过零（C1 缺陷）。
- r1425：照归因去给商品袖上帽，4 个臂里 3 个 UNADJUDICABLE_PHASE（相位散度 > 到线的距离），并留下
  下轮指针：**把 Y4 换成显式口径，并先在相位集上证明它能判自己**。

本轮就是那个证明。被否掉的那把尺子（Y4）没有被放宽，也没有被悄悄换掉——它作为**控制臂**留在表里，
用来对齐 r1418/r1425 的读数。

## 四把尺子（单位、分母、线，全部在读数之前冻结）

| 尺子 | 单位 | 分母 | 线 | 均匀书的读数 |
|---|---|---|---|---|
| `net_top2_share` | 净年收益的份额 | Σ 年净收益（**可过零**） | ≤ 0.70（import `TOP2_SHARE_MAX`） | 2/n = 0.286 |
| `gross_top2_share` | 年**变动**的份额 | Σ \|年净收益\|（**只有全不动才为 0**） | ≤ 0.70 | 2/n = 0.286 |
| `effective_years` | 年（gross 份额的熵的指数） | 同上 | ≥ 3.0 / 7 | n = 7 |
| `years_for_half` | 年（整数） | 无（[1, n] 内整数；非正和发 None） | ≥ 3 / 7 | ceil(n/2) = 4 |

三条判据（V/S/D）先冻结、写进回执、由 `check` 从已发布行重算：

- **V 分母不能消失**：结构性声明，不看数。
- **S 能判自己**：每个臂上所有相位落在线的同一侧，且 `max-min ≤ |中位数 − 线|`。
- **D 能分辨**：这本书与「均匀书」的距离 ≥ max(该尺子的绝对地板, 自身相位散度)。

`S` 是廉价的门——把线放远就永远稳定、也永远没用；所以必须有 `D`。而 `D` 的第一版（能不能分开**臂**）
被实跑否掉了，见下。

## 读数（生产臂，20 格）

| 尺子 | 各臂状态 | 中位（plain / cap≤1 / cap≤2 / 双帽） | 散度 vs 距离 |
|---|---|---|---|
| `net_top2_share` | plain FAIL；cap≤1、cap≤2 **判不了**；双帽 FAIL | 79.58 / 84.81 / 76.91 / 84.90 % | 8.75 vs 9.58（只有 plain 保住） |
| `gross_top2_share` | plain **判不了**；cap≤1 PASS；cap≤2 判不了；双帽 PASS | 63.96 / 57.24 / 59.48 / 57.53 % | plain 15.82 vs 6.04 |
| `effective_years` | **四臂全 PASS** | 4.98 / 5.09 / 4.97 / 5.25 年 | 1.25 vs 1.98（四臂全部稳定） |
| `years_for_half` | **四臂全 FAIL** | 2 / 1 / 1 / 1 年 | 1.0 vs 1.0（四臂全部稳定） |

- **控制尺复现了 r1425**：Y4 在两把帽臂上判不了自己（散度 8.44pp < 距离 6.91pp；14.44pp < 14.90pp），
  所以 r1418 那条 71.08% 的拒绝本来就站在一个不能自判的读数上。
- **换成 gross 分母不是万能药**：它确实不会过零，但它自己的相位散度（plain 15.8pp）宽于它到线的距离
  （6.0pp），照样判不了。**「分母安全」与「能判自己」是两件事。**
- **两把能自判的尺子方向相反，而且都对**：书在「有效年数」上是 5 年 / 7（宽），在「一半收益来自几年」
  上是 2（plain）→ 1（上帽后更前置）。这不是矛盾，是同一本书的形状：**收益分布宽，但中位数那条线上
  的前置性很强**。可行动的那一半是 FAIL。

## 一次自捕：D 的第一版是错的

第一版 `D` 问「这把尺子能不能分开四个臂」。实跑时**没有任何一把尺子能过**。查下来不是尺子坏，是判据
把「仪器」和「样本」混在一起：四个在集中度上真的没有差别的书，任何尺子都分不开；而这条读数本身是
r1425「上帽只是搬走集中度」的第三个实证。

所以 `D` 改成「能不能把这本书从**均匀书**里分辨出来，分辨率要细于它自己的相位噪度」，并把「臂分离」
降级为一个**信息面字段**（`D_arms` / `arm_separation_is_informational`），两个结果都照印。
改规则的缘由写进回执的 `rule_revision` 块——**改在读数之后，所以必须公开，而不是悄悄换掉判据**。

## 判决与下一步

- 主尺 = `effective_years`（连续、四臂全稳）；佐证尺 = `years_for_half`（整数，零散度，只作证不作主）。
- **复合词 = FAIL**（取最差词，禁跨尺平均）：宽不能抵消前置。
- 生产文件一个都没动：`candidate_year_gate.py` 的 Y1–Y4 原样在岗。**换口径是换准入规则**，要走它自己的
  采纳轮（预注册 + 相位集自判 + 允许写入 `calendar_admitted` 那条门）。
- 下一个可做的旋钮不再是「上帽」（本轮在集中度轴上再次证明帽三臂不可分辨），而是**前置性**：收益集中在
  少数年份是这本书的结构（2024 商品 94.4%、2025 双引擎宽年，r1423），要么承认它并按它定资本节奏，要么
  换标的/换调仓块长度，而不是给袖上帽。

## 复现

```
python scripts/etf_book_year_caliber.py selftest   # 33/33，全离线
python scripts/etf_book_year_caliber.py run        # ~80s，20 格重定价 + 两条身份腿
python scripts/etf_book_year_caliber.py check      # 从已发布行重算，禁手改
```

两条身份腿：①无帽臂必须逐位复现 nobond_vt08 的发布窗口（cagr/sharpe/maxdd dev = 0/0/0）；②20 格的
`net_top2_share` 必须等于 r1425 已发布的 `top2_share`（在它的 4 位小数上逐格相等，max|d| = 0.0）。
任一条不符 = rc3 不落盘：尺子不能在另一本书上称重。

正身 = `results/etf_book_year_caliber.json`（含全部 20 格逐年净收益）；S6 链腿 `year_caliber`（check 形态）；
smoke 两条腿（selftest + check，套件不重写已发布面）。
