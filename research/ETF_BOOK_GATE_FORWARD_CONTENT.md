# 供给闸的四把尺子，没有一把能看见下一年（r1444 bm-c·2026-11-08）

## 一句话

年轴门对候选的四条拒收判据（Y1 正年占比 / Y2 年度中位 / Y3 最差年 / Y4 top-2 年占比），
**逐条做前向内容检验，四条全盲**（对齐后 |rho| ≤ 0.29，置换 p ≥ 0.09，3 年窗 54 格 / 4 年窗 36 格）。
供给地板连红四十轮（ready 0 / floor 3）因此不是「货不够」，是**一把形状尺子在拒绝形状**。

## 为什么这项检验必要

r1441 只测了一把（Y4），结论 RULER_BLIND，并把它写成下轮指针。但门实际拥有四条判据，
而四只在册候选**全部只因 Y4 被拒**。只测一条就下判断等于把一个四问的门读成一个一问的门；
反过来，如果 Y1/Y2/Y3 有前向内容，那么正确的修法不是废门，而是**把拒收重新指向会说话的那几条**。
两个方向的后果完全不同，所以必须四条一起读。

## 方法（判据跑前冻结，见脚本 CRITERIA 块与产物 `criteria` 字段）

- 18 支臂（宽 3/5/8 × 调仓 10/20/40 × 波动目标 开/关），引擎 import 不重写（`etf_robust_pf.open_to_open_equity`）。
- 每臂切固定 3 年（主）/4 年（备）滚动窗；窗口内四条判据各自统计量由 **`candidate_year_gate.year_metrics`**
  算出（冻结实现，不抄一份）；对照值 = 同一臂**紧接窗口的下一年**收益。
- 方向先声明：Y1/Y2/Y3 越高书越强（正向），Y4 越高越集中（负向）。对齐后：
  `CARRIES_FORWARD` = 对齐 rho ≥ +0.35 且 p < 0.10；`BACKWARDS` = ≤ −0.35 且 p < 0.10；其余 `BLIND`。
- 两个窗取**最差词**，禁跨窗平均（E433）。触及部分年的格一律剔除不截断。

## 读数

| 判据 | 3 年窗 对齐 rho / p（格） | 4 年窗 对齐 rho / p（格） | 判词 |
|---|---|---|---|
| Y1 正年占比 | −0.0572 / 0.686（54） | +0.2407 / 0.157（36） | BLIND |
| Y2 年度中位 | +0.0801 / 0.567（54） | +0.2899 / 0.094（36） | BLIND |
| Y3 最差年 | −0.0242 / 0.866（54） | +0.1113 / 0.507（36） | BLIND |
| Y4 top-2 占比 | +0.0302 / 0.830（52） | +0.2700 / 0.106（36） | BLIND |

- 一致性腿：Y4 对齐 rho 的原始值为 −0.0302，与 r1441 独立发布的 −0.0302 逐位一致（同一家族同一样本）。
- 4 年窗四项都偏正但都没过线：Y2/Y4 逼近 p≈0.10，读作「可能有点东西，但不足以改变拒收」，不读成通过。

## 第二条腿：把 Y4 拿掉会怎样（场景，非改动）

按相位逐格重发判决（`ADMIT`/`CONDITIONAL`/`REFUSE`，规则冻结在 CRITERIA）：
拿掉 Y4 后 **3 本书在它自己的每个相位上都 ADMIT**（nobond_vt08_adopted、nobond_vt08_floor_050、
all_classes_published），`nobond_base` 仍是相位不稳（2 相位 ADMIT / 1 相位 CONDITIONAL）。
——这条不是判决，只是「如果」；本文件不改任何线、不改拒收集、不改生产配置。

## 第三条腿：那道「还有信任尺子兜底」的兜底

相位票据说拒收 `REFUSAL_SURVIVES_TRUSTED_RULER`。把两份已发布面并排读（不重算）：
拒收实际由 `years_for_half` 承担，而它**自己的自判判决是 FAIL**（`results/etf_book_year_caliber.json`，
r1426 四臂）。因此第二道防线不是第二条线，是同一个问题问了两次；`effective_years` 自判 PASS，
但它在这三本书上是 PASS（不拒收）。**唯一能拒绝的那把尺子，恰好是不能自判的那把。**

## 限制（印在面上，不藏）

- 18 支臂是一个家族，多数格共享同一个赌注，横截面比格数窄。
- 每臂最多三个前向年（r1316 功效地板）：能裁决「这条判据有没有前向内容」，不能裁决策略问题。
- 3 年窗算术下限：全正记录的 top-2 占比不可能低于 0.667，Y1 在 3 年窗要 0.70 就意味着三年全正——
  「从来不过线」里有一部分是窗口算术，不是书。
- 本文件不改任何闸线、不改供给地板、不改生产配置；判决留给 2026-11-11 转仓日前的决策。
