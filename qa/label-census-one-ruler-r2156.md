# r2156 — 一面镜子两个数：标签普查的检查过去只照自己

轮号：r2156（bm-c）｜时间：2026-11-27 01:5x-02:0x+08:00｜面件：`scripts/etf_label_census.py`

## 一、红在哪（本轮入口）

上一轮全量冒烟（759/783）的红项里有这一条：

```
product: etf_label_census (face re-derived from its own pair table, ruler cross-checked)
exit=1 | {"ok": false, "problems": ["the two faces price the same pair differently:
512040/159263: census 0.3883 vs sibling face 0.3850"]}
```

读法不是「两个脚本算错了」，而是：**检查根本没有去读面板**。`check()` 只把已发布的两个 JSON
拿来互相比较——`mine` 取自 `results/etf_label_census.json` 的 `median_pp`，`med` 取自
`results/etf_book_sibling_gap.json` 的 `gap_median_pp`。于是它只能回答「两张纸上的数一样吗」，
永远不能回答「这张纸还是不是今天的面板算出来的」，这正是 r1935 立的判例（*自检只重算自己 =
永远不会说自己过期*）在标签普查上的复现。

现场取数验证（本轮实测）：

| 读数 | 值 |
|---|---|
| 面板重算 `512040/159263` 中位 | **0.3850**（338 个共同交易日，最后一根 2026-11-26） |
| 孪生面 `etf_book_sibling_gap.json` 发布值 | 0.3850 |
| 本面 `etf_label_census.json` 发布值 | 0.3883（停在前一根 bar 的旧面板上） |

所以两条不是矛盾，是一条旧、一条新。按老判据它每轮都红，而红句里既没有 `STALE` 这个词，
链的 `run_leg` 就不会为它付一次重生（`_repairable = "stale" in text`）——一条**永久红**，
且它会训练读者把真缺陷当背景噪声（r1789 族）。

## 二、改法（改的是判据，不是放宽）

1. **把面板读数搬进检查**：`check()` 现在对面上每一个已定价配对调用 `pair_reading()` 重算，
   再与已发布值比。411 个配对全部重算，读数进 `pairs_rederived`。
2. **两态分开，词不同**：
   - 面板重算 ≠ 本面发布 → `STALE the panel moved under N priced pair(s)…`（值得付一次 run）；
   - 本面重算 = 本面发布，但孪生面发布值与面板不符 → `STALE the sibling face … is behind the
     same panel`（点名是**谁**旧了，不记在本面头上）；
   - 两边都各自与面板相符却仍不同 → `the two faces price the same pair differently`（真缺陷，
     不带 `STALE`，任何重生都抹不掉它）。
3. **容差=面自己的存储精度（4dp），不是 1e-9**：实测一根新 bar 只把这些中位推动 ~1e-4 pp，
   与 4dp 存储的舍入同量级；首版用 5e-5 容差把 341 个正确配对判成「面板动了」，改用
   `round(x, 4)` 比较后即为 0。这条写进代码注释（`same_reading`）。
4. **自检三腿钉死行为**（不用真面板，用中毒副本跑真 `check()`）：
   - L18 未改动副本必须绿（守卫不把普通情形染红）；
   - L19 把本面某个配对中位 +1.00 pp → rc=1 且出现 `STALE`，且**不得**出现「两面对同一配对定价不同」；
   - L20 本面不动、只把孪生面某配对 +1.00 pp → rc=1 且出现 `STALE` 与 `sibling face`（点名对方）。

只看两版都在的 63 个组（同一口径下比较）：昨日合计 **42,781 元 → 今日 21,452 元，存活 50.1%**；
昨日换仓额超过 100 元的 44 个组，**中位存活率 0.46**；昨日越过材料线的 17 组里，**13 组掉出、
4 组留下、4 组新进**。

掉得最狠的几组（同一对成员，昨日→今日，10 万元）：

- `159995/512760/516350/516640/516920`（芯片系）：**7,025 → 268 元**

结论（产品话）：这张面上的「换一次能省多少」是**当日的价差**，不是可重复的钱——一夜之间一半
就没了，昨天最值的五组里有四组是单日错价。真正可行动的是那 4 个连续两日都越线的组。
