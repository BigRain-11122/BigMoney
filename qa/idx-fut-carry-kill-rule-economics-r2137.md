## 一句话

这本书历史上最深的一次回撤只有 **-1.89%（IC）/ -3.05%（IM）**，折合 **0.58σ / 0.90σ** 的年化波动——
所以**写在章程里的 4%/6%/8%/10% 杀线，在这段记录上一次都没响**（四条线 × 两品种全 0 次触发）。
按波动标定之后它才开始有意义：1.0σ 线什么都不做（代价 0.00–0.04pp、买回 0.00pp），
0.6σ 线便宜到近乎免费（代价 0.13–0.35pp、买回 0.23–0.94pp），0.4σ 线代价上台阶（IC +0.89pp 只买回 0.32pp，
IM +0.28pp 买回 1.63pp）。**同一族规则在两个品种上给出相反的钱，且样本内外排序翻面——所以这一页给的是价格，不是建议。**

## 口径对账（必看）

- 日序列＝`paper_basis_timing_cost_split.replay(code, 1.5bp)`，与已发布台账逐日一致的同一镜像（r2134 已证 3442 天零差）；**未重写规则**。
- 杀线用**当日可知**的滚动波动（含当日收益、作用于次日），没有用全样本常数，也没有拟合倍数。
- 回撤在收盘 t 读、状态变更作用于 t+1；复入用**影本**（未过滤路径）判定——空仓净值读不出「危险过去没有」。
- 空手日按 0 超额记，真实现金腿（保证金利息/逆回购）不在序列里 ⇒ 本页价格是**上界**；进出各付 1 个边（当日权重 × 1.5bp）。
- 与 r2135 的关系：r2135 的 4% 线「一年响 9.3%/15.2%」是**去均值自助噪声世界**里的概率；真实记录里 4% 线（≈1.2σ）一次不响。两个数不矛盾，是两个世界。

## 自检覆盖（23 腿）

回撤手算值｜不可达阈值=零触发且复现基线｜崩盘当日不被躲开（无前视）｜状态只在崩盘收盘后翻｜冷却期恰好 N 日复入｜
影本减半严格早于影本新高｜空手日收益恰好 0｜每次状态变更恰好一个边、边的大小=当日权重×1.5bp｜
滚动波动 min_obs 前无定义／手算值逐位相等／只用过去数据｜样本内外切分是划分｜确定性重跑逐位相同｜
判词闭集六腿（免费保险 / 代价小于买回 / 代价大于买回 / 什么都不做 / 空面不可读）｜排序两腿（样本内最优掉出前三 → IN_SAMPLE_ONLY；留在前三 → HOLDS）。
