# QA — 同一顶帽子，两种单位（r2072 bm-c）

工作面：`scripts/etf_book_cap_beta_units.py` · 面 `results/etf_book_cap_beta_units.json` · 页面 `research/ETF_BOOK_CAP_BETA_UNITS.md`

## 为什么要这张面

CEO 一页纸把 ETF 复合书与阶梯总帽并排放着，只写一句「列在同一张表但不进裁决」；帽子对账面
`results/regime_cap_vs_book.json` 则把它标成 `own_rule`、差额 **23.5pp**。

于是读者手里只有一个结论：**这本书是帽子的 2.18 倍**。这个结论量的是**名义敞口**。
同一本书的 β 约 0.48，它对市场的敞口是 43.5% × 0.48 ≈ **20.9%** —— 同一顶 20% 的帽子，
换个单位就只剩 0.94pp，而这点差额还在尺子自己 ±5.89pp 的噪声里。

本面不替任何一方辩护，只把两种单位并排印出来，并回答第三个问题：这本书的仓位规则与帽子
是不是同一个东西。

## 判据（写死在纯函数里，不读盘不读钟）

| 函数 | 判据 |
|---|---|
| `beta_units(k, beta)` | 市场敞口 = 仓位 × β |
| `trim_cny(...)` | 卖到帽子上的钱 = (k·β − cap)/β × NAV；负值 = 本来就在帽下 |
| `band_units(k_noise_sd, beta)` | 尺子噪声在 β 当量上的尺寸 |
| `verdict_of(cap, eq, band)` | 三态：`OVER_CAP_BEYOND_THE_RULER` / `UNDER_CAP_BEYOND_THE_RULER` / **`AT_CAP_WITHIN_RULER_NOISE`** |
| `reading_in_notional(k, cap)` | 名义读法自成一票，永不与 β 读法合并 |
| `rung_rows(eq, beta)` | 每档帽子允许的 k：>1 即「要杠杆」（这本书不会到那一档） |

边界刻意钉死：`band=0` 时退回严格比较（自检腿钉住 0.20001 判超、0.2 判平）；
`trim` 必须能把自己送回到帽子上（自检往返腿 1e-12）。

| 项 | 读数 |
|---|---|
| 政体态 / 当期帽子 | RED / 20% |
| 书仓位 k | 0.435003（NAV 1,000,000） |

| 尺子噪声（β 当量） | ±5.892pp |
| 名义读法 | 43.5% vs 20% → **2.175x**，`ABOVE_CAP` |
| β 读法（当窗 / 全史） | 1.047x / 1.000x |
| 判词 | `AT_CAP_WITHIN_RULER_NOISE` |
| 卖到帽子上的钱 | 19,543 元（当窗 β）/ 0 元（全史 β） |
| 该档允许的名义仓位 | 415,460 元（当窗 β）/ 435,027 元（全史 β） |

结构性发现（可验而非断言）：票面 k 与 `beta_target/β` 的恒等式成立到 **−0.0024pp**
（0.2 / 0.459741 = 0.435027 vs k = 0.435003）。即这本书的规则 **就是 RED 档在 β 单位下的写法**，
且与政体无关：ORANGE 以上各档要的 k 分别是 1.039 / 1.350 / 1.662 / 1.973，**全部 >1**，
没有杠杆就用不到——所以它在 GREEN 档也仍按 β 当量 20% 跑，RED 档是它唯一会碰到的档。

## 它不声称什么

- **不是超额合规的辩护**：β 当量 20.94% 确实在 20% 上面，只是没有超出尺子的分辨力
- **不是新回测**：全部数字由三张既有面与本票面算术派生，零新判据、零新阈值
- **不是建议改 β 目标**：抬到 0.8 会让它在 GREEN 档吃满杠杆预算，那是设计决定不是本面能签的字
- **不是帽子对账面的替代**：那张面量的是六个阶梯账户的名义合规，本面只回答「这本书换算到帽子的单位是多少」
- β 是一阶线性读数；商品与黄金袖对指数 β 不承载其在组合内的真实风险
