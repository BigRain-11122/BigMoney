## E42 — Writer-Pause Window（daemon 活写阻断 rebase 的让路法）

"staged changes"/"must edit merge conflicts" 提示误导）。

**方法**：
1. 诊断面：`git diff --name-only` + 文件 mtime 连续观测确认 daemon 是写入源；
   `git status` 提示 "you have staged changes ... git commit" = editing-stop 态真错误

3. 静窗内完成 absorb+continue+冲突解（22-UU 批=ALL_FACES resolver+手解件）；
4. rebase 落地后立即 ENABLE 全部恢复（队列态在文件面持久，暂停只延迟烧录零损失）；
5. untracked 撞重放（引擎新写分片）按 r220 律 TEMP 暂移，回移前与重放侧做

## E101 一条腿的**算术贡献**不是它的**边际价值**——判腿的权重看「剔除后重跑」，不看它赚了多少（r1244 bm-c 实测·ETF 复合书袖变体）
- 病象：r1243 按袖分解出债腿「在 85.4% 的日子在场、平均权重 53.6%、算术贡献 +8.57pp」，很容易读成「这本 9.04%/年 的一半是债腿挣的，所以要留着它」。把债从可选池里剔掉、同一套打分同一套成本重跑：**13.47%/年（+4.43pp）**，样本外 15.30%→**20.81%**，且对**同一批列**的等权对照每个窗口都赢（IS +10.87pp / OOS +11.77pp）。去掉一条腿反而更强——正贡献与正边际价值是两件事。
- 机制：五格等权书里每个名额都是稀缺资源。防御腿在股票回撤期占掉一个坑，书就被支付 carry 而不是等反弹；被占掉的名额机会成本从不进「贡献」账。
- 正法（任何多腿书的腿部裁决都走这四步）：①**剔除重跑**：把该腿从候选池删掉，打分/成本/节奏全部不动，重跑同一窗口；②**同列对照**：对照必须建在**同一个子集**上（换池子=换基准，跨池比较读不出边际效果）；③**逐窗读数**：full / IS / OOS 三窗都要，别用全样本一个数定案；④**命中面**：绝对收益、Sharpe、maxDD 三面同表，因为腿常是「买波动」不是「买收益」（本例含债 OOS Sharpe 1.466 > 无债 1.30，但 CAGR 低 5.5pp）。
- 姊妹陷阱（必写进结论）：静态子集 ≠ 原书减一条腿。子集书**不能**再轮进被删的袖，它是另一个策略；报告须显式声明，否则「剔除债后更强」会被读成「原书少配债就行」。
- 证据：`results/etf_composite_decomp_variants.json`（bond_removed / commodity_removed / crossborder_removed / equity_gold_only 四子集各自带 own-EW 三窗对照）、`research/ETF_COMPOSITE_SLEEVE_VARIANTS.md`、对照原面 `results/etf_composite_decomp.json`。
- 另一条同源读法：**承重腿靠「剔除后塌多少」认，不靠贡献排名**——本例剔除商品/黄金，OOS 超额从 +11.77pp 塌到 +0.78pp（塌 11pp），是全表唯一承重腿；剔除跨境只降 4.9pp。
