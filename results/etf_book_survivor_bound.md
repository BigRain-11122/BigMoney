# ETF 书 · 生存者偏差能给 2015 年的拒绝打几折？

**面**：`results/etf_book_survivor_bound.json`（脚本 `scripts/etf_book_survivor_bound.py`，selftest 13/13 + `check` 复算 ok）
**截止**：2026-11-19 收盘 bar；口径来自 `results/etf_book_year_gate/YEAR-GATE.json`（线 = 单日冲击 1% ADV，镜头 = 1,000,000 元 / 5 名，每名 200,000）

## 一句话

**打不了折——2015 年的拒绝不是「市场没深度」，是「打分挑了薄票」。**

## 读数（2015-01-05 锚）

| 项 | 值 |
|---|---|
| 当日可读名单 | 61 只（面板出生集合 67 只中 66 只活到今天） |
| 全池成交额（ADV 合计） | 131.06 亿 |
| 第五深的名字 ADV（决定容量那一个） | 9.99 亿 |
| 五名等权能承载的资本（1% 线） | **4,994.5 万** |
| 一个名额在 1% 线下需要的 ADV | 2,000 万 |
| 过这条线的名字数 | **21 只** |
| 打分自己选出的五名能承载的资本 | **60.24 万** |

同一根 bar 上，市场能装 4,994 万，打分只装 60 万 —— 差 **82.9 倍**（与 r1872 在印数一致）。
一个名额只要 2,000 万 ADV，2015 年有 **21 只**名字过线；打分选中的五名里最薄的一只只有约 1,205 万。

## 生存者偏差的实际尺寸

- 面板 1,725 个 csv，**只有 2 个**尾 bar 停在 2026-10-01 之前（0.12%）。
  这是一份「今天还活着」的名单快照，不是全史 —— 早期名单被低估，广度数字是下界。
- 2015 年锚上，面板里出生的 67 只中有 66 只活到今天，只有 `510880_t73` 死在 2026-09-22。
- 判据（先冻结）：一个名额需要的 ADV ≤ 全池成交额 → 一只消失的基金**有可能**补上这块深度（该年的拒绝不可引用）；大于全池 → 任何名单都补不上。
  2015 年：2,000 万 ≤ 131.06 亿，本来该走「可能」那支——**但五只可读名字已经过线**，所以这个问题在 2015 年根本不成立。

## 对下注决策的意义（闸门 b：下多大）

1. 2015–2018 那几年的容量瓶颈**不是流动性**，是选名规则。加一道「入场时名义 ADV ≥ 名额/线」的流动性筛，
   在同一批分数里挑更深的名字，容量就能从 60 万抬到千万级而**不改变信号本身**——这是下一轮要量的东西（不是本轮结论）。
2. 「2015 年拒了这本书」这句话今后只能作为**排名质量**的证据引用，不能再当作「当年市场太浅」。
3. 生存者偏差对 r1871/r1872 的**广度**结论仍然成立（名单被低估），对**深度**结论不成立（可见的名字已经够）。
