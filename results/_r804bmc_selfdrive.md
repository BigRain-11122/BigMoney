# Self-Drive v2.0 — 零空闲·满算力·三线并行

> CEO令 2026-09-28：「没有任何空闲，算力跑满，各自跑业务新方向+新技术+技术底层，任何工作都别闲着」。
> 铁律：**任何司任何轮次，手里必须有活。没活=失败。**

## 0. 三条并行流水线（每司必须同时跑）

每个司不是做完一件等下一件，而是三条管道同时转：

| 管道 | 干什么 | 产出节奏 | 停工=事故 |
|---|---|---|---|
| **P1 主业务线** | 你本职：Biggame做游戏/BigMoney做量化/BigStream做内容/FluxVerse建城市 | 持续commit/交付物 | 是 |
| **P2 技术深耕线** | 挖技术底层：试新模型/新管线/优化现有管线/压token/提速/做工具 | 每24h至少一个技术commit | 是 |
| **P3 新方向线** | 找下一个增长点：新赛道/新玩法/新变现/新合作/新数据源 | 每48h至少一个调研件或prototype | 是 |

三条管道的活**不排队、不等令、不互相等**。本轮P1干完了立刻切P2，P2卡住了立刻切P3，P3调研出结论立刻回P1落地。

## 1. 零空闲队列（No-Idle Queue）

每个司 `state/queue/` 下常备三类任务，永远不许空：

- `queue/main.md` — P1主业务活，至少列5条待办
- `queue/tech.md` — P2技术深耕活，至少列10条待办（试新工具/优化脚本/压prompt/做benchmark）
- `queue/explore.md` — P3新方向活，至少列10条待办（新赛道扫描/竞品拆解/跨界合作可能）

**轮次启动规则：**
1. 先看P1队列头部，有活就干。
2. P1队列空了=立刻从P2队头抽活，不许停。
3. P2也空了=从P3队头抽活。
4. 三个队列都空了=这是事故，该司当轮必须先花时间填队列（自己想该干什么），再干活。
5. 任何一轮结束时，三个队列剩余条数必须比开头少，否则=空转，复盘。

**队列填充纪律：**
- 每轮结束前必须往队列里补至少1条新待办（从扫描的信息里来）。
- 队列里不许有"等CEO指示""等别的司"——能自己干的自己干，不能干的扔协作市场。

## 2. 算力跑满（Local Compute Saturation）

现状：GPU利用率5%，显存占6.6G/12G。目标（**方向性参考·非执法线**——nvidia-smi util=时占指标·burst 推理反显低值·显存常驻≠有效产出代理·C-20260929-02 席2/席7 附款）：本地GPU利用率常态>70%，显存>9G。**执法线=§7.1 的 30% 点名阈值（唯一）。**

每个司必须把本地Ollama/GPU用起来，不许所有活都扔云端：

- **批量活扔本地**：批量文案生成/数据清洗/代码审查/ summarization / 初筛分类——用qwen2.5:14b或7b本地跑，不要烧云端token。
- **GPU空闲时自动跑**：每司有一个"空闲时任务"——比如本地批量出图/本地embedding/本地小模型推理，GPU一闲就自动接上。
- **BigCompute负责调度**：监控GPU利用率，低于50%超过30分钟=自动派活给任何能跑本地批处理的司。
- 判据（**随 C-20260929-02 改制**）：自动派活=**毕业呈批制**（§7.4·非默认毕业）；GPU<30% 连续 3 窗且无保护态豁免=夜轮点名行（§7.1 唯一执法阈值·本行旧「<50%=失职」废止）。

## 3. 信息源墙 + 协作市场 + 技术交易所（保留v1，强化）

- **信息源墙** `docs/intelligence-wall.md`：每司每天必须扫至少3个源（自己找的，不要等给），发现信号写墙。
- **协作市场** `docs/collab-market.md`：每司每天发一条"我有什么/我要什么"，跨司自己谈，不用批。
- **技术交易所** `docs/tech-exchange.md`：做完任何可复用的东西（脚本/prompt/配置/数据集）必须丢上去，不许藏私。

## 4. 自驱心跳 + 闲置唤醒

- `state/heartbeat.txt` 每轮写。
- 心跳停3h（不是6h）=自动唤醒，从该司队列里抽队头任务强制跑。
- 连续2次被唤醒=CPH4 Labs接管重写该司循环。
- 外部审计把"队列是否常备25条以上""GPU利用率""三线commit分布"纳入每轮检查。

## 5. 红线（唯一三条）

1. **不许重复建设**——技术交易所里有的东西，先看再做，别从零造。
2. **不许空转**——一轮结束没有commit/没有文件改动=空转，夜轮复盘为什么。
3. **不许藏私**——好工具/好发现不丢交易所/协作市场=下次进化轮提案权重清零。

## 6. 启动（本周必须落地）

1. CPH4建三个空表（信息墙/协作市场/技术交易所）。
2. 每司在自己 `state/queue/` 下建三个队列文件，各填至少10条待办。
3. BigCompute GPU 监控脚本已建（gpu_idle_collector·dry-run 观察窗实录在档）——自动派活按 §7.4 **毕业呈批制**执行（非默认毕业）。
4. 夜轮从下周开始统计：每司三线commit占比/GPU利用率/队列常备数，不达标自动补。

### 7.1 算力面可见与判活
心跳 GPU util 字段（P-33 已采集）**读侧消费**：夜轮/fleet-audit/patrol 判色加 GPU 维——**连续 3 窗 GPU<30% 且无保护态豁免=点名行**（唯一执法阈值）；点名响应面含「GPU 面外借、控制面任务续跑」合法项（禁为点名达标强停装配相塞 GPU 活）。周报自驱面 GPU 均值行**分机即刻起报**；算力面数据兼作 fleet-allocations §六.6 扩容判据前置证据（防申购叙事）。

### 7.2 备货池范式集团化
每司 **lane 文件常备 ≥2 条本地可执行批**（O-1855 单写者律·字段=O-1820 三验〔假设/消费面/consumer_plan〕+**可执行机档**行〔按产线矩阵/模型分配节自声明·认领时 verdict 复核·档位不符≠池内有货〕）。**违例限缩=「有活不备」**：真无意义批=lane 一行亮牌声明+转创新轨免计（O-1820 承接·防凑数批制度化）；**负值闸**=回访窗连续零真实消费的批=违例计数+清出池。就绪度分档：反馈面缺位司（Biggame）收执落定前不启计；首批试点=范式已验司（BigMoney/BigLife）先行·Bonsai 09-30 回执后再扩团。跨司拉活=fleet §5 借算+让路律不变；git 认领非原子坑沿批次先占律；他司 repo 拉取失败≠池空违例。

### 7.3 商业与内容护栏
产出归属=consumer_plan 所载消费面司；对外变现走 BigCompute 出口（D-09/D-10 分账律）；成本按借算工单入算力账本（口径 B·共享窗折价分列）。批活只填闲窗·交互流量到达即让路（P2 台词 ≤15s 车道律恒在）；内容类批产出过机审门+QC 方可入库（本地批活恒居 advisory/预筛位）；BigDomain lane 含大厅/共创端可演示批·bm-c 闲窗优先登记参观端推理需求。

### 7.4 自动派活毕业（10-05 复核窗·呈批制）
**默认不毕业**：须双侧证据（成本侧闲置基线+供给侧 lane ≥2 持续 ≥3 日）+预注册失败判据+**非 CEO 机受控实弹 ≥1 次证零前台扰动**（dry-run 0 in-flight=只验证了监控）。**bm-a 列自动派活黑名单直至 GPU/显存余量帽实测通过**（CEO 余量令扩帽 GPU·CPU 帽恒在）；派活器只收可让路批（小批粒度/断点续跑）+headroom ≥1.5GB 前置；监控密度 ≥6 样本/h 前利用率不作失职线。
