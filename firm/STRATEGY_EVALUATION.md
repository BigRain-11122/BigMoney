## §0 判定

## §1 设计原则（五律）

1. **实战优先**：最高权重给实战维度（随机起点实战检验 P-5 = 30%）；纯回测统计只作基础面。
2. **数据驱动**：一切分数来自既有 results JSON 与 P-5/paper 产物自动聚合，禁手工打分禁写死；无数据维度如实标 ⬜ 未测，禁假装。
3. **预注册**：维度/权重/公式/分级带 v1.0 写死；修订走立法废法 7 天否决窗（RULES §7）；禁看结果调权重（=变相「禁止跑到达标为止」铁律）。
4. **一票否决**（硬红线，任一命中=S 级无资格）：未来数据违规 / ×2 成本不存活 / 单起点破 -35% 回撤红线 / OOS 盲区违规 / 窥探折价未声明。
5. **诚实分级**：宣称分级律（✓ 全过 / 🟡 部分 / ⬜ 未测 / ✗ 失败）逐维度适用；总分如实含未测零分，禁平均掩盖。

## §2 八维框架（权重跑前写死，Σ=100%）

| 4 | 政体存续 | 10% | 逐年/OOS 切片 | OOS 留存率、最差年、2025+ 政体方向一致性 |

## §8 三对象统一评价律（v2.0 五律 · O-20260925-1755）

1. **≥2 维呈报律**：对交易员/策略/组合的一切采纳、晋升、编制、接线、呈报决策，依据面 ≥2 维度；**单一指标禁作任何决策依据**（单指标只许出现在过程监控面板）。
2. **硬否决面通用**：未来数据违规/×2 成本不存活/回撤红线/诚实违例/风控违例——任一命中=评价对象无采纳资格（继承 §1.4）。
3. **评价≠门禁**：评价=排名/画像/呈报面；采纳/晋升恒走 G1'/G2/hr.py 冻结判据（继承 §5，promotion.md v2 权威不变）。
4. **数据驱动**：三卡全由 scorecard 聚合既有 results JSON 自动重算，禁手工打分；未测=⬜ 如实呈现。
5. **校准律与修订律**：交易员卡/组合卡总分与权重带=**首届对象分布校准后预注册再启用**（交易员首届=在册 6+PROSPECT 22；组合首届=IV6/EW6/B_MAXDIV/EW+合格复合格；校准前=读数卡）；一切维度/权重/分级修订=预注册+7 天否决窗（继承 §1.3 数据窥探红线）。
