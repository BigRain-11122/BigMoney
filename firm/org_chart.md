```
                    ┌──────────┐
                    │  CEO     │  (你，最终决策权)
                    └────┬─────┘
                         │
              ┌──────────┼──────────┐
              ▼          ▼          ▼
        ┌─────────┐┌─────────┐┌─────────┐
        │ 研究部   ││ 交易部   ││ 风控部   │
        │ Research││ Trading ││  Risk   │

             │           │           │

                   ▼
            ┌─────────────┐

            │ 数据/算力/   │
            │ 分布式/实盘   │
            └─────────────┘
```

## 部门职责

### 研究部 (Research)
- 从因子库挖新 idea
- 写新策略骨架代码
- 做 IC/回测研究
- 输出：`research/ideas/*.md` → 培养新交易员

### 交易部 (Trading Desk)
- 每个交易员 = 一个策略实例
- 有编号、风格、参数、等级
- 按等级分配资金
- 输出：交易信号 → 风控审核 → 下单

### 风控部 (Risk)
- 制定铁律（持仓周期、止损、仓位上限）
- 每日审查交易员表现
- 触发风险自动熔断
- 输出：风控报告、熔断指令

### 技术部 (Tech)
- 数据管道
- 分布式回测（Master + 3 Worker）
- 实盘网关
- Dashboard

## 交易员等级

| 等级 | 代号 | 资金分配 | 准入条件 |
|---|---|---|---|
| 实习生 | INTERN | 0（只跑回测） | 刚生成，样本内 Sharpe>0.5 |
| 见习生 | TRAINEE | 0（模拟盘） | 样本外 Sharpe>0.8，回撤<25% |
| 正式 | TRADER | 5% 总资金 | 模拟盘 3 个月达标 |
| 高级 | SENIOR | 15% 总资金 | 实盘 6 个月 Sharpe>1.0 |
| 王牌 | PRINCIPAL | 30% 总资金 | 实盘 12 个月 Sharpe>1.5，回撤<15% |
| 淘汰 | FIRED | 0 | 连续 2 月不达标 |

## 晋升/淘汰规则

**晋升**：
- INTERN → TRAINEE：样本外 Sharpe>0.8，交易次数≥30
- TRAINEE → TRADER：模拟盘 3 个月，月度胜率>55%，最大回撤<15%
- TRADER → SENIOR：实盘 6 个月，Sharpe>1.0，超额>沪深300
- SENIOR → PRINCIPAL：实盘 12 个月，Sharpe>1.5，回撤<15%

**淘汰（FIRED）**：
- 模拟盘连续 2 个月回撤>20%
- 实盘单月亏>8%
- 策略 IC 衰减>50%
- 违反风控规则
