## ⚠️ 先读这个（必看）

1. **历史回测收益 ≠ 未来收益。** 系统的一切指标（回测、样本外、模拟盘）都只能证明"过去如此"，不能保证未来。真金白银入场前，请让模拟盘轨道跑足够长（建议 ≥ 1-3 个月）再评估。
2. **合规前置。** 按《证券市场程序化交易管理规定》（2025-07 施行），程序化交易投资者须向券商**报备**后方可实盘。本系统为日频调仓（远低于"高频交易"报备阈值），但报备流程不能省。
3. **风控红线是硬的。** 单票 ≤15%、个股 -8% 硬止损、最高持股 15 交易日。**出局机制（2026-09-21 用户指令"亏完出局，不能盘中波动出局"）**：盘中波动永不触发出局；回撤 10% 停机线与"亏完出局线"（本金亏 80%＝数学实质亏完，需 +400% 回本）都只看**收盘结算**判定。停机需人工 `run.py resume`，毁灭出局不自动恢复。
4. **无冠军不出手。** 进化不出合格冠军（样本外得分不过线）时，系统保持空仓——这是防垃圾策略上场的保护，不是故障。
5. 本项目不构成投资建议；实盘损失自负。

        │                                              │                         │
   ┌────▼─────┐   ┌──────────┐                  ┌─────▼──────┐   ┌──────────┐ │
   │ 决策层    │→ │ 执行层     │                  │ 进化引擎    │→ │ 冠军晋升  │ │
   │ decide.py │   │ paper.py  │                  │ evolve.py  │   │ 样本外闸 │ │

- **数据层** `quant/data.py`：akshare 多源自动切换（实测环境：股票日线走新浪、ETF 走东财、股票池=沪深300权重Top120 + **中证1000尾部小市值40只（×2滑点分档诚实计费）** + ETF成交额Top30（宽基/行业/债券/黄金/跨境，剔除货币ETF）），CSV 增量缓存，多级降级兜底。
- **回测引擎** `quant/backtest.py`：T+1、开盘涨跌停拒单、整手100股、佣金/印花税/过户费/滑点（小市值×2分档）、成交额参与率≤5%、个股-8%硬止损、最高持股2周。回测与实盘同一套撮合规则（`run.py verify` 用真实分钟数据逐单核验撮合假设）。
- **策略库** `quant/strategies.py`：12 个策略=可进化参数空间（基因型），其中 8 个源自公开验证的经典模型：

| 策略 | 出处（"拿别人成功的模型去推论"） |
|---|---|
| `rotation_28` 二八轮动 | A股量化社区经典大小盘轮动框架（20日动量短线版） |
| `dual_momentum` 双动量 | Gary Antonacci《Dual Momentum Investing》2014（相对+绝对动量） |
| `rsrs` RSRS择时 | 光大证券金融工程 2017 公开研报《基于阻力支撑相对强度的市场择时》 |
| `low_vol` 低波动异象 | Baker & Haugen 2012 / BAB 学术因子 |
| `momentum` 12-1动量 | Jegadeesh & Titman 动量（skip_days 跳近段） |
| `mean_rev` RSI2 | Larry Connors 短线均值回归经典 |
| `small_reversal` 小市值反转 | A股最强公开策略族：小市值+短期反转（标的池=中证1000尾部，×2滑点诚实计费） |
| `sector_momentum` 行业ETF轮动 | 机构常用行业轮动框架 |

**仓位控制基因（`quant/sizing.py`）**：个体基因 = {选股策略, 选股参数, **仓位策略, 仓位参数**}，"买什么"与"买多少"两层共同进化：

| 仓位策略 | 机制 |
|---|---|
| `equal` 等权 | 基线（选中即 1/N） |
| `inv_vol` 波动率倒数 | 风险平价式：低波者配更多，总暴露不变（海龟 ATR 定仓思想） |
| `vol_target` 组合波动率目标 | 总暴露 = clip(目标波动/市场实现波动, 下限, 1)，市场越动荡仓位越轻 |
| `ma_risk` 均线风险开关 | 等权指数跌破均线 → 整组缩至 risk_off 比例 |

仓位基因贯穿全链路同一口径：适应度/样本外晋升/随机取点闸/竞技场/备单/实盘/评估缓存键全部携带；
执行前仍被资产上限截断（股票15%/ETF50% 用户红线优先于任何仓位意图）；旧个体缺省按 equal 兼容。

**冠军团队（资产组合）**：冠军从单策略升级为**团队**——12个策略族各出最优个体、样本外验证后取前3个**不同族**组队、资金均分（`meta.team_size`）；换队须团队平均样本外分超现任5%。
**Walk-Forward 链式验证**（`run.py walkforward`，每周末自动）：把历史当实盘——每窗只用窗前数据进化→组队→下一段全规则撮合，权益链式衔接，全程无未来数据。首跑结论（2026-09-19，报告在 `logs/walkforward_*.md`）：近12个月6窗全部"无合格团队→空仓"（链式 0% vs 等权基准 +8.26%）——**样本外闸门拒绝部署过拟合参数，空仓纪律生效**。
GA 种群初始化注入以上经典标准参数作为**种子**——从验证过的起点进化，不从随机噪声起步。
- **进化引擎** `quant/evolve.py`：遗传算法（锦标赛选择/均匀交叉/高斯变异/精英保留）+ **4进程并行适应度评估**（迭代频率×3~4，`evolve.workers` 可调）+ 停滞自适应（变异步长放大/移民注入）+ **年化目标项**（`evolve.cagr_target=0.20`——朝20%目标倾斜搜索；目标是搜索方向，不是收益承诺）。
- **百团锦标赛** `quant/arena.py`（`run.py arena`）——**2026-09-20 赛制升级（用户指定）**：
  **100 支团队 × 各 100 万本金**，风格谱系五档各占 1/5 席位（**极稳/保守/均衡/进取/激进**，
  各档独立风控参数+曝光缩放，单票上限 5%→40%、止损 5%→12%、敞口 ×0.3→×1.0）——
  "从极度保守到极度激进都要有，均衡也要有，通过竞赛和迭代选出最合适的"。
  历史分段战绩 + 总榜 + **风格榜**（5 档均值战绩对比=哪种风格适合当下市场的直接证据，
  `logs/arena_*.md` 与 `arena_leaderboard.csv`）；优胜者基因自动注入GA种群；
  spawn之后每个收盘日全体团队前瞻结算（参数冻结的模拟实盘竞赛），周六自动重赛。

**联赛循环赛** `run.py league`（auto 闭市时段自动高频开局）——用户指定的团队制进化机制：
1. **一局=随机起点 3 年**（756交易日，用户指定周期）考核窗口，100支团队独立回测（**100万/队**，各自风格风控，全引擎规则）
2. **前10晋级下一局**，其余淘汰——换一批新团队进来（晋级者变异体+GA种群+经典种子+全新随机补满）
3. **多样性硬约束**：前10同策略族≤3、两两持仓权重相关性<0.85（"选股等策略都要不一样"，选股雷同者拒绝晋级）
4. **稳定前10认证**：连续3局留在前10（`arena.qualify_streak`）且过绝对分线 → 认证为"正式选手"，**基因注入GA种群参与冠军团队竞争**，留痕 `state.arena.qualified` 可审计
5. 随机窗口意味着：想靠"恰好适配某段行情"连庄3局极难——**认证=多个随机3年窗口的稳定性证明**
6. **风格席位保障**：换血时变异体派给席位最少的风格（冠军基因跨风格检验）+ 任何风格缺位自动补位——5 档风格永远在场竞技，风格谱系不会塌缩

## 快速开始

```bash
pip install -r requirements.txt
python run.py init        # 初始化：股票池 + 3.5年历史数据（约3-5分钟）
python run.py evolve -m 30     # 进化30分钟（随时可重复运行，进度自动续）
python run.py status           # 看状态：冠军/进化代数/账户
python run.py backtest         # 冠军全历史回测
python run.py paper --replay 250  # 闭市时：模拟实盘回放验证（最近250交易日）
python run.py auto             # 全自动守护（核心命令，建议常驻运行）
```

### auto 守护的一天

| 时段 | 自动动作 |
|---|---|
| 交易日 00:00-09:20 | **盘前空窗进化**（2026-09-21 上线）：凌晨不再沉睡——联赛/GA照常连打，每轮结束自动刷新备单，新晋团队当晚上位、当日开盘即可执行；09:20 用最新团队做末次备单 |
| 09:25-15:06 | 盘中会话：开盘执行调仓单 → 60秒轮询止损/超时/负面离场 → 收盘结算写轨道+出局判定（停机/毁灭线只看收盘） |
| 闭市其余全部时间 | **24小时连续进化**：联赛循环赛（随机1年窗开局，每队100万）→ GA迭代轮换进行 → 开市前备单 |
| 每个交易日后 | 分钟线语料自动入库（`data/minute_store/`，滚动窗口外永久保存） |
| 随时 | 项目根目录创建 `STOP` 文件 = 紧急停机（撤单+全面暂停） |

24小时进化模式的防磨刷设计：样本外晋升尝试每日上限 12 次（`evolve.max_promote_attempts_per_day`），
防止无限进化把验证窗口磨成变相训练集；全部进化代数与晋升记录留痕于 `state/state.json` 可审计。

关闭窗口不再误杀守护；单守护制——检测到 `run.py auto` 存活时绝不重复启动）。

### "自我进化"怎么防过拟合（五道闸）

1. **多时间片适应度**：训练期切3段分别回测取均值——参数只在单一行情段好使会被拉低分。
2. **样本外闸**：最近18%历史**从不参与**适应度计算，只用于冠军晋升验证。
3. **晋升门槛**：挑战者样本外分必须 > 现任冠军×(1+5%) 且过绝对分下限，否则冠军不动。
4. **磨刷上限**：每天最多12次晋升尝试，防24小时连续进化把样本外磨穿。
5. **随机取点闸**（历史随机窗口检验）：晋升团队成员须在 16 个随机(起点,长度)窗口上
   均分≥0.25 且过半窗口跑赢持币；团队每日体检 24 个随机窗口（seed=当日，可复现），
   不过线→自动置位衰退信号→GA移民重启搜索。`run.py stress` 随时手动复检。
   实测意义：固定切分的回测容易"恰好适配该段行情"——随机取点让模型必须在任意行情段活下来。
6. **回撤硬约束**（2026-09-20 用户确认，红线一致性）：团队成员**样本外最大回撤 ≤ 5%**
   （= 实盘回撤停机线 10% 的一半，`meta.team_member_max_dd`）——防止选出"会被自己的
   实盘风控枪毙"的冠军；现任成员定期复检，违规即清退，全员违规→团队整体退休空仓待新。
   每日新数据自动进入样本外，冠军"定型"后的表现构成模拟盘轨道——这就是实盘为证的起点。

### 历史当实盘的两条铁证轨道

- **Walk-Forward 链式验证**（每周末自动，`run.py walkforward` 手动）：每窗只用窗口前数据进化250代
  → 按族组队 → 下一段约2个月当实盘全规则撮合 → 权益滚动衔接，全程无未来函数。
  首跑诚实结论：近一年6窗均无合格团队（样本外闸门纪律=宁空仓不推垃圾），链式空仓0% vs 基准+8.26%。
- **随机取点体检**（每日自动，`run.py stress` 手动）：见第五道闸。

### 防作弊审计（`run.py audit`，每日自动——用户红线要求的机器验证）

"没有作弊"不靠口头承诺，靠三件可复核证据（首跑已通过，台账 `logs/audit_ledger.jsonl`）：

| 审计项 | 回应的指控 | 机器验证方式 |
|---|---|---|
| **无未来函数抽查** | "提前知道分时走势/结果" | 随机取5个历史日D，只用≤D的截断数据重算**完整决策链**（策略→仓位基因→团队合成），D行必须与全量计算逐元素一致（实测偏差 0.00e+00） |
| **复算一致性** | "AI幻觉/编造数字" | 同一输入跑两遍回测引擎，净值曲线哈希必须相同（实测两遍哈希一致） |
| **先声明后揭示** | "先看结果再下结论" | 审计先落盘声明（窗口+团队快照+输入/代码指纹），结果算完才追加——声明时结果尚不存在；台账追加式，事后篡改破坏时序一眼可辨 |

审计为只读操作（不写账户状态），可与运行中的守护进程并行。未通过时守护进程会明文报警：排查前不得实盘。

## 机制自进化与自动复盘（不只是参数在进化）

机制层面的自我更新（全部留痕可审计，红线永不自动修改）：

| 机制 | 触发条件 | 自动动作 |
|---|---|---|
| **GPU 广域海选**（RTX 4070 SUPER） | 每晚闭市段一次 | 8个排名/轮动族 × 3000组参数 torch 批量近似评估（400-2000组/秒）→ 每族Top12注入GA种群当移民。GPU出广度、CPU精确引擎出深度、样本外/体检/联赛闸门出裁决。海选窗口强制与GA目标同窗（训练期），实测教训：全历史打分在行情切换下与训练适应度负相关。无CUDA自动跳过不影响主流程；`run.py gpu-screen [--inject]` 可手动 |
| **市场风格引擎**（每晚+盘中每小时） | 定时 | 识别当下风格：趋势/震荡、动量/反转因子有效性（横截面IC）、大小盘占优、波动分位、市场宽度 |
| **模型近段验证** | 每晚备单前 | 冠军近40日实盘式验证 + 11个经典族同窗适配度排名（学习"现在什么有效"） |
| **风格错配处置** | 冠军近段明显跑输最适族 | 曝光系数×0.6 + GA移民偏向最适族加速换血 |
| **敌对风格防御** | 震荡+高波+冠军近段亏损 | 曝光系数×0.5（防御态；只降意愿，红线仓位/持股上限/收盘出局照常生效） |
| **停滞自适应** | 连续8代最优适应度无提升 | 变异步长×1.5逐级放大（上限×2.5）+ 下代注入30%移民（新随机个体替换最差） |
| **Top10 循环迭代**（用户指定核心机制） | **每一代** | ①先选出本轮前10名选手 ②看策略：每10代打印家族分布、状态/周报展示Top10画像与参数均值 ③子代全部由Top10繁殖（亲本池），其中25%为Top10邻域小步精修（40%步长），循环迭代赢家 |
| **锦标赛换血** | 每届锦标赛后（周度/手动） | 总榜Top10原样保留（个人轨道延续）+ 每人1个变异体 + GA种群/经典种子/中游表现者/新随机补满100人 → 下一届阵容即本届赢家的迭代 |
| **突破回落** | 最优分显著突破 | 变异步长回落至×1.0（收敛态） |
| **冠军衰退检测** | 轨道≥15个交易日且实际年化 < 冠军样本外年化×33% | 置位衰退信号 → 进化引擎下轮注入50%移民重启搜索 |
| **每日结算报告** | 每个交易日收盘 | `logs/report_YYYYMMDD.md`：权益/持仓/成交/风格快照/风控状态（追加式） |
| **周度机制复盘** | 每周六（`meta.weekly_review_weekday`） | `logs/review_YYYYMMDD.md`：轨道绩效、风格演变、交易行为画像、进化健康度、衰退检测；`run.py review` 手动触发 |
| **红线隔离** | —— | 用户指定风控（15%仓位/-8%止损/15日上限/停机10%/出局80%）硬编码为用户规则，风格引擎/复盘/进化只调方法论（曝光/移民/步长/换血），永不自动改红线 |

随时看市场风格与模型验证：`python run.py regime`（当日什么风格、冠军近段表现、当前什么策略族最有效）

## 风控规则（稳健档，`quant/config.py`）

| 规则 | 阈值 | 行为 |
|---|---|---|
| 定位 | **小散户：10万本金**（用户指定） | 最小佣金5元摩擦占比更高，费率建模与 10 万口径全部一致 |
| **负面清单** | **亏损/暴雷/衰亡行业/舆论负面 不做**（用户指定） | 三层强制执行（见下节）：股票池筛选 → 备单终检 → 持仓负面离场 |
| 交易风格 | **短线·日频**（用户指定） | 收盘决策→次日开盘执行，无分时交易；盘中仅执行风控（止损/超时离场） |
| 持股级别 | **3~15个交易日**（用户指定） | 不满3日不因调仓卖出；满15日开盘强制离场、当日不回买；止损/超时离场不受限；回测/模拟/实盘三端同规则 |
| 单只股票仓位 | ≤15% 组合市值（用户红线） | 订单生成时硬截断 |
| 单只ETF仓位 | ≤50% 组合市值（ETF=一篮子股票，轮动类经典模型需要集中度；`risk.max_etf_position_pct` 可调） | 同上 |
| 持仓数量 | ≤8 只 | 订单生成时截断 |
| 个股止损 | -8%（相对成本） | 盘中轮询触发立即卖出（T+1可卖部分）——交易纪律（换股），非账户出局 |
| ~~单日熔断~~ | 已停用（2026-09-21 用户指令"不能盘中波动就出局"） | 日亏损不是出局理由；回测/模拟盘两端一致关闭 |
| 回撤停机 | 距高水位（收盘权益）-10% | **收盘结算判定**（盘中波动不触发）；全面停机+撤单，**需人工 `run.py resume`** |
| 毁灭出局 | 收盘权益 ≤ 初始本金×20%（亏80%） | **唯一账户出局线**（用户"亏完出局"）：数学实质亏完（需+400%回本），永久停机不自动恢复，残值保留 |
| 保底现金 | ≥2% | 始终保留 |
| 参与率 | 单票 ≤当日成交额5% | 防冲击成本 |

## 负面清单（四条"不做"，`quant/fundamental.py`）

| 规则 | 实现 | 自动化程度 |
|---|---|---|
| ① 亏损的不做 | 最新报告期净利润 ≤ 0 → 剔除（东财业绩报表，全市场单请求） | 全自动 |
| ② 暴雷的不做 | 净利润同比 < -60%（暴雷代理）+ ST/退名称 + 手动黑名单 | 自动+手动 |
| ③ 共识衰亡行业不做 | 行业关键词排除（预置"房地产"，`run.py blacklist add-industry` 增删） | 自动 |
| ④ 舆论负面广不做 | 舆情无法可靠自动化：**人判断，`run.py blacklist add 编号 "原因"` 录入，系统强制执行** | 手动 |

**三层执行**（缺一不可）：股票池筛选（买入源头堵死）→ 备单终检（防池缓存与最新披露脱节）→
持仓负面离场（"不做"含持货：持仓新触发负面，会话内强制清仓）。
实盘数据（20260630报告期）：当前股票池自动命中12只（牧原/温氏/隆基等亏损8只+暴雷4只）。
维护命令：`run.py blacklist show / add / remove / add-industry / remove-industry / refresh`。

## QMT 实盘接入（5步）

1. 券商开通 QMT 权限（各券商门槛不同，常见 10-50 万资产 + 申请）。
2. QMT 客户端以**极简模式**启动并登录（交易日 8:45 前挂好）。
3. `config.json` 填 `qmt.account_id`（资金账号）与 `qmt.qmt_path`（QMT 目录下 `userdata_mini`）。
4. xtquant 库：`pip install xtquant`；装不上则把 QMT 自带库目录填到 `qmt.xtquant_path`。
5. 先保持 `qmt.dry_run: true` 跑通（只打印委托不真实报单），再改 `false` 真实下单；向券商完成**程序化交易报备**后，把 `mode` 改为 `live`，`python run.py auto`。

实盘与模拟盘共用同一决策/风控代码，仅撮合通道不同（`quant/broker_qmt.py`）。

## 常见问题

- **为什么冠军晋升这么慢/一直没冠军？** 样本外绝对分门槛 0.45 不低——2022-2025 是难做的行情段，多数日频策略过不了闸。这正是设计的防垃圾机制：宁可空仓，不上歪招。
- **东财/新浪接口连不上？** 已内置多级降级：股票历史（新浪↔东财互备）、ETF 历史（东财→新浪）、股票池（csindex权重表→成分表→旧缓存）、ETF池（东财快照→内置主流清单）。盘中全市场快照约25秒且偶发限流，失败会自动重试。
- **想跑更快进化？** `python run.py evolve -g 20 -m 120` 手动加代数；或调大 `evolve.population`（代价是每代更久）。
- **模拟账户玩坏了？** `python run.py reset-account` 重置为100万（进化进度保留）。
