# MoneyViz · 进化竞技场（团结引擎可视化）

把 Money 自进化交易系统变成像素小人世界——**打开项目按 Play 即可**，无需任何场景配置
（代码在运行时自动接管场景、程序化搭建全部画面，零美术资产）。

## 怎么看懂画面

| 画面元素 | 含义 |
|---|---|
| 🧍 地台上的像素小人军团（10个） | **Top10 循环迭代擂台**（用户指定核心机制）——#1~#10 排名、颜色=策略家族、**地台高度=真实适应度**；无Top10数据时退化为最近各代最优 |
| 🟦 市场风格行 | 风格引擎快照：趋势/震荡 · 动量/反转有效 · 大小盘占优 · 宽度 · 波动 · 当前最适族 |
| 🟠 锦标赛战报行 | 周度锦标赛：参赛人数、最佳选手与收益 |
| 👑 金色小人 + 皇冠 | 现任冠军（冠军殿堂），换代时播放退位→登基→加冕→彩带动画 |
| 顶部 σ 风暴表 | 变异步长倍数：停滞自适应触发时变红并放大 |
| 红色像素雨/星星坠落 | 变异风暴（GA 检测到停滞、放大σ、注入移民的瞬间） |
| 🪙 金币喷泉 | 检测到新成交（state.trade_log 更新） |
| 底部像素曲线 | 账户轨道（paper_track 逐日收盘权益），灰虚线=基线 |
| 全屏红晕 + 警报字 | 日熔断（亏3%）/ 组合停机（回撤10%） |
| 右上角市场时钟 | 开市/闭市状态 + 下一开市倒计时（读真实交易日历 data/trade_dates.csv） |
| 右侧面板 | 冠军样本外战绩（分/年化/回撤/夏普/胜率） |

## 数据连接

- 自动向上级目录查找 `state/state.json` 与 `data/trade_dates.csv`（本项目位于 `Money/MoneyViz`，天然命中）
- 每 2 秒轮询刷新；找不到状态文件时进入**演示模式**（左上角红字提示）
- 交易系统在跑 `python run.py auto` 的同时打开本可视化即可实时联动

## 技术说明

- 4个脚本（`Assets/Scripts/Viz/`）：`MiniJson`（轻量JSON解析）、`PixelArt`（程序化像素画工厂）、`StateFeeder`（状态轮询/演示模式）、`VizBootstrap`（场景构建与全部动画）
- 精灵全部由代码生成（16×16小人两帧行走、金币、皇冠、星星），无外部资源依赖
- 中文渲染使用系统字体（微软雅黑→SimHei 依次探测）
- 编辑器要求：团结引擎 1.10.3（2022.3.62t15）
