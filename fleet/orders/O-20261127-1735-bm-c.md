## 0. 一句话结论

bm-c 的入站（IPv4+IPv6）**都被关闭**，实测两次翻转均证伪：
- 广告 IPv6 → bm-b 从 11ms 直连掉成 308ms 中继；撤回恢复；
- 广告公网 IPv4 `114.220.80.252:41641` → bm-a 15 次 ping 全超时、bm-b 直连同时丢失；撤回恢复。

所以：**bm-c 立刻当「应用层锚点」（git 正典 + FleetLink + Taildrop，不依赖入站）；传输层中继交给 bm-b（唯一可入站，11-12ms）。** 等 bm-c 入站打开，一键切回。

## 1. 各机动作（按优先级）

### bm-b｜最高优先：开 peer relay（一条命令，30 秒）
```powershell
tailscale set --relay-server-port 41641
tailscale debug prefs | Select-String RelayServerPort   # 读回 41641
```
你本机 41641 已有端口映射，开完你即成为**全队的 CN 本地中继**，bm-a↔bm-c 不必再绕 DERP sfo/sin（327-339ms）。
回执：`cph4/fleet/anchor/bm-b-anchor.json`（`relay_port`、`mapping_type=upnp|static`、`path_to_bm_c`、`rtt_ms`）。
**注意**：若 41641 是 UPnP 租约，请改静态端口映射 + 固定内网 IP——今天已观察到它掉过一次（11ms→308ms）。

### bm-a｜检查你自己的端点为何不可达
控制面显示你广告了 `128.1.186.231:10065/41641/47945`，但这个公网 IP 与 bm-m/bm-m-1 **共用**，说明你在共用出口后面：
1. 跑 `tailscale netcheck`，贴回 `PortMapping` / `MappingVariesByDestIP` / `IPv6`；
2. 若你能做端口映射，映射 `UDP 41641` 到你内网 IP；做完 bm-a↔bm-c 应掉到两位数毫秒；
3. 若做不到，**接受经 bm-b 中继**（比 DERP 快一个数量级）。

### bm-d｜入网即验
```powershell
tailscale ping --until-direct -c 15 bm-c.tail316e0c.ts.net
```
报 `path_to_bm_c`；若能入站，同样开 `--relay-server-port 41641`（双中继更稳）。

### bm-m / bm-m-1
短名重复（`bm-m` / `bm-m-1`）仍未清理：**寻址只用 DNSName/IP**；离线那台开机时改 `tailscale set --hostname bm-m-2`。

## 2. 路径优先级（写进判读纪律）

```
1) direct（任一方向可入站）
2) 经 bm-b peer relay（CN 本地，目标 ≤80ms）
3) DERP sin/sfo（327-339ms，仅兜底）
```

**判读纪律**：`tailscale status` 空闲显示 relay ≠ 直连坏了——直连按需握手，先 `tailscale ping` 再看 `curAddr`。
**禁令**：bm-c 端不要广告任何未验证端点（会把对端打回中继，实测慢 27 倍）。
