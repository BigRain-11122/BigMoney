## 0. 一句话

bm-c 的网络角色升级为**锚点**；生产角色（gpu-production 车道）**不变**。
当前锚点**只开了监听、没广告端点**，因为本机入站还被光猫挡着——要先做一步物理动作，锚点才真生效。

## 1. 现状（实测数字，别猜）

| 链路 | 今日实测 | 备注 |
|---|---|---|
| bm-b ↔ bm-c | **direct 124.77.140.89:41641 = 11ms** | 直连按需建立，空闲时 status 显示 relay 属正常 |
| bm-a ↔ bm-c | relay sin **327-330ms**（偶发 639ms-1.4s） | bm-a 无入站可达性 |
| bm-b 回落 DERP | sfo **308ms** | 直连掉线时慢 27 倍 |
| bm-c Taildrop → bm-a | 1MB / 12.4s = **82.7 KB/s** | 中继级带宽 |

锚点翻转实验（关键判据）：
- bm-c 广告自己的公网 IPv6 作锚点端点 → **bm-b 从 11ms 直连掉到 308ms 中继**；
- 撤回广告 → **11ms 立刻恢复**。
- 判定：**bm-c 入站被挡，广告端点有害**。当前 `static_endpoints=`（空），只留 `relay_port=41641` 监听。

## 2. 各机要做的动作

### bm-a（最急，因为它最慢）
1. 跑一次 `tailscale netcheck`，把 `IPv6`、`PortMapping`、`MappingVariesByDestIP`、`Nearest DERP` 贴进回执。
2. 若路由器可开端口：**UDP 41641 → bm-a 内网 IP**（与 bm-b 同样做法）。做完 bm-a↔bm-c 应掉到直连两位数毫秒。
3. 回执落 `cph4/fleet/anchor/bm-a-anchor.json`（字段：`ipv6`,`portmap`,`symmetric`,`derp`,`path_to_bm_c`,`rtt_ms`）。

### bm-b（当前事实锚点，但要防掉线）
1. 确认 41641 是靠 **UPnP 租约**还是**静态端口映射**。UPnP 会过期——今日就观察到直连掉过一次。
2. 若为 UPnP：改静态端口映射 + 固定内网 IP，否则随时回 relay sfo。
3. 回执 `cph4/fleet/anchor/bm-b-anchor.json`，多写一个 `mapping_type=upnp|static`。

### bm-d（入网时）
1. 入网后第一件事跑 `Tools/fleet-bmc-anchor-check` 等价命令：`tailscale ping --until-direct -c 15 bm-c`。
2. 报告 `path_to_bm_c`；若可入站，把 41641 一起开（双锚点比单锚点稳）。

### bm-m / bm-m-1
1. 短名重复仍在（`bm-m` 与 `bm-m-1` 同名 bm-m）：**寻址一律用 DNSName/IP**，别用短名。
2. 离线那台开机时由属主改 `tailscale set --hostname bm-m-2`。

## 3. 路径优先级（全队统一，写进各自脚本/判读）

```
1) direct（任一方向可入站）
2) 经 bm-c 锚点中继（锚点放行后自动成立）

```

判读纪律：`tailscale status` 空闲快照显示 relay **不代表**直连坏了；先发流量（`tailscale ping`）再看 `curAddr`。
