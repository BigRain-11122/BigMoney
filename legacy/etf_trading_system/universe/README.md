# ETF 标的池

## 文件

- `etf_universe.csv`：主标的池，字段见下
- `industry_map.csv`：行业 → 代表 ETF 映射，用于行业轮动策略

## etf_universe.csv 字段

| 字段 | 说明 |
|---|---|
| code | 6 位交易代码 |
| name | 场内简称 |
| category | broad / industry / cross_border / commodity / bond |
| tracking_index | 跟踪标的指数 |
| exchange | SSE（沪）/ SZSE（深） |
| list_date | 上市日期（留空，由数据拉取脚本补全） |
| liquidity_tier | A=日均成交额>5亿，B=1-5亿，C<1亿（粗估，实盘前必须用实时成交额校准） |
| note | 备注 |

## 入选原则（3-15 天日线波段）

1. **只做 A 级流动性**：日均成交额 > 5 亿，确保 3-15 天波段能进得去出得来。
2. **避免 C 级标的**：买卖价差大、滑点高，短波段策略不适用。
3. **行业分散**：宽基 + 行业 + 跨境 + 商品，单一行业不超过组合 30%。
4. **剔除新上市 < 60 个交易日的 ETF**：数据不足，信号不可靠。
5. **债券 ETF 只做对冲/底仓**：不参与 3-15 天进攻性波段。
